# 黑地图：单机游戏创意库

> **当前项目方向**：先读[玩法与剧情简要说明](玩法与剧情简要说明.md)及[最新大纲与修改意见](大纲/当前版本/README.md)。[历史大纲](大纲/历史/README.md)单独归档。下方创意库是备选素材，不是全部实施需求。

从“摸黑走迷宫”出发，想一想探索游戏还能长成什么样。

这里有玩法、有故事、有可以独立成作的方向，也有只适合出现一次的小场面。它们不必同时成立。你可以喜欢一座会照顾人的房子，同时完全不喜欢时间循环；拿走你喜欢的部分就好。

所有正文放在 **[创意库](创意库/索引.md)**，按主题分类。目前有 **200 个带编号的创意条目**：原有 160 个逐条补了实现计划，新增 40 个把实现入口写在点子下方。

想挑方向，先读[十二个完整方向](创意库/06-完整游戏方向/十二个方向.md)；想知道怎么做，直接打开[实现规划索引](创意库/09-实现规划/索引.md)。实现计划包括操作、状态与规则、可先做的小片段，以及需要处理的边界。

## 阅读时留一个心眼

这里的“独特”是创作目标，不是“市场上绝对没人做过”的保证。黑暗探索、时间残影、地图编辑等都有已有作品的先例。真正值得争取的是：玩家在这里反复做出的判断、产生的感情，以及行为留下的后果，有自己的味道。

这是一份创意与实现规划资料，不是已经开发或验证好玩的游戏。技术路线是可尝试的选择，尚未绑定引擎、工期或商业模式；先用小片段验证，再决定哪些值得扩展。
