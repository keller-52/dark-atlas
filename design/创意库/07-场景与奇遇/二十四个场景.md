# 二十四个场景

这里放的是玩家可能记得很久的一小段体验。有些能当一关的中心，有些只该路过一次。编号后的关联是可选的，不是必须安装的机制套餐。

<a id="v01"></a>

## V01｜桥头的灯

[查看实现思路](../09-实现规划/12-具体场景.md#v01)

桥只有被照着才存在。你把灯留在桥头，摸黑过桥。回来时，发现有人把灯换了角度，让更矮的孩子也能看见桥面。它先是一道题，后来变成别人参与过的地方。关联：G07、E09。

<a id="v02"></a>

## V02｜楼下正在量身高

[查看实现思路](../09-实现规划/12-具体场景.md#v02)

你站在废墟里，过去的孩子问你墙边哪里适合做记号。你圈出位置。下一次来，刻痕已经长过你的肩膀。不要立刻解释他后来的人生，让玩家先停一会儿。关联：M08、T03。

<a id="v03"></a>

## V03｜怪物给你让路

[查看实现思路](../09-实现规划/12-具体场景.md#v03)

狭窄走廊里你无处躲藏。怪物停下，侧过身，重复一种陌生动作。你学会回应，双方才擦身而过。后面这套礼仪能真正使用，而不只是一次剧情豁免。关联：E07、R05。

<a id="v04"></a>

## V04｜地图上多了一张桌子

[查看实现思路](../09-实现规划/12-具体场景.md#v04)

你休息时，另一端的人在地图角落画了一张桌子，问你家乡早餐吃什么。这个空白不服务谜题，只让后续的沉默有分量。关联：M08。

<a id="v05"></a>

## V05｜一间不会追你的房间

[查看实现思路](../09-实现规划/12-具体场景.md#v05)

整章都在移动的建筑里，有一间普通厕所始终原地不动。门上写着“总得有个地方让人安心”。它没有隐藏怪物，真的安全。关联：S04。

<a id="v06"></a>

## V06｜你的错误路标救了人

[查看实现思路](../09-实现规划/12-具体场景.md#v06)

你早先标错一个方向，回访时发现一群人因为绕远，避开了事故。它不会证明错误总是好事，只提醒地图的后果超出绘图者想象。让玩家有机会更正，不把偶然变成最优路线。关联：M04、N02。

<a id="v07"></a>

## V07｜不要替我开灯

[查看实现思路](../09-实现规划/12-具体场景.md#v07)

你习惯性点亮老人家门口的灯，他请你关掉。等一会儿，黑暗里出现一群只在夜间来探望的小东西。你可以坐下听他给它们起的名字。关联：E02、N10。

<a id="v08"></a>

## V08｜出口门框上的抓痕

[查看实现思路](../09-实现规划/12-具体场景.md#v08)

你一直以为抓痕来自逃不出去的人，后来从另一侧看见门框：痕迹都是为了阻止门自己离开。下一步可以是追门，也可以先问谁需要它留下。关联：S03。

<a id="v09"></a>

## V09｜房子闹别扭

[查看实现思路](../09-实现规划/12-具体场景.md#v09)

你连续几次只拿物资、不停留。回来时床被放得离门很远。没有好感扣分提示，只有一间不善表达的房子。你可以搬回去，也可以留下来喝杯茶。关联：R01。

<a id="v10"></a>

## V10｜熟路上的陌生扶手

[查看实现思路](../09-实现规划/12-具体场景.md#v10)

你受伤后走不稳。回程发现路边多了临时扶手，是你此前教会认路的人装的。他并不知道你今天受伤，只是觉得这里对很多人都不好走。关联：R03、E09。

<a id="v11"></a>

## V11｜排练中的笑场

[查看实现思路](../09-实现规划/12-具体场景.md#v11)

你移动错误道具，演员第一次脱离固定台词笑出声。没有灾难，演出反而活了。这个场面告诉玩家，打破循环不必总通过破坏。关联：S10。

<a id="v12"></a>

## V12｜两份不一样的午饭

[查看实现思路](../09-实现规划/12-具体场景.md#v12)

你与过去的人约好同时吃饭。你这边只有罐头，他画了一盘不太像的饺子。几章之后，地图上同一个油渍仍然在。关联：M08、W03。

<a id="v13"></a>

## V13｜救援员终于找到你

[查看实现思路](../09-实现规划/12-具体场景.md#v13)

你躲了他一整章，后来真的被困。你学会吹他教过的哨音，他沿声而来，没有责备，只先递水。此前的对抗因此获得另一种含义。关联：H05。

<a id="v14"></a>

## V14｜没寄出的地址

[查看实现思路](../09-实现规划/12-具体场景.md#v14)

一封信的收件地址随着你接近而改变。信并不想送达，因为寄信人后悔了。你需要找寄信人确认，而不是无条件把投递当成正确目标。关联：S07、R02。

<a id="v15"></a>

## V15｜整座市场把门朝向你

[查看实现思路](../09-实现规划/12-具体场景.md#v15)

你帮助迁徙市场避过洪水。下次路过，商贩们把门统一朝向你的来路，方便你穿行。他们不停止做生意向你致敬，只自然地招呼一句。关联：E10、E05。

<a id="v16"></a>

## V16｜有一只影子没有重复

[查看实现思路](../09-实现规划/12-具体场景.md#v16)

回溯留下的影子照常动作，只有一个停下来扶住即将倒下的架子。不是立刻宣布它觉醒，而是给你一个可再次验证的异常。后续需要解释哪条规则造成偏差。关联：T01、N03。

<a id="v17"></a>

## V17｜你听见自己明天会说的话

[查看实现思路](../09-实现规划/12-具体场景.md#v17)

空房里传来“别进来”。你先绕开，后来有机会站在同一位置决定是否说出这句话。重要的是留下选择，而不是把玩家控制权强行拿走以闭合时间线。关联：G10、T09。

<a id="v18"></a>

## V18｜最后一班车上的空位

[查看实现思路](../09-实现规划/12-具体场景.md#v18)

总坐在后排的人今晚没上车。经过他家，窗里有人一起吃饭。他没有消失，也不是死了，只是不再需要独自坐车到天亮。关联：R10、W05。

<a id="v19"></a>

## V19｜你照不见的幼崽

[查看实现思路](../09-实现规划/12-具体场景.md#v19)

一只始终不可见的动物把食物推到你的脚边，又轻轻往旁边拨了一点。你从多出来的进食声，知道它不再独居。镜头不必给答案。关联：E02、W06。

<a id="v20"></a>

## V20｜一场不用赢的追逐

[查看实现思路](../09-实现规划/12-具体场景.md#v20)

孩子请你扮演怪物。你可以故意撞错门、放慢速度，也可以认真绕路。他们笑着逃跑，让你第一次用熟悉的追逐操作带来快乐。关联：H01、P10。

<a id="v21"></a>

## V21｜灯不是留给你的

[查看实现思路](../09-实现规划/12-具体场景.md#v21)

远处一直亮着一盏灯，你把它当作目标。抵达后发现只是有人给晚归的伴侣留门。他愿意让你歇脚，但世界并没有处处围着主角布置。关联：R06、N10。

<a id="v22"></a>

## V22｜终于有一张准确的地图

[查看实现思路](../09-实现规划/12-具体场景.md#v22)

经历很多不确定之后，你进入一个地形稳定、标记清楚的小区域。完整地图在入口免费提供。这里的乐趣来自使用掌握，而非继续剥夺信息。关联：M01。

<a id="v23"></a>

## V23｜给另一种身体修的路

[查看实现思路](../09-实现规划/12-具体场景.md#v23)

你作为巨大生物修好一条宽路，发现孩子仍过不去旁边的高台。你重新蹲下，从他们的视角检查一次。最后路既能让你走，也能让轮椅通过。关联：G08、P10。

<a id="v24"></a>

## V24｜今晚是你等人敲门

[查看实现思路](../09-实现规划/12-具体场景.md#v24)

主角生病，外出按钮暂时变成“休息”。不久有人按你平时的节奏敲门，放下一份热饭。玩家可以起身开门，或者听对方隔门讲今天路上的事。没有隐藏超时失败。关联：R09、W08。
