# 八个故事提案

这些是不同作品的故事胚子。它们不共享一套宇宙，也不需要最后都证明“黑暗其实是记忆”。

<a id="w01"></a>

## W01｜《无人认领的街道》

[查看实现思路](../09-实现规划/09-故事提案.md#w01)

**开头。**你收到一封寄给已故母亲的水费通知。地址是地图上不存在的一条街。去处理这件小事，才发现城里所有被行政系统遗漏的地方，都会逐渐变黑。

**中间。**你为居民补画地图、核实门牌，街道重新接上公共设施。但一些人本来就是为了躲避追索才住进去，重新被看见并不总是好事。母亲当年既帮助过他们，也替其中一些人做过未经同意的决定。

**后面。**一场城市更新要求你提交完整地图。你可以建立居民共同管理的地图、留下一套只有当地人懂的路标，或协助部分人迁出。结局看实际形成的网络，不靠一句漂亮宣言。

最想保留的场面：电终于接通，整条街只有一家没有开灯。不是坏结局，那家人只是睡了。

适合 M04、M05、M09、R07。不要把所有制度角色写成坏人；一个认真工作的抄表员也可以成为重要同伴。

<a id="w02"></a>

## W02｜《请替我把灯关掉》

[查看实现思路](../09-实现规划/09-故事提案.md#w02)

**开头。**城市的夜晚被长期照明工程取消了。你是一名逐区检修的人，工作是在停用旧灯前确认安全。没有人相信黑暗里还有别的生活。

**中间。**你发现某些居民只能在暗处入睡，某些植物需要真正的夜晚，而某些路又确实不能熄灯。你逐渐学会分区、遮光和安排时间，而不是简单反对照明。

**后面。**一次故障迫使全城选择哪些地方优先供电。你之前建立的照明习惯、邻里互助与暗路，会决定这一夜是否能平安度过。

结尾可以是天亮之前的一场街头早餐。人们第一次不是在机器规定的白昼里醒来。

适合 E01、E02、E07。气质偏安静、温暖，有未知感，不必有主要反派。

<a id="w03"></a>

## W03｜《迟到的地图》

[查看实现思路](../09-实现规划/09-故事提案.md#w03)

**开头。**你在拆迁楼里捡到一本旧图册。你写下“这里已经拆了”，纸上回了一句：“没有，我就在这里。”另一端是几十年前的孩子。

**中间。**你们用小改动互相帮助。孩子需要通过一场考试、找到走丢的猫，后来才卷入影响整条街的事故。你掌握未来的结果，却不了解当时每个人的动机。

**后面。**不是所有事都能改。你们需要决定保住什么、留下什么证据，以及是否继续维持这条联系。故事要允许救下具体的人，避免所有努力都被宿命抹掉。

最想保留的场面：你让他在墙边量身高，下一次回到废墟，墙上多了许多年的刻痕。

适合 M08、T03、N04。对方必须有自己的生活，不要每次上线只谈主线灾难。

<a id="w04"></a>

## W04｜《一间房子的离家出走》

[查看实现思路](../09-实现规划/09-故事提案.md#w04)

**开头。**你继承了一间会走路的旧屋。它嫌弃新家具、讨厌下雨，还会趁你睡着偷偷掉头。你以为它认旧主人，后来发现它在找自己最初建造的地方。

**中间。**你们经过迁徙市场、废弃采石场和无人居住的村庄。你认识它用过的木头、借来的窗和被换掉的梁，也认识那些参与过建造的人。

**后面。**原址已经成了水库。你可以帮助它接受变化，找一个新的停泊处，也可以把还能使用的部分送给需要的人。不要把“拆掉房子才算成长”定为唯一正确选择。

最想保留的场面：下雨时它习惯性把屋檐移向你，自己那边的旧木板却湿透了。

适合 R01、S04、E10。允许拌嘴、维修失败和不感人的普通下午。

<a id="w05"></a>

## W05｜《末班车不去终点》

[查看实现思路](../09-实现规划/09-故事提案.md#w05)

**开头。**你接手一条夜间公交线，地图只有几个站名，没有道路。乘客报出的目的地会让城市临时拼出路线。

**中间。**有人要去已经倒闭的电影院，有人只想坐到困，有人每天上车却从不下车。你决定先满足谁、在哪里停、是否绕路寻找旧地址。

**后面。**线路即将停运。你可以帮助乘客建立新的联系，而不是让所有人永远依赖这辆车。最后一班究竟运送的是人、物品还是未完成的告别，由之前的关系决定。

适合 S01、S03、R10。交通本身可以轻松，悬念来自乘客之间逐渐产生的关系。

<a id="w06"></a>

## W06｜《没人见过的动物园》

[查看实现思路](../09-实现规划/09-故事提案.md#w06)

**开头。**你接下夜间饲养员工作。规定只有一条：不要打开全园照明。园里住的是无法被直接看见的动物，你靠食量、声音与足迹理解它们。

**中间。**你发现所谓逃跑事故，有些其实是迁徙，有些是动物在寻找同伴。园方、居民与动物的需要并不相同。你开始调整隔栏、遮挡和夜间通道。

**后面。**有人要求拍下全部动物证明它们存在。你要提供另一种可信的证据，或建立能让人相处而不必占有全部视野的方式。

适合 G02、E02、E07、R05。最后不必露脸。玩家能够准确理解一种生物的脾气，已经是一种相遇。

<a id="w07"></a>

## W07｜《排练结束以后》

[查看实现思路](../09-实现规划/09-故事提案.md#w07)

**开头。**你是剧场新来的场务。演出每天重来，演员记得台词，却不记得昨天。只有后台会留下变化。

**中间。**你通过搬道具、改灯位、提前发出音效，让演员有机会偏离角色。有人想离开，有人害怕没有剧本以后不知道怎样活。

**后面。**你发现循环最初是为了保护一次无法承受的失败。但解除它不等于强迫所有人接受你的答案。你可以安排最后一场演出，让他们自己选择是否走出舞台。

适合 S10、G07、N03。重点是排练与即兴，不必在最后引入一层“原来都是程序”。

<a id="w08"></a>

## W08｜《送到时还是热的》

[查看实现思路](../09-实现规划/09-故事提案.md#w08)

**开头。**一座被黑暗分开的城里，你负责送饭。订单写着普通需求：少辣、敲两下门、别吵醒孩子。你通过这些小事认识路线。

**中间。**饭菜温度会暴露你，也会吸引愿意帮忙的生物。某些收件人不吃饭，只是需要每天有人敲门；某些人开始替你给下一站捎东西。

**后面。**你生病了。你曾经帮助建立的邻里路线，决定今天谁会接过保温箱。游戏可以在你第一次成为收餐者时结束。

适合 G04、R03、R06、R09。它可以没有大阴谋。小人物之间形成可依靠的生活，本身就足够成为结局。
