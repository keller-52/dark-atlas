# 十六个人物与关系种子

人物先有生活，再有谜题用途。下面每个人都应该能够拒绝主角、犯普通错误，或者在与你无关的时候做点事。

<a id="c01"></a>

## C01｜认路很差的邮差

[查看实现思路](../09-实现规划/10-人物种子.md#c01)

他记不住街道，却记得每个人家门口的声音。你修了所有吱呀作响的门，反而让他迷了路。关系可以从互相嫌弃开始，最后一起设计更好的路标。

<a id="c02"></a>

## C02｜不肯逃走的修鞋匠

[查看实现思路](../09-实现规划/10-人物种子.md#c02)

不是为了悲壮地守住故土，只因为他答应给邻居孩子修的鞋还没交。你可以找孩子、安排接手，也可以帮他收拾。别强迫他用死亡证明固执。

<a id="c03"></a>

## C03｜假装知道路的孩子

[查看实现思路](../09-实现规划/10-人物种子.md#c03)

他给你指路，是因为怕承认自己也迷路了。识破后不是惩罚或赶走，而是一起重新做标记。后来他第一次诚实地说“不知道”，应该是关系进展。

<a id="c04"></a>

## C04｜不会保密的门

[查看实现思路](../09-实现规划/10-人物种子.md#c04)

门很热情，会向所有来客介绍谁住在里面。你需要帮它理解什么可以说、什么应该先问。它并非笨，只是从来没见过需要藏起来的人。

<a id="c05"></a>

## C05｜嫌你太轻的渡船

[查看实现思路](../09-实现规划/10-人物种子.md#c05)

船需要足够重量才能在特定水层航行。它让你帮忙捎东西，逐渐把你变成沿河居民的信使。它喜欢抱怨，但从不在你没站稳时开船。

<a id="c06"></a>

## C06｜一直替别人等人的老人

[查看实现思路](../09-实现规划/10-人物种子.md#c06)

他记着几份几十年前的约定，替已经去世的人继续等。你可以查明这些约定，也可以只是轮一天班，让他去吃顿热饭。

<a id="c07"></a>

## C07｜过分认真的救援员

[查看实现思路](../09-实现规划/10-人物种子.md#c07)

他反对你深入危险区，有充分理由，也愿意解释。他不是可戏弄的笨追兵。某一次你真的失去方向时，之前觉得烦人的哨声会让你安心。

<a id="c08"></a>

## C08｜讨厌被叫作安全屋的房子

[查看实现思路](../09-实现规划/10-人物种子.md#c08)

它说自己也想看风景，不想只等你睡觉。你可以把窗朝向不同地方，带它参加集市。它要求的不是升级材料，而是共同生活中的位置。

<a id="c09"></a>

## C09｜不想恢复记忆的人

[查看实现思路](../09-实现规划/10-人物种子.md#c09)

他现在有朋友、有工作，对自己的过去既好奇又害怕。你找到的证据不应自动触发恢复。先问他，再允许他分几次决定看多少。

<a id="c10"></a>

## C10｜替怪物翻译的人

[查看实现思路](../09-实现规划/10-人物种子.md#c10)

她承认自己的翻译只是猜测。有时猜错，却会负责补救。后期玩家掌握更多信息，可以和她一起修订，而不是揭穿她是骗子。

<a id="c11"></a>

## C11｜一直在换工作的前任英雄

[查看实现思路](../09-实现规划/10-人物种子.md#c11)

他曾救过城市，现在想卖面包，但大家还把难事交给他。你可以继续求助，也可以学会把他的普通生活当回事。

<a id="c12"></a>

## C12｜比你年轻的上一轮自己

[查看实现思路](../09-实现规划/10-人物种子.md#c12)

他很相信那个你已经不再相信的计划。你可以帮助他测试、说明失败证据，或陪他亲自走一段。不要把成熟写成嘲笑以前的天真。

<a id="c13"></a>

## C13｜负责涂掉道路的人

[查看实现思路](../09-实现规划/10-人物种子.md#c13)

她的工作与制图师相反：道路泄露、塌陷或危及居民时，她负责删除。她懂得哪些空白是保护，与你的争论可以一直没有唯一胜者。

<a id="c14"></a>

## C14｜送餐时总说不饿的邻居

[查看实现思路](../09-实现规划/10-人物种子.md#c14)

他省下饭给楼下的人，又不愿被当作好人。玩家发现后可以让两份饭都有合理借口送到，不必播放公开感谢的过场。

<a id="c15"></a>

## C15｜没有恶意的冒名者

[查看实现思路](../09-实现规划/10-人物种子.md#c15)

它模仿你，是因为只有你的身份能进入学校、买东西、租房。你可以争夺身份，也可以帮助它获得被承认的名字。模仿带来的损害仍需要处理。

<a id="c16"></a>

## C16｜记得每次失败的售票员

[查看实现思路](../09-实现规划/10-人物种子.md#c16)

他不会预言，只在你回头时知道你又经历了什么。他从不讲大道理，偶尔把找零换成一颗糖。直到某次你成功，他第一次不知道该收多少钱。
