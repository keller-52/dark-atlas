# 不靠加速的追逐

<a id="h01"></a>

## H01｜它只会走你的旧路

[查看实现思路](../09-实现规划/05-追逐.md#h01)

追逐者沿着玩家留下的足迹前进。原路返回危险，陌生区域暂时安全。你可以绕行、断开痕迹，也可以提前设计一条让它兜圈的路。

变化重点是路径结构，不是速度越来越快。足迹寿命与跳跃规则必须一致，玩家才会相信自己的计划。

<a id="h02"></a>

## H02｜它追的是你的目的地

[查看实现思路](../09-实现规划/05-追逐.md#h02)

它不会跟踪脚步，而会试图猜出你要去哪里，提前守候。你暴露的线索包括携带的物品、反复查看的地标、启动过的装置。

你可以先表现出另一个目标。系统必须只使用可解释的信息，不能直接读取任务标记后宣称自己很聪明。让玩家看到它判断错误，会很有满足感。

<a id="h03"></a>

## H03｜它听得见你命名

[查看实现思路](../09-实现规划/05-追逐.md#h03)

给房间写名字会吸引一种以名字为食的东西。无名区域安全，却难以交流；你可以给假地点起响亮名字，替真正的避难所取很普通的称呼。

这是一种信息战。不要要求玩家完全不用标记，给私人符号和公开名称明确区别。

<a id="h04"></a>

## H04｜它会学，但也会误学

[查看实现思路](../09-实现规划/05-追逐.md#h04)

你连续躲在柜子里，它开始检查柜子；你连续用钟声诱敌，它开始绕开钟塔。更有趣的是，玩家可以有意训练它相信错误规律。

学习需要少数清楚的行为类别与可见迹象。无边界的自适应只会让人觉得作弊；玩家应该能预测、利用并重新教它。

<a id="h05"></a>

## H05｜它是来救你的

[查看实现思路](../09-实现规划/05-追逐.md#h05)

救援员会带你离开危险区，但你还要找一个人、取一件证物或完成约定。被抓住不是死亡，而是被送回安全地带，并失去一个时间窗口。

你既可以躲避，也可以让它帮忙破门、救别人。别把救援员写成无理由的恶人；冲突来自目标不一致。

<a id="h06"></a>

## H06｜你必须带它走

[查看实现思路](../09-实现规划/05-追逐.md#h06)

追逐者是唯一能撞开某些门、驱散某种雾的存在。你不能甩得太远，也不能让它贴近。跑动变成保持距离、安排路线、保护沿途居民。

后面允许用环境接力，把持续紧张拆成几个阶段。避免全程“牵狗跑图”，给它暂时安定或愿意协作的时刻。

<a id="h07"></a>

## H07｜它只在你确信安全时行动

[查看实现思路](../09-实现规划/05-追逐.md#h07)

世界里有一种以“封闭、无人、完全安静”为栖息条件的生物。你以为的标准躲藏点，正是它喜欢的地方；留一条缝、保持轻微响动，反而能防它。

不要读取玩家心理。把所谓确信翻译成可观察的环境条件，玩家学会后就能主动准备安全点。

<a id="h08"></a>

## H08｜你们在追同一个人

[查看实现思路](../09-实现规划/05-追逐.md#h08)

怪物的目标并不是你。你可以抢先找到目标，也可以跟着怪物寻找踪迹，甚至在某些时刻替它开路，以换取更远处的线索。

关系不必永远敌对。最好的变化是发现目标有自己的意愿，并不一定希望被任何一方找到。

<a id="h09"></a>

## H09｜追逐发生在地图上

[查看实现思路](../09-实现规划/05-追逐.md#h09)

身体暂时安全，但纸面上有一个黑点沿着你画出的路线靠近某个名字。你通过折纸、改路、涂掉连接拖延它，现实中则去寻找地图之外的解法。

两个层面的压力互相影响。给玩家暂停整理的机会，否则会变成一边操作界面一边看不见现场的手忙脚乱。

<a id="h10"></a>

## H10｜它怕你停下来听它说话

[查看实现思路](../09-实现规划/05-追逐.md#h10)

追逐者靠不断被逃避来维持形态。某些安全地点允许你停下，听完它的一小段话，追逐范围便会缩小。你要分辨真正在求助的片段与诱导。

危险不是单靠站住就解除：停留地点、距离和前置观察都重要。别把解决所有创伤简化成听几句台词；理解可以改变关系，不一定立刻治愈。
