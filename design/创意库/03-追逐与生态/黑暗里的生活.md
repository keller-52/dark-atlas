# 黑暗里的生活

<a id="e01"></a>

## E01｜灯光也会过度捕捞

[查看实现思路](../09-实现规划/06-生态.md#e01)

灯会吸引发光虫，虫会吸引捕食者，某种植物却因此停止开花。一路把灯点满能方便自己，也会改变整个区域的夜间生活。

玩家可以做遮光罩、调时段、留下暗道。核心是安排照明，不是把“用灯”判为坏事；人类也确实需要看得见。

<a id="e02"></a>

## E02｜黑暗是需要保护的栖息地

[查看实现思路](../09-实现规划/06-生态.md#e02)

有些温和生物只能生活在未被直视的区域。你通过留下食物、听回应、观察第二天的变化与它们相处。看清它们反而不是奖励。

玩家会学会尊重未知。可以让它们在你走过后修补地板，却始终不露脸；不要最后一定用怪物图鉴把神秘感收干净。

<a id="e03"></a>

## E03｜道路需要休息

[查看实现思路](../09-实现规划/06-生态.md#e03)

被频繁使用的路会疲劳，出现裂纹、低沉响声和弯曲；长期无人走的路则会生长。你安排轮换路线，城市也因此形成不同节律。

适合有据点与居民的游戏。必须有批量交通安排和明确提示，不要让玩家反复绕路只为了照顾一条耐久条。

<a id="e04"></a>

## E04｜你种的不是资源，是路标

[查看实现思路](../09-实现规划/06-生态.md#e04)

不同植物朝水、风或人的声音生长。你沿途种下它们，几小时后能读懂区域流向，也能让后来的人找到路。

植物还会被居民挪走装饰家，产生小故事。别塞入大量采集配方，关注种植位置与长期变化。

<a id="e05"></a>

## E05｜洪水不是灾难倒计时

[查看实现思路](../09-实现规划/06-生态.md#e05)

水上涨会封住地面，同时打开船道、让漂浮房屋靠岸、把深井里的东西送上来。退水也有自己的机会。玩家在不同水位重新认识同一区域。

让等待成为有效选择，并允许查看可预期水位。否则错过窗口后的空等会迅速耗尽耐心。

<a id="e06"></a>

## E06｜一座城在睡觉

[查看实现思路](../09-实现规划/06-生态.md#e06)

建筑是一个巨大生物的身体。道路随呼吸张合，广场是皮肤上的温暖处，地铁像缓慢的循环系统。玩家逐渐理解它的不适，能疏通、安抚或唤醒它。

它可以只是生病，而不是最后必打的巨型怪物。尺度变化要让日常探索受益，别全靠远景奇观。

<a id="e07"></a>

## E07｜怪物之间有礼貌

[查看实现思路](../09-实现规划/06-生态.md#e07)

不同生物遵守路权：小者先过、带幼崽者优先、某种鸣叫代表借道。玩家学会之后可以安全穿行，甚至借它们的礼仪解决堵塞。

这是观察与参与，不是找弱点打死。保持少量清楚习俗，允许犯一次小错后补救，不把文化学习做成秒杀陷阱。

<a id="e08"></a>

## E08｜天气会搬动秘密

[查看实现思路](../09-实现规划/06-生态.md#e08)

雾把声音带到远处，霜复制门把手上的指纹，风暴把不同地区的气味混在一起。同一线索在不同天气下能读到不同部分。

玩家可以选择何时出门，不必刷随机天气。提供预测、局部人工影响或可等待的日程。

<a id="e09"></a>

## E09｜你留下的东西成为别人的工具

[查看实现思路](../09-实现规划/06-生态.md#e09)

弃置的梯子被店主当货架，旧灯被孩子拿去捕虫，绳子变成晾衣线。回访时你发现自己的痕迹已经进入别人的日常。

这能让世界显得有生活，而不需要大量剧情过场。涉及关键解谜物时要可追踪、可协商，不能用“活世界”当丢钥匙的借口。

<a id="e10"></a>

## E10｜地图上有迁徙的街区

[查看实现思路](../09-实现规划/06-生态.md#e10)

市场、学校和澡堂都随季节移动。你记住的是相遇规律与约定的地标，不是永久坐标。错过一家店，可能在别处遇见它的顾客。

适合温暖、轻喜剧或公路片气质。给移动带来新组合，而不是每天花时间找同一个商人。
