# 点子之间怎样产生反应

两个机制同时存在，不等于它们真的组合了。下面每组都要能回答：加入第二个以后，玩家的决定有什么变化？

| 组合 | 会出现的新判断 | 可玩的场面 | 注意什么 |
| --- | --- | --- | --- |
| G02 声音探路＋H01 足迹追逐 | 不只问哪里有路，还问该把声音留在哪条旧路 | 把声源送进旧回廊，自己开辟新路 | 追逐者究竟追足迹还是声音，优先级要清楚 |
| M01 旧地图＋E05 潮汐 | 地图没错，只是记录了另一个水位 | 用旧水线推断水下门的位置 | 提供水位参照，避免随机失效 |
| M08 共绘地图＋T03 微小改动 | 无法直接告诉对方全部答案，必须建立表达习惯 | 用三把椅子的位置表示不同危险 | 协议建立后不要无故让对方忘记 |
| G07 光固定现实＋S10 剧场 | 灯既是空间工具，也是演出秩序 | 移动追光，让演员走入未写好的后台 | 不用频繁黑屏制造难度 |
| R01 活房子＋S05 重量楼层 | 家具既是家，也影响旅行能力 | 为了渡过低桥，决定哪些东西暂时寄存 | 不要每次旅行都清空家园 |
| M04 公开地图＋E09 物品流转 | 路线发布以后，世界会自行使用你的成果 | 梯子成了街区共享设施，回程更方便 | 给影响留下可追踪来源 |
| H04 学习敌人＋G04 热痕 | 玩家能主动制造错误经验 | 连续加热一把空椅子，让它误判等待点 | 学习只覆盖少量可理解规律 |
| R03 教人认路＋T08 人物接力 | 上一位角色的教学决定下一位可得到的帮助 | 新角色被你以前救过的人带出黑暗 | 不把之前没教过变成无法通关 |
| E02 暗处生物＋M05 自愿留白 | 不记录既保护居民，也保护生态 | 用触觉路标引导居民，不做公开照明 | 必须仍有可用导航方案 |
| S02 身份门＋N07 身份误认 | 借用身份能走新路，却会接到不属于你的责任 | 门内的人请你继续一项你不懂的工作 | 给退出和说明的机会 |
| T04 借未来＋R02 同伴自主 | 借用别人的未来帮助，需要征得对方合作 | 桥已出现，修桥人却想离开城市 | 不把同伴拒绝直接当惩罚 |
| E07 生物礼仪＋P10 巨大主角 | 体型优势不等于通行权 | 你给更小的动物让路，其他生物才放行 | 礼仪有线索，可重新尝试 |
| G05 气味＋E10 迁徙市场 | 找地方变成寻找生活规律 | 跟着烘面包的气味追上搬迁的街区 | 不要求玩家无休止寻找同一家店 |
| S01 关系空间＋R10 告别 | 关系变化会关掉旧捷径，也打开新连接 | 同伴搬家后，两人仍保留一条约定路线 | 分离不自动等于关系恶化 |
| M06 折纸＋H09 纸面追逐 | 折地图既能救人，也可能把危险折近 | 临时折叠公共区域，给某个名字腾出时间 | 让折叠后关系可预览 |
| G09 共同见证＋N02 历史记录 | 谁来现场会影响哪些证据稳定下来 | 邀请互相不信任的人共同确认一间房 | 不把真相完全等同多数票 |

## 六组暂时别硬拼

**任意改图＋所有路线都很重要。**如果随手画门就能解决一切，足迹规划会失去价值。可以限制改图只在特定区域发生，或直接选其中一套为主。

**自由回溯＋很重的永久后果。**要么承认回溯能修正，让乐趣放在安排；要么明确哪些东西跨回溯保留。不要到剧情高潮才突然宣布这次不能重来。

**频繁追逐＋精细阅读语言。**玩家没有余裕观察字形和验证猜测。把研究区域与压力区域错开，让学到的语言在追逐中以简单方式应用。

**会学习的敌人＋不断变化的地图＋隐藏规则。**三种不确定性同时叠加，很难知道自己为什么失败。至少让两项保持稳定，并给第三项清楚反馈。

**有限地图容量＋强依赖记忆的剧情。**如果玩家为了下一关必须删掉前面的人物信息，容易把感情变成存储管理。路线数据与人物记录可以分开保存。

**温暖陪伴＋必然牺牲的所有同伴。**玩家很快就会防备每个友善角色。让一些关系平安延续，损失才不会变成套路。

## 三种有节制的混合方案

### 轻悬疑：共绘地图＋城市日常

主线用 M08 与 T03，支线用送饭、修门和邻里关系。谜题之外仍然有人值得联系，紧张来自某天笔迹停了，而不是每晚都有怪物。

### 紧张探索：旧地图＋足迹追逐＋可靠据点

主线用 M01、H01，安全屋只提供休息与生活，不再增加独立养成系统。玩家交替经历未知、理解、掌握和放松。

### 古怪旅行：活房子＋迁徙街区＋陌生礼仪

主线用 R01、E10、E07。不需要地图失效、时间回溯和巨大阴谋；旅途中新地方的生活方式已经能提供变化。
