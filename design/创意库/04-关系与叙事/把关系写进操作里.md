# 把关系写进操作里

<a id="r01"></a>

## R01｜会走路的安全屋

[查看实现思路](../09-实现规划/07-关系.md#r01)

一座小屋缓慢跟随你，提供休息，也会害怕某些地方。你带回燃料和故事，它学着照顾你。你很久不回来，它可能离开安全地带找你。

关系发生在日常动作里：修门、给它找一块平地、等它跟上。不要用饥饿条迫使玩家定时喂房子；陪伴应有自主性，而不是电子宠物的惩罚。

<a id="r02"></a>

## R02｜同伴有权不跟你走

[查看实现思路](../09-实现规划/07-关系.md#r02)

同伴会说明自己害怕什么、想去哪里。你可以改变路线、找替代办法或独自前进。强行带走不应该是默认交互。

合作的乐趣是找到双方都能接受的路。让拒绝提供新信息和新选择，别只弹一句“好感不足”。

<a id="r03"></a>

## R03｜你教别人认路

[查看实现思路](../09-实现规划/07-关系.md#r03)

你亲自带一个人走一次，以后他能独立完成这段路。教法影响他记住什么：靠地标、靠声音，还是靠你摆下的东西。

后面你受伤，由他带你回去。教学不必变成重复护送，可以通过几处关键停留与选择完成；他也可能发现你没注意到的捷径。

<a id="r04"></a>

## R04｜灯要交给谁

[查看实现思路](../09-实现规划/07-关系.md#r04)

你和同伴共用一盏灯。拿灯的人看得清，却也更容易被发现；另一个人能潜行，却必须依靠信号。交灯改变双方角色。

游戏应让两种位置都值得体验。别把同伴变成永远完美的灯架，偶尔的请求和迟疑才能让交接像信任。

<a id="r05"></a>

## R05｜怪物不懂你的礼物

[查看实现思路](../09-实现规划/07-关系.md#r05)

你送食物，它认为你想圈养它；你放下武器，它以为你在求保护。建立关系需要观察对方自己的交换方式。

可以把一段陌生生物外交做成独立区域。避免所有误解都惩罚玩家，让对方也努力理解你，关系才是双向的。

<a id="r06"></a>

## R06｜每次回来，饭桌上多一个位置

[查看实现思路](../09-实现规划/07-关系.md#r06)

你帮助过的人会陆续来据点。不是站成一排卖道具，而是在一起吃饭、争吵、修东西，偶尔替你完成一件小事。

据点变化给探索以回声。允许有人不留下、有人离开后仍保持联系；收集全部居民不应该等于最佳结局。

<a id="r07"></a>

## R07｜你帮人藏起来

[查看实现思路](../09-实现规划/07-关系.md#r07)

任务目标不是找到某人，而是保证他不被找到。你改掉路牌、安排备用住所、给可信的人留下暗号，还要考虑他愿不愿意一直隐藏。

这里能形成很不一样的探索：你越了解城市，越有能力制造安全的空白。别把被保护者当行李，让他参与计划。

<a id="r08"></a>

## R08｜同行者记得另一个版本的你

[查看实现思路](../09-实现规划/07-关系.md#r08)

每个同伴都认识不同阶段的主角。有人信任你，有人怕你，有人仍把你当孩子。他们的记忆影响愿意替你打开哪些门。

你不必找出唯一正确的自我，可以用眼下的行动重新建立关系。不要把人格写成几根善恶进度条。

<a id="r09"></a>

## R09｜你要学会接受照顾

[查看实现思路](../09-实现规划/07-关系.md#r09)

主角习惯独自解决问题，但某些路只有受伤、疲惫或主动承认不知道时，别人才能提供新的帮助。接受帮助打开不同体验，不必给予更高分。

必须避免奖励故意受伤。主动求助、把地图交给别人也能触发，重点是改变关系中的位置。

<a id="r10"></a>

## R10｜告别是一条可以走完的路

[查看实现思路](../09-实现规划/07-关系.md#r10)

同伴有自己的目的地。你可以陪他走最后一段，交接物品，约定通信，然后继续旅行。离队不一定意味着背叛、牺牲或永久消失。

以后路过时，能看见他开始的新生活。给玩家一段可自由停留的告别，比忽然播放煽情过场更容易留下感觉。
