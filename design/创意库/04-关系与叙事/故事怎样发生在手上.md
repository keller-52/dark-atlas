# 故事怎样发生在手上

<a id="n01"></a>

## N01｜习惯先于自白

[查看实现思路](../09-实现规划/08-叙事.md#n01)

主角下意识绕开某块地砖、在门口脱鞋、替一个空座位摆杯子。玩家先学会这些动作有实际作用，之后才知道它们来自谁。

故事不是找到一封信后突然增加，而是给熟悉操作换了含义。别让所有习惯都来自创伤，也可以来自幸福。

<a id="n02"></a>

## N02｜你决定什么进入历史

[查看实现思路](../09-实现规划/08-叙事.md#n02)

调查结束后，只能提交有限的证据。你选的是关于一个地方的叙述：这里发生过事故，也曾经有人互相照顾。不同提交方式会影响后来者的行动。

不要让取舍只等于隐瞒罪行。资料篇幅、证据可靠性与当事人隐私，都可以形成更细的选择。

<a id="n03"></a>

## N03｜反派会做与你一样的操作

[查看实现思路](../09-实现规划/08-叙事.md#n03)

你会涂改地图，对方也会；你靠点灯固定房间，对方也能熄灯。对抗来自同一规则下的不同目的。

玩家能从行动推断对方计划，而不必听反派解释。对方必须受同样限制，剧情不能临时给他无限能力。

<a id="n04"></a>

## N04｜缺席的人通过维修被认识

[查看实现思路](../09-实现规划/08-叙事.md#n04)

你修一扇门，发现前任维修者用过同样笨拙的方法；后来知道那是他给孩子留的低门闩。物品的做法揭示人的生活。

这适合低台词叙事。维修要能改变实际使用方式，不只是按住按钮播放回忆。

<a id="n05"></a>

## N05｜日记承认你没弄懂

[查看实现思路](../09-实现规划/08-叙事.md#n05)

记录保留你的猜测、证据和疑问，而不是自动写出正确答案。你可以修订，也可以暂时搁置。某些错误猜测仍然能导向有趣探索。

把推理过程留给玩家。不要事后偷偷改掉旧文字；划线、添注会更诚实，也更有人味。

<a id="n06"></a>

## N06｜真相不改变事实，改变责任

[查看实现思路](../09-实现规划/08-叙事.md#n06)

桥确实是你炸的，人确实受了伤。新线索不会洗白这些事实，只会让你理解当时还有哪些选择，以及谁承担了什么。

结局落在修复、承担或拒绝继续，而不是一句“其实你是好人”。同时保留角色的幽默和日常，别让每个人都像在法庭陈述。

<a id="n07"></a>

## N07｜城市误把你当成另一个人

[查看实现思路](../09-实现规划/08-叙事.md#n07)

旧系统认识你的钥匙、步态或姓氏，不认识你本人。你因此获得便利，也继承了别人的债与期待。是否解释清楚，会改变路线与关系。

身份误认可以产生轻喜剧，不必永远通向惊天身世。允许某些人很早就看穿，却选择暂时帮你。

<a id="n08"></a>

## N08｜结局是一种持续的做法

[查看实现思路](../09-实现规划/08-叙事.md#n08)

最后没有三扇颜色不同的门。你一直公开的路线构成了新交通网，一直隐藏的房间成为避难所，一直照顾的生物改变了城市的夜晚。

结局展示行为累积出的生活。给玩家中途看见影响、修正方向的机会，不要用隐藏总分结算道德。

<a id="n09"></a>

## N09｜第二次玩时，你是别人的路人

[查看实现思路](../09-实现规划/08-叙事.md#n09)

重玩换一个小角色，从旁边经过上一轮的重要场面。第一次觉得空无一人的走廊，其实有人在门后帮你扶住了梯子。

新增的是视角与行动，不是多几份日志。别要求必须二周目才获得完整结局；第一遍要自足。

<a id="n10"></a>

## N10｜有些谜可以不拆穿

[查看实现思路](../09-实现规划/08-叙事.md#n10)

一个人每天给无人居住的房间送饭。你可以调查、询问，也可以只帮他把屋檐修好。两种参与都能产生完整的小故事。

允许玩家保留未知，是黑暗探索很适合的一种温柔。保留未知不等于谜题没写答案；创作者仍需要知道行为的因果。
