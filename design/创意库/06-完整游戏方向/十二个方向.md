# 十二个可以单独成为游戏的方向

这里先谈“玩起来像什么”，暂时不谈引擎和工期。每个方向只抓几个互相有反应的点子，其余先放下。

<a id="p01"></a>

## P01｜《不要相信回来的路》

[查看实现思路](../09-实现规划/11-完整方向.md#p01)

你进入一座缓慢变动的地下城市。地图记录过去，脚步留下可被追踪的痕迹，声音既帮助探路，也会把东西引过来。

玩家反复做的事情是：从可靠地标出发，探出一小块区域，留下自己的路线，再决定是否冒险利用旧路返回。越熟悉地形，越能设计追逐者的行进方式。中段开始允许放置声源，后段让玩家主动带着追逐者穿越自己规划的路线。

它的招牌不是视野小，而是回程有历史。昨天的捷径今天仍然能用，但你知道谁也可能知道它。

剧情可以围绕一名失踪制图师展开，见 W01 的部分关系思路。适合 G02、M01、H01。先不要加入地图改写现实和无限回溯，它们会削弱路线本身的分量。

最容易腻：重复试探每个岔路。需要让已理解的区域快速通行，只有重要变化值得重新确认。

<a id="p02"></a>

## P02｜《另一端的笔迹》

[查看实现思路](../09-实现规划/11-完整方向.md#p02)

你与过去的陌生人共用一张地图，双方都是不可靠但愿意努力的伙伴。探索为了寻找可以给对方用的信息，对方的日常又改变你所在的废墟。

一次典型体验可能是：发现一条被树根堵住的排水道，告诉过去的人换个地方种树，再回到这里看变化。可随着关系深入，你会开始考虑那棵树对他意味着什么，而不只是把过去当作编辑器。

前期建立共同符号，中期共同完成一件小事，后期处理双方利益冲突。地图上的停顿、涂改和犹豫，都能承载人物性格。

适合 M08、T03、N05、W03。全程单机，另一端由预写剧情和状态逻辑驱动。不要默认需要真实玩家或生成式聊天。

最容易腻：每个谜题都“改过去、看现在”。有些段落只交流，有些要你去现场判断，有些让对方独立完成并向你报告。

<a id="p03"></a>

## P03｜《房子想回家》

[查看实现思路](../09-实现规划/11-完整方向.md#p03)

你与一间会移动的小屋旅行。外出探索得到的东西，既能解决前方问题，也改变共同生活：一扇更轻的门、一副挡雨的檐、一条房子喜欢的地毯。

路线选择同时考虑你和房子。你能穿过的窄桥，它过不去；它能趟过的浅水，你走不了。你们需要暂时分开，也需要决定在哪里等对方。

长期变化来自互相了解：早期你把它当交通工具，中期开始争执，后期能提前为彼此做安排。它不是装着储物箱的坐骑。

适合 R01、S04、E10、W04。气质可以温暖又有一点古怪。追逐只偶尔出现，不需要一只常驻怪物压住所有日常。

最容易腻：反复找燃料和等房子走过来。常规补给应简化，旅行中的选择放在目的地和相处方式上。

<a id="p04"></a>

## P04｜《请勿登记》

[查看实现思路](../09-实现规划/11-完整方向.md#p04)

你是城市制图员，工作是让黑暗区域重新进入公共地图。每提交一块地形，就有人获得便利，也有人失去藏身空间。

探索包含拜访、核实路线、对照居民证词，再决定哪些内容进入哪一版地图。不是所有选择都有坏结果：你认真画出轮椅能过的路线，就真的有人能第一次去市场。

中段引入不同地图读者，后段让你协助建立由居民维护的版本。玩法的成长是从“我来替他们画”，变成“我怎样把绘制权交回去”。

适合 M04、M05、M09、R07、W01。可以用轻微荒诞的文书制度承载压力，不需要密集战斗。

最容易腻：每区都是同一种隐私两难。加入纯粹的技术难题、居民合作和令人高兴的工程成果。

<a id="p05"></a>

## P05｜《夜间饲养员》

[查看实现思路](../09-实现规划/11-完整方向.md#p05)

你照料一座不能完全照亮的动物园。白天整理痕迹，夜里送食物、修围栏、观察反应。动物通过习性被认识，不通过完整模型被收集。

最初你照手册工作，后来发现手册过时：某种动物根本不爱独居，另一个被误认为攻击的动作其实是在让路。你重新安排空间，园区会逐渐形成自己的秩序。

新鲜感来自关系的进展，而不是不断增加新物种。熟悉的动物也能因幼崽、迁徙、邻居变化而提供新问题。

适合 E02、E07、G02、R05、W06。不要把最终目标做成点亮整个园区；保留黑暗可以是熟练的表现。

最容易腻：工作模拟的日常重复。完成理解之后允许安排自动照料，把注意力转向异常和新关系。

<a id="p06"></a>

## P06｜《借来的明天》

[查看实现思路](../09-实现规划/11-完整方向.md#p06)

你能短暂借用未来的成果：修好的桥、长大的树、已经送达的物品。为了让借来的东西成立，你必须在后来补足过程。

核心体验是先获得便利，再想办法履约。一个选择会改变后续路线：借桥让你提前进入新区域，却也让你需要认识会修桥的人、找到材料或者建立替代的因果链。

前期只有一笔清楚的欠账，中期允许几条因果互相帮忙，后期让玩家选择不再借用，踏踏实实把一段路修好。

适合 T04、T02、R03。故事可以是重建一座即将被放弃的城。别把未来当成无穷无尽的资源商店。

最容易腻：记账负担。把欠账表现为具体地点和人物，允许查看清楚的因果图，避免大量不同倒计时。

<a id="p07"></a>

## P07｜《给下一位留一盏灯》

[查看实现思路](../09-实现规划/11-完整方向.md#p07)

你依次扮演进入迷宫的不同人。每个人的身体、目标和能做的事情不同。前一位留下的路，可能是后一位出发时唯一的依靠。

一段旅程不是必须以死亡结束，也可以是留下工作、决定定居、找到自己的目的地。新角色遇见旧角色时，之前的行为变成现实关系。

开始你为自己修路，中段意识到某些成果只能由别人使用，最后用一个没有特殊能力的角色走完大家留下的路线。

适合 T08、R03、E09、N09。它的重点是接力，不是肉鸽式永久加点。

最容易腻：每次换人重学操作、重跑开局。保留公共基础操作，让角色差别集中在一种有意思的能力和一种不同愿望。

<a id="p08"></a>

## P08｜《末班车不去终点》

[查看实现思路](../09-实现规划/11-完整方向.md#p08)

你在黑暗里开一辆夜班车，路由乘客的目的地和记忆共同生成。站点会出现，也会因为没人再去而消失。

每晚决定顺序、绕行和停留。你可以下车确认陌生路段，也能听乘客指路。有人方向感很差，有人不愿解释为什么不走那条街。

前期认识人，中期让乘客彼此发生联系，后期逐渐建立不再完全依赖你的夜间网络。地图是这些关系长出的形状。

适合 S01、S03、E10、R10、W05。驾驶可以宽松，真正的判断放在谁先到、谁愿意一起走。

最容易腻：重复听长对话。支持安静乘车，重要信息用自然重提和可查看记录补足，不强迫每晚听全。

<a id="p09"></a>

## P09｜《世界尚未命名》

[查看实现思路](../09-实现规划/11-完整方向.md#p09)

你来到一个没有共同语言的地方。符号、门的称谓、让路的动作，都是可探索的规则。名字会改变人们理解地点的方式，也改变部分道路。

玩家观察相似情境，提出词义猜测，再用行动验证。能走的地方越来越多，不因为背包里多了十把钥匙，而因为你终于懂得怎样提出请求。

中段发现不同社群对同一词的理解不同，后段可以帮他们建立新约定。你不是把一切翻译成唯一标准，而是在学会相处。

适合 M10、S02、E07、N05。可使用图形语法与可编辑词典，不依赖打字猜口令。

最容易腻：做填字题、查字典。词义应该改变实际行动，让同一句话在不同生活场景里产生用途。

<a id="p10"></a>

## P10｜《你看起来很吓人》

[查看实现思路](../09-实现规划/11-完整方向.md#p10)

你是巨大而笨拙的生物，想找到一处能住的地方。人们怕你，你的脚步会震塌旧桥，伸手帮忙可能被误解为攻击。

玩家学习停在合适距离、放低身体、先示意、留下退路。你仍然有能力推倒障碍，但越来越懂得什么时候不该直接动手。

关系发展应双向：有人逐渐学会你的信号，也有人需要帮助你理解自己的力量。最后不是变成人才得到接纳，而是形成能共同生活的空间。

适合 G08、R05、R02、E07。允许尴尬和喜剧，不把“我是怪物”只留作最后反转。

最容易腻：每个居民都先尖叫再感动。不同人从不同态度开始，包含熟悉你的人、利用你的人和毫不在意的孩子。

<a id="p11"></a>

## P11｜《演出不能中断》

[查看实现思路](../09-实现规划/11-完整方向.md#p11)

你穿行于一座不断重演同一晚的剧场。舞台是被光固定的世界，后台保留上一轮的痕迹。你通过道具、音效和出入顺序改变事件。

前期保证戏演完，中期用偏差救下一次事故，后期发现某些演员根本不想继续扮演原来的角色。你必须替他们创造即兴的空间。

玩法有两种节奏：演出中临场处理，演出间慢慢观察和布置。失败也能产生新台词、新误会和可利用的痕迹。

适合 S10、G07、T01、W07。不要每次重置所有准备，保留后台调整，减少无效重复。

最容易腻：背固定流程。给关键场面几种可行处理，让演员会对异常做有限但清楚的反应。

<a id="p12"></a>

## P12｜《今晚谁来敲门》

[查看实现思路](../09-实现规划/11-完整方向.md#p12)

你在一座被黑暗隔开的城市送饭。保温箱的热、食物的气味和你记下的住户习惯，构成整套探索工具。

路上遇到的不只是障碍：怕人的动物会被香味引出，孤独的人会多留你几分钟，居民开始把要送往下一家的东西交给你。

最初你追求准时，后来学会安排互助；最后你不用亲自跑完每条路，仍然有人能吃上热饭。成长来自城市逐渐接上联系。

适合 G04、G05、R03、R06、W08。可以有紧张夜晚，也应有毫无意外的一次顺利配送。

最容易腻：订单刷量和评分压力。不用五星排行榜驱动全部体验，把新关系、城市变化与偶发小事作为继续走下去的理由。
