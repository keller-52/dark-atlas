# 再往外走二十步

如果不想让“黑地图”限制想象，这里是二十个更远的岔路。它们还只是种子，有的适合短篇，有的也许只值得保留一个场面。

<a id="x01"></a>

## X01｜迷宫维修工

[查看实现思路](../09-实现规划/13-延伸构思.md#x01)

英雄每天进来破门、搬箱子、杀怪，你负责夜里恢复设施。你逐渐发现有些“经典谜题”对这里的居民非常不方便，于是偷偷改造。乐趣来自理解冒险关卡在非冒险时段怎样运作，也来自让设计变得更好用。

它可以是喜剧。一个被迫每天守钥匙的骷髅，可能只想调班去看球。

<a id="x02"></a>

## X02｜为从没见过太阳的人设计清晨

[查看实现思路](../09-实现规划/13-延伸构思.md#x02)

你管理一座地下城的人工照明。用亮度、色温、声音和开门顺序，让不同街区拥有自己的晨昏。居民会对你编排的日常形成习惯，你逐渐意识到“适合所有人的一天”并不存在。

探索用于认识不同生活，不是采集电池。最终成果是一座能协商时间的城市。

<a id="x03"></a>

## X03｜藏猫猫冠军正在失去工作

[查看实现思路](../09-实现规划/13-延伸构思.md#x03)

整个城市热爱藏猫猫，但你找人太厉害，大家开始不愿与你玩。你要学会制造悬念、给对方机会、设计公平场地。胜利不再是最快抓到所有人，而是让大家还想再来一局。

它保留黑暗、路线与追逐，却把情绪转成玩心与社交判断。

<a id="x04"></a>

## X04｜侦探只调查没发生的事

[查看实现思路](../09-实现规划/13-延伸构思.md#x04)

一间房有打斗痕迹，却没人打过架；站台有人等车，列车从未存在。你调查的是被取消的历史如何留下残余，并决定哪些可能性需要真正发生一次才能安息。

玩家必须提出能解释多条痕迹的假设，不能只靠最终播片揭晓。失败的假设也可通过现场实验排除。

<a id="x05"></a>

## X05｜黑暗是一种公共交通

[查看实现思路](../09-实现规划/13-延伸构思.md#x05)

只要没人看见，物体就能沿暗区快速移动。居民用关灯运输家具、投递包裹。你负责规划暗路，兼顾安全、隐私和白天生活。

看似恐怖的规则成了市政服务。最有趣的麻烦可能只是有人深夜忘拉窗帘，堵住了整条货运线。

<a id="x06"></a>

## X06｜你是一座迷宫的园丁

[查看实现思路](../09-实现规划/13-延伸构思.md#x06)

道路会像枝条生长，岔路是分蘖，出口是开花。你修剪不是为了让所有人最短通关，而是照顾不同访客：散步者想绕远，赶路人需要直达，害怕的人想看见退路。

真正的反馈是人怎样使用空间，不是迷宫复杂度评分。

<a id="x07"></a>

## X07｜拍不到东西的摄影师

[查看实现思路](../09-实现规划/13-延伸构思.md#x07)

相机只能拍到场景里被忽略的东西。肉眼越关注某个对象，照片越容易空白。你通过调整他人的注意、改变自己的观察方式，寻找一座城市不愿面对的细节。

规则需要落实为可观察的关注状态，不要要求系统读取玩家真实心理。它适合调查与艺术感强的短篇。

<a id="x08"></a>

## X08｜怪物保险调查员

[查看实现思路](../09-实现规划/13-延伸构思.md#x08)

居民申报“房屋被巨兽吞了一半”，你得去现场确定究竟是事故、迁徙，还是房子主动离家出走。证据可能来自牙印、路权和邻居的借条。

荒诞世界也有平常的利益冲突。不要把每个案件都写成骗保，认真帮助被误解的申请人同样有趣。

<a id="x09"></a>

## X09｜没有人需要你拯救的末日

[查看实现思路](../09-实现规划/13-延伸构思.md#x09)

灾难很久以前就过去了，居民已经建立新生活。你带着旧时代的使命醒来，试图恢复一切，却发现旧出口现在是学校，旧能源核心成了温泉。

玩法围绕认识现状、调整目标和参与建设。主角最终可以放下英雄身份，找到一份普通工作。

<a id="x10"></a>

## X10｜路线是一首可以演奏的曲子

[查看实现思路](../09-实现规划/13-延伸构思.md#x10)

每次经过地标都会发出不同声部，你规划的路形成旋律。某些居民听旋律认路，某些门需要听见完整乐句才愿意打开。

它不必考验音游手速。允许预览、慢速与视觉节拍，让空间安排产生音乐，而不是给走路配一首背景曲。

<a id="x11"></a>

## X11｜家族聚会是一座迷宫

[查看实现思路](../09-实现规划/13-延伸构思.md#x11)

一栋屋子的连接由亲属间未解决的话题决定。你传菜、找椅子、陪人去阳台，逐渐打开对话的路。秘密不是奖品，有时不当众揭开才让人愿意继续说。

可以完全没有超自然敌人。玩家的难题是如何让一顿饭平安结束，同时不再假装什么都没发生。

<a id="x12"></a>

## X12｜你在教一座城市做梦

[查看实现思路](../09-实现规划/13-延伸构思.md#x12)

城市从居民白天的行动生成夜间空间。你不能直接选梦境，只能在白天创造材料：一次相遇、一场小雨、一条修好的路。夜里再进入梦中理解这些材料怎样被组合。

这是一种间接创作。居民的梦不该全部以你为中心，你只是参与者之一。

<a id="x13"></a>

## X13｜手提箱里的远征

[查看实现思路](../09-实现规划/13-延伸构思.md#x13)

你拖着一只箱子，每次打开，里面是一片正在缓慢扩展的地形。外界物品以不同尺度进入箱内：一根线变成桥，一滴水成为湖。你既探索内部，也选择带它去怎样的外部环境。

要给尺度变化稳定规则。吸引力在照顾一个可携带的小世界，不在无限制造物品配方。

<a id="x14"></a>

## X14｜你负责把怪谈讲错

[查看实现思路](../09-实现规划/13-延伸构思.md#x14)

城里的传说会照着人们讲述的版本成为现实。你通过戏剧、路边故事和孩子的游戏，把危险传说慢慢改成能相处的版本。

不能随便输入一句话就赢。新版本需要有可信的见证和传播路径，玩家既探索事实，也安排它如何被理解。

<a id="x15"></a>

## X15｜重力是地方口音

[查看实现思路](../09-实现规划/13-延伸构思.md#x15)

不同街区对“下面”的理解不同。你通过观察落雨、晾衣和走路姿势，学会当地的重力习惯。带来的物品还保留原乡重力，能够解决也能够制造问题。

新鲜点在日常生活与空间规则相互解释，避免变成连续眩晕的视觉机关展。

<a id="x16"></a>

## X16｜唯一的战斗动作是道歉

[查看实现思路](../09-实现规划/13-延伸构思.md#x16)

你误入一片对行为极其敏感的领域。踩影子、挡路、直视都可能引发冲突。你要确认自己冒犯了什么，再通过让路、归还、修复或合适的表达结束争执。

“道歉”必须包含具体行动，也允许拒绝不合理要求。它不是对所有敌人按同一个安抚键。

<a id="x17"></a>

## X17｜游戏会逐渐把地图交还给你

[查看实现思路](../09-实现规划/13-延伸构思.md#x17)

开场地图准确、路线明确，像一份完整旅游指南。随着探索，你发现指南遗漏了生活里的细节，开始主动遮去推荐路线，画出自己的版本。

成长方向与常见开图相反：从被安排得很清楚，到有能力承受未知。不是强制删功能，而是让玩家选择怎样看世界。

<a id="x18"></a>

## X18｜你是别人的隐藏路线

[查看实现思路](../09-实现规划/13-延伸构思.md#x18)

你扮演建筑里一个不起眼的维修生物，只能在墙内通行。外面的冒险者不知道你存在，你通过搬动门闩、疏通管道和送出声音，让他们完成旅程。

你也有自己的日常目标，不必始终无私。最后可以让他们发现你，也可以继续过安静生活。

<a id="x19"></a>

## X19｜旅馆接待互不相容的客人

[查看实现思路](../09-实现规划/13-延伸构思.md#x19)

怕光的、怕静的、逆时间睡觉的、梦里会长大的客人同时入住。你探索扩展中的旅馆，安排房间连接、公共区域与作息。

问题可以有多个舒服的解法，而不是只找一套精确排布。每位客人需要个性，否则容易变成换皮数独。

<a id="x20"></a>

## X20｜终点是把迷宫交出去

[查看实现思路](../09-实现规划/13-延伸构思.md#x20)

你先亲自探索，后来修缮、解释、教学，最终让一个从没玩过这套规则的游戏内角色独自通过。你只能看见他留下的简短记录，不能实时遥控。

最终考验不是玩家能否通关，而是能否把理解变成别人也能使用的帮助。允许对方发明新办法，他不必完整复刻你的路径。
