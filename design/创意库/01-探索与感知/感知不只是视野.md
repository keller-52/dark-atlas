# 感知不只是视野

<a id="g01"></a>

## G01｜借来的眼睛

[查看实现思路](../09-实现规划/01-感知.md#g01)

你可以把感知暂时交给一只动物。蛾子看见光的梯度，老鼠记得墙根与气味，鱼只理解相连的水。切换之后，不是同一张地图换滤镜，而是“什么算一条路”都变了。

有趣的判断是：我需要它带我到哪里，还是需要知道它为什么不愿意过去？后半程可以让两种动物提供互相矛盾的信息。别把它做成每道门前换一次工具；动物应有自己的路线，玩家也可以跟随、引导、等待。

<a id="g02"></a>

## G02｜声音先于形状

[查看实现思路](../09-实现规划/01-感知.md#g02)

敲墙得到厚度，投石得到距离，哼唱得到房间的回响。你先知道“这里很空”，再知道那里原来是礼堂。信息来自自己的试探，会比自动扫出轮廓更有参与感。

后来允许声音穿过管道和传送口，空间推断就能变复杂。不要要求玩家具备专业听音能力：给回声的视觉记录，重点放在判断，不放在耳朵测试。

<a id="g03"></a>

## G03｜阴影告诉你缺了什么

[查看实现思路](../09-实现规划/01-感知.md#g03)

物体本身不可见，影子却仍然存在。你绕着灯移动，从影子的变化猜出桌子、楼梯或一个站着的人。某些影子属于早已不存在的建筑。

最值得做的变化是移动光源，主动取得另一个角度。不要整段游戏都让玩家辨认模糊轮廓；看懂之后应有一段真正使用这些知识的路。

<a id="g04"></a>

## G04｜热是一封迟到的信

[查看实现思路](../09-实现规划/01-感知.md#g04)

你看得见温度。刚离开的椅子、有人摸过的扶手、熄灭不久的炉子，都能告诉你这里发生过什么。地形很普通，时间线却藏在温度里。

你可以给某处加热，伪造足迹，也可以守着一杯正在变凉的茶，判断主人离开多久。别把所有答案都染成发光颜色；让不同原因产生相似痕迹，给推理留位置。

<a id="g05"></a>

## G05｜先闻到家

[查看实现思路](../09-实现规划/01-感知.md#g05)

气味随着风、水和布料移动。玩家能把气味来源记录成粗略方向，却不能直接获得坐标。找到熟悉的饭香，有时是在回家，有时是在接近模仿家的人。

它适合慢节奏区域：改变通风、晾晒布料、堵住裂缝，重排气味的路径。表现上用文字、粒子或纹样辅助，不假装屏幕能真的传递气味。

<a id="g06"></a>

## G06｜只有闭眼才认得路

[查看实现思路](../09-实现规划/01-感知.md#g06)

闭眼以后，过去走过的地方会作为触觉记忆浮现。睁眼看到的是现在，闭眼走的是记忆。有些熟悉的路已经断了，所以不能一直闭着。

真正的选择在于什么时候相信熟悉感。可以让失明角色比主角更了解这座城市，但别把现实中的失明神秘化成超能力；这是世界规则，不是医学描述。

<a id="g07"></a>

## G07｜照亮也是作证

[查看实现思路](../09-实现规划/01-感知.md#g07)

光会把尚未确定的事固定下来。你照见桌上的信，就确认信存在；一直不照，信仍有可能被另一段历史替换。手电筒成了决定什么被世界承认的工具。

先用小事让玩家学会：照住摇摆的桥、确认门的朝向。后面再涉及人物命运。每次不可逆确认都要看得出分量，不能惩罚玩家正常观察。

<a id="g08"></a>

## G08｜你的身体是测量工具

[查看实现思路](../09-实现规划/01-感知.md#g08)

没有数字地图，你用步幅、呼吸、肩膀能否穿过来理解空间。背上一个人之后，你原本能过的缝隙不再能过；鞋底湿了之后，某种地面变得危险。

它让身体状态改变路线价值，而不只是改变血条。要避免逐步数格子的苦差事：允许打结的绳、墙上刻痕和自动记下的大致距离。

<a id="g09"></a>

## G09｜看见的人越多，真相越少

[查看实现思路](../09-实现规划/01-感知.md#g09)

独自观察时，一个房间同时存在几种可能；带上同伴，双方看到的交集才会稳定。不同同伴会固定不同细节，有人记得门，有人坚持那一直是窗。

带谁同行就是选择一种世界解释。别让同伴等于颜色钥匙；他们应该能争论、改变主意，也能被现场证据说服。

<a id="g10"></a>

## G10｜你听见的是将要发生的事

[查看实现思路](../09-实现规划/01-感知.md#g10)

雨还没下，屋顶已经响起雨声；门后先传来跌倒声，几秒后才有人跑进去。听觉给出短暂未来，视觉给出当下。

前期靠它避险，后期发现自己制造的声音也会提前泄露，于是可以通过安排未来的动作，给现在的自己发信号。保留清楚的时间范围，别让所有预告都变成随剧情解释的预言。
