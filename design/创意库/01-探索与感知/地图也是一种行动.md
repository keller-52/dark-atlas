# 地图也是一种行动

<a id="m01"></a>

## M01｜旧地图不会撒谎，只会过时

[查看实现思路](../09-实现规划/02-地图.md#m01)

地图准确记录你最后一次看见的样子。道路变化后，它不自动更新。不同年代的线条颜色和笔触有所区别，你能估计哪些地方值得复查。

这会让回程也有判断，但不能让所有路都随时失效。保留可靠地标，让玩家能规划风险，而不是每走一步都怀疑系统。

<a id="m02"></a>

## M02｜擦掉一条路，也擦掉一种追法

[查看实现思路](../09-实现规划/02-地图.md#m02)

某种东西只能读取你的地图。你擦去走廊，它就失去追踪线索，但你也失去精确导航。熟悉一片区域之后，主动不画图可能比全图更安全。

后面可让你制作一张故意有错的副本，留给它。它的知识来源必须明确，不能一边说只看地图，一边又隔墙知道你的坐标。

<a id="m03"></a>

## M03｜地图的纸不够了

[查看实现思路](../09-实现规划/02-地图.md#m03)

世界很大，纸张有限。你决定哪些地点用精确平面图，哪些只写“第三扇门左转”，哪些交给记忆。制图变成整理信息，而不只是填色。

适合给喜欢推理的人，也必须允许自动压缩低价值区域。不要靠限制标记数，强迫玩家拿手机拍屏幕。

<a id="m04"></a>

## M04｜公开地图会改变城市

[查看实现思路](../09-实现规划/02-地图.md#m04)

你可以把路线贴到公共告示板上。商贩沿着它来，救援也沿着它来，但猎手和征税者同样会来。画出一条路，是对那里的人施加影响。

这里的核心问题是“谁需要知道”。后面可以发布不同版本、使用只有居民懂的记号。避免每次善意都招来灾难；有些路真的会让生活变好。

<a id="m05"></a>

## M05｜地图上的空白是你留给别人的地方

[查看实现思路](../09-实现规划/02-地图.md#m05)

有些居民要求你不要记录他们的家。你仍可以亲自找到那里，但不能用自动导航或公共传送。留白是一种尊重，也带来实际不便。

可以让玩家用私人约定记路，比如门口不同方向的鞋。不要把不记录做成隐藏真结局的道德考试；应该看见具体的人和具体的风险。

<a id="m06"></a>

## M06｜折一下纸，两间房就靠近了

[查看实现思路](../09-实现规划/02-地图.md#m06)

地图能折叠，折痕两侧的地点会短暂相连。玩家不是随意画传送点，而是在考虑纸的形状、哪些区域会被压住、能不能把折痕带过去。

高级变化可以是正反面、湿纸、他人留下的折痕。重点在空间关系，不在模拟折纸软件；用少数清楚操作就够了。

<a id="m07"></a>

## M07｜地图记录的是承诺

[查看实现思路](../09-实现规划/02-地图.md#m07)

路径只有在你向某人承诺“我会从这里回来”之后才会稳定。违约的路线会慢慢模糊，但允许解释、延期和托人带话。

玩家实际在维护一张关系网。最有趣的不是到处接受任务，而是哪些承诺值得让自己绕远。不要把它变成密密麻麻的倒计时清单。

<a id="m08"></a>

## M08｜两个人画同一张纸

[查看实现思路](../09-实现规划/02-地图.md#m08)

另一个人的笔迹从远处出现。你们能交换标记、猜测和简单图形，却不能直接看到对方。对方由游戏内角色驱动，整个体验仍是离线单机。

当两张地形对不上时，先允许怀疑对方，之后再发现年代不同。给对方普通生活和偶尔的错误，别让他只是按时吐提示的导航软件。

<a id="m09"></a>

## M09｜地图是会被质疑的证词

[查看实现思路](../09-实现规划/02-地图.md#m09)

你带回的地图会影响一个地区是否被救援、拆除或封锁。不同证据可以支持或推翻你的绘制：水位痕迹、住户记录、通风的方向。

绘图之后还要说明依据。这适合调查型游戏，让“我来过”不等于“我知道一切”。无需写长篇报告，可以用现场证据与图块配对。

<a id="m10"></a>

## M10｜你给地方起名，地方才开始不同

[查看实现思路](../09-实现规划/02-地图.md#m10)

起名会让无差别的走廊逐渐拥有性格。叫“回家路”的地方更容易认，叫“没人来的房间”的地方真的开始避开访客。

可以从有限的词组中组合，而不是依赖自由文本理解。后面有人反对你取的名字，提醒你这里在你来之前就有生活。别把命名只有增益做成常规升级树。
