# 完整方向：逐条实现思路

这是候选做法，不是已经完成的功能。共用规则见[先搭什么底座](先搭什么底座.md)；先验证条目里的小场景，再决定是否扩展。

<a id="p01"></a>

## P01｜《不要相信回来的路》

[原始构思](../06-完整游戏方向/十二个方向.md#p01)

**玩家实际会做什么。**玩家从可靠据点出发探路，用声音获取信息，再处理旧路与足迹追踪。

**可以这样实现。**先串起视野、记忆图、声事件与足迹敌人四件事；地图变化仅保留水位改桥一种，剧情放在返回据点时。

**先做一小段。**做一段能完成的短旅程：出发、观察、绕敌、取物、用旧地图回家。记录玩家每次改路线的原因。

**需要守住的边界。**先不加回溯和任意画门；若玩家只是试遍岔路，优先补声音反馈与可靠地标，不扩大地图。

<a id="p02"></a>

## P02｜《另一端的笔迹》

[原始构思](../06-完整游戏方向/十二个方向.md#p02)

**玩家实际会做什么。**玩家与过去伙伴共绘地图，完成生活小事后遇到双方目标冲突。

**可以这样实现。**采用两份世界状态、共享图纸、符号协议和有限因果表；内容工具可预览一笔标记会触发哪段回应。

**先做一小段。**一栋楼三个任务，包含一次配合、一次误解与一次需要协商的改变。

**需要守住的边界。**最先验证的是是否关心对方；若只有解题而没有相处，增加安静互动而非更大历史灾难。

<a id="p03"></a>

## P03｜《房子想回家》

[原始构思](../06-完整游戏方向/十二个方向.md#p03)

**玩家实际会做什么。**玩家与房子共同旅行，外出调查路况，协商停靠与携带物。

**可以这样实现。**旅行使用节点路线与宽度标签，房子状态机驱动等待和跟随；室内独立场景持久保存布置。

**先做一小段。**三个停靠点、一次不能同行的障碍、一段重聚，证明分离与相处都有内容。

**需要守住的边界。**不先造自由大世界或复杂装修；若陪伴变成等待运输，缩短行走并增加双方主动安排。

<a id="p04"></a>

## P04｜《请勿登记》

[原始构思](../06-完整游戏方向/十二个方向.md#p04)

**玩家实际会做什么。**玩家调查街区、协商地图版本、提交后回访影响。

**可以这样实现。**地点证据、受众地图与访客日程组成核心，地区变化由发布事件批量计算；报告编辑器展示会透露哪些内容。

**先做一小段。**三户居民、一处公共设施、两类地图读者，做出两种合理发布方案。

**需要守住的边界。**避免每案同一道德题；先验证证据与受众决策是否清楚，不做大量重复文书手续。

<a id="p05"></a>

## P05｜《夜间饲养员》

[原始构思](../06-完整游戏方向/十二个方向.md#p05)

**玩家实际会做什么。**玩家夜间照料不可见动物，白天根据痕迹修改手册和布局。

**可以这样实现。**每物种一份需求表、有限行为状态和可见痕迹；园区用区域照明和栖息连接图驱动，不运行完整生态。

**先做一小段。**两物种四个围场三晚，含一次可修正误判及一次自发的新关系。

**需要守住的边界。**日常熟悉后可委派；若只剩按表投食，就增加观察和关系变化，不增加维护条。

<a id="p06"></a>

## P06｜《借来的明天》

[原始构思](../06-完整游戏方向/十二个方向.md#p06)

**玩家实际会做什么。**玩家借用未来设施先行，再把履约过程安排进后续旅行。

**可以这样实现。**因果债以有向依赖图维护，借用前求一条有效履约路径，禁止自循环；到期由明确事件而非任意后台计时触发。

**先做一小段。**两笔相互有帮助但不循环担保的债，提供替代履约和主动放弃。

**需要守住的边界。**这是状态复杂度较高的方向；先做可逐步检查的少量链，别承诺任意对象都能从未来借。

<a id="p07"></a>

## P07｜《给下一位留一盏灯》

[原始构思](../06-完整游戏方向/十二个方向.md#p07)

**玩家实际会做什么。**玩家用不同角色接力探索，留下公共成果与未完约定。

**可以这样实现。**角色档案与世界档案分离；交接摘要列出实际留下的设施、线索和关系，新角色目标从这些条件选择场景。

**先做一小段。**两角色两次交接，其中一次自愿离开而非死亡，最后让普通角色使用前人成果。

**需要守住的边界。**防止角色差异只是钥匙颜色；每个人至少一种不同路线判断，开局可跳过已熟悉路段。

<a id="p08"></a>

## P08｜《末班车不去终点》

[原始构思](../06-完整游戏方向/十二个方向.md#p08)

**玩家实际会做什么。**玩家经营一条夜间线路，听乘客指路，下车确认站点并安排顺序。

**可以这样实现。**节点驾驶、站点激活条件与车内人物组合对白；每晚结束更新关系网络，最后用替代交通验证网络成长。

**先做一小段。**四站三乘客两晚，第二晚让两位乘客因相识而改变目的地。

**需要守住的边界。**先不做高精度驾驶；乘客对白和路线安排才是主要验证点，驾驶不能吞掉它们。

<a id="p09"></a>

## P09｜《世界尚未命名》

[原始构思](../06-完整游戏方向/十二个方向.md#p09)

**玩家实际会做什么。**玩家观察语境、记录词义、尝试请求，逐渐学会陌生社会的通行方式。

**可以这样实现。**建立有限语法和语义标签，语句由可组合词块构成；世界规则依据语义而非猜输入字符串执行。

**先做一小段。**六个词、三种语境、一段需要协商的借道，允许误解后验证修订。

**需要守住的边界。**内容生产成本主要在例句一致性；制作词义检查表，不能同一符号在无提示时随剧情变义。

<a id="p10"></a>

## P10｜《你看起来很吓人》

[原始构思](../06-完整游戏方向/十二个方向.md#p10)

**玩家实际会做什么。**巨大主角学习靠近、示意、搬动和让路，逐渐能与居民生活。

**可以这样实现。**身体碰撞与力量使用明确阈值；NPC读取距离、姿态、速度和是否有退路，判断害怕或愿意交流。

**先做一小段。**一条街三个不同态度的居民、一处共同改造，至少一种解法不使用力量。

**需要守住的边界。**先给误碰恢复机会，别把操作笨拙等同道德坏；镜头需保证看见脚下的人。

<a id="p11"></a>

## P11｜《演出不能中断》

[原始构思](../06-完整游戏方向/十二个方向.md#p11)

**玩家实际会做什么。**玩家在演出间布置，在演出中临场补救，逐步改变演员选择。

**可以这样实现。**舞台事件调度器、后台持久物、角色即兴分支与灯光锁定；提供幕次回放，能查看事件为什么未触发。

**先做一小段。**一幕三种完成方式：照演、救场、让一人离场，分别留下后台变化。

**需要守住的边界。**别先追求整晚自由戏剧模拟；无关重复可快进，失败应产生新处理机会而非全部重来。

<a id="p12"></a>

## P12｜《今晚谁来敲门》

[原始构思](../06-完整游戏方向/十二个方向.md#p12)

**玩家实际会做什么。**玩家通过配送认识城市，后来教居民互相代送，最终接受别人送来的饭。

**可以这样实现。**订单、气味、温度与居民路线知识共享地点编号；将学会的路线转交他人，日程生成可追踪的代送事件。

**先做一小段。**四户三天一段代送，最后在家收到饭，完整验证互助循环。

**需要守住的边界。**温度先作线索而非严格评分；若流程像接单刷钱，减少订单量，保留具体人物需求。
