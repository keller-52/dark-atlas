# 人物种子：逐条实现思路

这是候选做法，不是已经完成的功能。共用规则见[先搭什么底座](先搭什么底座.md)；先验证条目里的小场景，再决定是否扩展。

<a id="c01"></a>

## C01｜认路很差的邮差

[原始构思](../05-世界与故事/人物与关系种子.md#c01)

**玩家实际会做什么。**玩家发现修好的门让邮差迷路，与他一起选择新路标。

**可以这样实现。**邮差路线绑定声音地标而非全图坐标；维修事件使部分地标失效，双方可重新录入提示。

**先做一小段。**两扇门、一条投递路和一次重新教学，观察误会能否自然形成。

**需要守住的边界。**不要惩罚修理；提供及时替代地标，投递物不会永久丢失。

<a id="c02"></a>

## C02｜不肯逃走的修鞋匠

[原始构思](../05-世界与故事/人物与关系种子.md#c02)

**玩家实际会做什么。**玩家帮修鞋匠完成最后一份约定，再决定一起走还是安排接手。

**可以这样实现。**个人任务跟踪鞋、收件人和交接者，三者位置独立；疏散日程留出可协商窗口。

**先做一小段。**一双鞋两种交付方式和一次打包离开。

**需要守住的边界。**不是找到任务道具才允许他活；逃生时可以带未修完的鞋，保留现实可行的选择。

<a id="c03"></a>

## C03｜假装知道路的孩子

[原始构思](../05-世界与故事/人物与关系种子.md#c03)

**玩家实际会做什么。**玩家识破孩子瞎指路，选择一起核对地标，鼓励他说不知道。

**可以这样实现。**孩子对白区分知道、猜测和怕被责备三种来源，温和核对事件解锁诚实求助而非加好感数。

**先做一小段。**三个路口一次错误指引，之后让孩子主动承认没把握。

**需要守住的边界。**错误路线必须可安全返回；不要让正常信任造成不可逆严重损失。

<a id="c04"></a>

## C04｜不会保密的门

[原始构思](../05-世界与故事/人物与关系种子.md#c04)

**玩家实际会做什么。**玩家教门在介绍来客前先询问住户，分别设置哪些信息能说。

**可以这样实现。**门使用信息字段与授权表，问候动作检查受众；习得隐私规则后生成不同短句。

**先做一小段。**两户居民一个陌生访客，让门学会一次正确保密。

**需要守住的边界。**别让自由语言承载权限判断；提供清楚选择，门不会为了戏剧性无故泄密。

<a id="c05"></a>

## C05｜嫌你太轻的渡船

[原始构思](../05-世界与故事/人物与关系种子.md#c05)

**玩家实际会做什么。**玩家接受渡船的捎货请求，调整重量后抵达不同码头。

**可以这样实现。**船有离散吃水层和货物质量，出发前预览可达码头；货物的收件人和借条形成沿河关系。

**先做一小段。**三种货物两条水层路线，完成一趟有实际投递后果的航行。

**需要守住的边界。**人物不能被当抛弃配重；允许安全卸货与返航，避免超载后一键沉船。

<a id="c06"></a>

## C06｜一直替别人等人的老人

[原始构思](../05-世界与故事/人物与关系种子.md#c06)

**玩家实际会做什么。**玩家接替老人等一段时间，让他离开去吃饭或办事。

**可以这样实现。**等待任务有可选择的时长、来客事件与代答权限；等待中提供可做的小动作，回报不只取决于是否等到人。

**先做一小段。**一个站台三种可能来客，玩家能在没有等到约定对象时仍完成照顾。

**需要守住的边界。**允许时间略过；不把长时间挂机当感情投入，也不把老人每句记忆都设成谜题。

<a id="c07"></a>

## C07｜过分认真的救援员

[原始构思](../05-世界与故事/人物与关系种子.md#c07)

**玩家实际会做什么。**玩家与救援员争论路线，也可以提交证据让他修改判断。

**可以这样实现。**救援规则由危险信息与职责条件组成，新的可靠证据能开放陪同、借工具等合作状态。

**先做一小段。**一次劝返、一次补充证据、一次主动援助，形成完整关系弧。

**需要守住的边界。**救援员不是必须被骗的障碍；诚实合作应同样可玩，且不自动代替玩家完成目标。

<a id="c08"></a>

## C08｜讨厌被叫作安全屋的房子

[原始构思](../05-世界与故事/人物与关系种子.md#c08)

**玩家实际会做什么。**玩家带房子看一次它想看的风景，而不是只给它升级。

**可以这样实现。**房子保存少量明确愿望，窗口朝向与停靠地点满足不同观察条件；满足后变化体现在闲谈与主动安排。

**先做一小段。**两个停靠点和一扇可转窗，做出一段双方意见不一致的旅程。

**需要守住的边界。**不设置日常愿望打卡；错过景色可再来，房子不会因此扣掉储物功能。

<a id="c09"></a>

## C09｜不想恢复记忆的人

[原始构思](../05-世界与故事/人物与关系种子.md#c09)

**玩家实际会做什么。**玩家询问是否愿意阅读某份过去资料，按对方选择分次交付。

**可以这样实现。**资料分级披露，每次需要单独同意；人物状态区分知道事实、接受讨论和愿意恢复联系。

**先做一小段。**三份资料，允许只看一份后仍完成关系支线。

**需要守住的边界。**不把拒绝标成未收集；关键路线不能要求强行恢复记忆，尊重选择要有完整内容。

<a id="c10"></a>

## C10｜替怪物翻译的人

[原始构思](../05-世界与故事/人物与关系种子.md#c10)

**玩家实际会做什么。**玩家与翻译者一起测试对怪物信号的解释，修订词典。

**可以这样实现。**每个译法存证据和置信等级，交互实验产生可比结果；翻译者会主动标出低把握判断。

**先做一小段。**两种鸣叫、一次误译和一个补救动作，让双方共同纠错。

**需要守住的边界。**不靠揭穿骗子推进；给误译合理来源，验证失败后保留可恢复关系。

<a id="c11"></a>

## C11｜一直在换工作的前任英雄

[原始构思](../05-世界与故事/人物与关系种子.md#c11)

**玩家实际会做什么。**玩家决定请前任英雄解决难题，或帮他经营面包店、找别人接手。

**可以这样实现。**请求带时间成本，与店铺日程冲突；替代帮助者和玩家自学路径都可用。

**先做一小段。**一件修路请求与一炉面包，至少两种解决方式不让任何人无故受罚。

**需要守住的边界。**不是求助就道德扣分；让英雄能明确答应、拒绝或约时间，不让玩家替他决定全部生活。

<a id="c12"></a>

## C12｜比你年轻的上一轮自己

[原始构思](../05-世界与故事/人物与关系种子.md#c12)

**玩家实际会做什么。**玩家陪旧版本的自己验证计划，展示证据或改进原方案。

**可以这样实现。**旧自己拥有固定初始知识和可更新假设，讨论围绕具体试验结果，最终可以坚持经过修订的方案。

**先做一小段。**一个已知会失败的小计划，允许找到第三条改良路线。

**需要守住的边界。**不要强制现在的自己永远正确；如果玩家真的找到可行改法，剧情应承认。

<a id="c13"></a>

## C13｜负责涂掉道路的人

[原始构思](../05-世界与故事/人物与关系种子.md#c13)

**玩家实际会做什么。**玩家与删路人共同现场核实，决定关闭、改标还是保留道路。

**可以这样实现。**每条删除申请记录风险、受影响者与替代路线；删图、封路和撤销通行权限是不同操作。

**先做一小段。**两条争议道路，其中一条可通过维修保留。

**需要守住的边界。**删除前检查替代出口；不能把反对制图简单写成反派，也不让她全知地替玩家做决定。

<a id="c14"></a>

## C14｜送餐时总说不饿的邻居

[原始构思](../05-世界与故事/人物与关系种子.md#c14)

**玩家实际会做什么。**玩家发现邻居转送饭，安排不会让任何一方难堪的双份配送。

**可以这样实现。**订单真实消费人与表面收件人分开；通过观察或交谈确认，之后选择加量借口或直接协商。

**先做一小段。**两户一个配送回合，比较私下调整与当面询问的短反馈。

**需要守住的边界。**不把穷困当解谜道具；两种合意方案都成立，没有公开揭穿才拿奖励的设计。

<a id="c15"></a>

## C15｜没有恶意的冒名者

[原始构思](../05-世界与故事/人物与关系种子.md#c15)

**玩家实际会做什么。**玩家调查冒名带来的问题，再帮助模仿者获得自己的身份。

**可以这样实现。**身份凭据与个体编号分离，冒名行动产生具体债务与误会；新身份通过见证、命名和登记建立。

**先做一小段。**一家店一间租屋两个纠纷，建立新身份后回访确认损害得到处理。

**需要守住的边界。**新名字不是一键洗白；也不强迫驱逐对方才能归还玩家权限，规则要允许共存。

<a id="c16"></a>

## C16｜记得每次失败的售票员

[原始构思](../05-世界与故事/人物与关系种子.md#c16)

**玩家实际会做什么。**玩家反复经过售票处，售票员根据已知失败给细微回应。

**可以这样实现。**跨轮事件摘要记录可被售票员观察的返回，选取短对白与小物变化；成功时开放从未用过的告别。

**先做一小段。**三次返回和一次成功，避免重复台词并保持普通语气。

**需要守住的边界。**他只记得见过的事；不读取玩家未暴露失败细节，糖也不成为刷失败的收益。
