# 延伸构思：逐条实现思路

这是候选做法，不是已经完成的功能。共用规则见[先搭什么底座](先搭什么底座.md)；先验证条目里的小场景，再决定是否扩展。

<a id="x01"></a>

## X01｜迷宫维修工

[原始构思](../06-完整游戏方向/再往外走二十步.md#x01)

**玩家实际会做什么。**玩家在冒险结束后修迷宫，听居民投诉，改造过时机关。

**可以这样实现。**白天访客按路线模拟，夜间开放模块化编辑；每次改造影响安全、通行和住户日程，记录改前改后。

**先做一小段。**三间房、一处经典推箱机关和两位住户，尝试既保留游玩性又方便生活。

**需要守住的边界。**不先做任意关卡编辑器；反馈来自具体使用，不用一个复杂度分数代替所有目标。

<a id="x02"></a>

## X02｜为从没见过太阳的人设计清晨

[原始构思](../06-完整游戏方向/再往外走二十步.md#x02)

**玩家实际会做什么。**玩家布置地下街区的灯、钟声与开门时间，为不同生活安排清晨。

**可以这样实现。**按区域设置时段曲线，居民作息声明可接受窗口；模拟一日后展示冲突与舒适变化。

**先做一小段。**夜班者、学校与花房三个需求，找出两种不同排班。

**需要守住的边界。**不把所有人满意做唯一数学解；有些冲突需要协商，原型只做三个时段。

<a id="x03"></a>

## X03｜藏猫猫冠军正在失去工作

[原始构思](../06-完整游戏方向/再往外走二十步.md#x03)

**玩家实际会做什么。**玩家找人，也设计能让大家玩得开心的藏身路线。

**可以这样实现。**孩子按可见地标挑藏点，兴奋由接近、逃脱与等待时间决定；玩家可示弱或增加新掩体。

**先做一小段。**四藏点三孩子两局，第二局根据第一局反馈调整场地。

**需要守住的边界。**不能把假装失误硬做评分表；用自然反应提示节奏，过度拖延时允许大家叫停。

<a id="x04"></a>

## X04｜侦探只调查没发生的事

[原始构思](../06-完整游戏方向/再往外走二十步.md#x04)

**玩家实际会做什么。**玩家检查未发生事件的残留，提出假设并布置小实验。

**可以这样实现。**残留证据绑定候选历史，实验会排除或支持某条因果链；少量被取消事件可在受控环境重演。

**先做一小段。**一间无打斗的乱屋、三种假设、两次可操作检验。

**需要守住的边界。**别靠收集到最后一张纸自动揭晓；实验结果要有判别力，错误假设可安全撤回。

<a id="x05"></a>

## X05｜黑暗是一种公共交通

[原始构思](../06-完整游戏方向/再往外走二十步.md#x05)

**玩家实际会做什么。**玩家安排公共暗路，让家具和包裹在无人观察时运输。

**可以这样实现。**暗区图由光照和观察者共同决定，运输物沿连通暗区移动；有人看见时停在安全节点。

**先做一小段。**三栋楼一条货路一位夜归者，协调照明与通行时间。

**需要守住的边界。**物体不在墙内生成；隐私、照明和运货有多个合理安排，不能鼓励强行让居民闭眼。

<a id="x06"></a>

## X06｜你是一座迷宫的园丁

[原始构思](../06-完整游戏方向/再往外走二十步.md#x06)

**玩家实际会做什么。**玩家修剪会生长的道路，为不同访客留直路与散步路。

**可以这样实现。**道路图按有限生长规则扩展，剪枝可撤销；访客按距离、休息点、可见退路三种偏好选路。

**先做一小段。**六节点花园三类访客，观察同一改动对不同人是否有不同影响。

**需要守住的边界。**保留可手工控制的生长范围；不靠随机生成大量死路增加复杂度。

<a id="x07"></a>

## X07｜拍不到东西的摄影师

[原始构思](../06-完整游戏方向/再往外走二十步.md#x07)

**玩家实际会做什么。**玩家改变场景里角色关注的对象，再拍摄被忽略的部分。

**可以这样实现。**关注来自游戏内注视、对白焦点与聚光标签；相机只显现低关注对象，不读取真实玩家心理。

**先做一小段。**一间屋三件物品，通过移动灯或请人转身让照片出现不同证据。

**需要守住的边界。**规则必须明说是场景注意力；主角已经看过不永久锁死拍摄，允许注意状态恢复。

<a id="x08"></a>

## X08｜怪物保险调查员

[原始构思](../06-完整游戏方向/再往外走二十步.md#x08)

**玩家实际会做什么。**玩家查怪物造成的损坏，问证人，核对保单后提出处理。

**可以这样实现。**案件包含事实、条款与补救方案三个独立层，证据影响事实判断，规则解释影响赔付与调解。

**先做一小段。**一栋离家出走的房子，一份歧义条款，两位相关人。

**需要守住的边界。**不要把每案变成骗子揭穿；允许修复、转介和补材料，不只批准或拒绝。

<a id="x09"></a>

## X09｜没有人需要你拯救的末日

[原始构思](../06-完整游戏方向/再往外走二十步.md#x09)

**玩家实际会做什么。**旧英雄醒来逐区核实原任务，发现居民已经另有用途。

**可以这样实现。**旧任务目标与当前用途并列，玩家调查后可改写自己的待办；修复方案需居民同意并保留必要服务。

**先做一小段。**旧能源核心变温泉的一处地区，提供恢复、改造和放下任务三种行动。

**需要守住的边界。**不把主角以前的努力全写成笑话；新生活有真实问题，放下使命之后仍有可做之事。

<a id="x10"></a>

## X10｜路线是一首可以演奏的曲子

[原始构思](../06-完整游戏方向/再往外走二十步.md#x10)

**玩家实际会做什么。**玩家规划经过地标的顺序，让路线形成可识别旋律。

**可以这样实现。**每个地标绑定声部与节拍，路线图生成乐句预览；机关读取离散音符序列，速度可自动对齐。

**先做一小段。**五地标两种可行旋律，一位靠曲子认路的居民。

**需要守住的边界。**不要求绝对音感；视觉符号、慢速与重听可用，路径音乐要有实际导航用途。

<a id="x11"></a>

## X11｜家族聚会是一座迷宫

[原始构思](../06-完整游戏方向/再往外走二十步.md#x11)

**玩家实际会做什么。**玩家在家族饭局里传菜、找椅子、安排私下说话，改变房间连接。

**可以这样实现。**关系话题与愿意同处状态控制少数门；对话时机由端菜、换座等动作触发，不需要自由语言理解。

**先做一小段。**四人一顿饭两个未解话题，至少能不揭秘密也让晚餐继续。

**需要守住的边界。**避免把关系优化成人人满意表；玩家可保留分歧，不能通过堵门强迫和解。

<a id="x12"></a>

## X12｜你在教一座城市做梦

[原始构思](../06-完整游戏方向/再往外走二十步.md#x12)

**玩家实际会做什么。**玩家白天参与城市生活，夜里探索这些事件组合出的梦。

**可以这样实现。**白天记录少量事件标签，夜间从手工梦片段按约束拼接；梦中变化通过固定桥接事件影响次日。

**先做一小段。**三种白天行动生成四个可区分梦段，让玩家猜到来源但不完全可控。

**需要守住的边界。**不从任意文本生成世界；避免组合出无路或剧情矛盾，梦片段也需要稳定出口。

<a id="x13"></a>

## X13｜手提箱里的远征

[原始构思](../06-完整游戏方向/再往外走二十步.md#x13)

**玩家实际会做什么。**玩家把线、水和小物放进箱子，进入缩小世界探索变化。

**可以这样实现。**箱内独立场景，外部物映射到有限内部地形模板；尺度按物类固定，箱体姿态只触发少量设计过的状态。

**先做一小段。**线、石子、水滴三种输入，生成两条可用路线与一个可恢复失误。

**需要守住的边界。**不要真实模拟所有体积与流体；放水有上限，重要居民不会因无提示倾箱被抹除。

<a id="x14"></a>

## X14｜你负责把怪谈讲错

[原始构思](../06-完整游戏方向/再往外走二十步.md#x14)

**玩家实际会做什么。**玩家收集怪谈的实际证据，再安排新版本通过故事与游戏传播。

**可以这样实现。**传说是结构化规则集合，传播者持有不同版本；有见证的版本逐渐改变有限世界行为。

**先做一小段。**一则怕灯怪谈、三个传播点、一次可见改写，让玩家追踪因果。

**需要守住的边界。**不是自由输入愿望即可成真；设可接受修改范围与反证，传播速度和覆盖要可观察。

<a id="x15"></a>

## X15｜重力是地方口音

[原始构思](../06-完整游戏方向/再往外走二十步.md#x15)

**玩家实际会做什么。**玩家观察雨、衣物与步态判断地方重力，携带外来物解决通行。

**可以这样实现。**每个区域定义重力方向，物体有原乡或入乡规则；门槛过渡使用可控旋转与稳定落点。

**先做一小段。**两个重力区、一件保留原乡方向的物体，完成一次搬运。

**需要守住的边界。**先用二维侧视或固定镜头；支持减弱镜头旋转，复杂刚体连续过界留到后期。

<a id="x16"></a>

## X16｜唯一的战斗动作是道歉

[原始构思](../06-完整游戏方向/再往外走二十步.md#x16)

**玩家实际会做什么。**玩家查明冒犯来源，用归还、修复和让路解决冲突，也可拒绝不合理索取。

**可以这样实现。**冲突记录具体事件与受影响者，补救行为逐项匹配；错误道歉解释不足之处而不直接失败。

**先做一小段。**三种冲突，其中一种要求本身不合理，允许安全退出或协商。

**需要守住的边界。**不能一个道歉键通吃；也不能把所有受害者都规定必须接受，保留冷静离开的路线。

<a id="x17"></a>

## X17｜游戏会逐渐把地图交还给你

[原始构思](../06-完整游戏方向/再往外走二十步.md#x17)

**玩家实际会做什么。**玩家从完整旅游图出发，逐渐关闭推荐层，绘制自己重视的内容。

**可以这样实现。**官方图、私人标记与实际观察分别存储；界面允许主动切层，隐藏推荐不删除已掌握事实。

**先做一小段。**同一区域分别按官方路线与个人目标走一次，发现不同生活细节。

**需要守住的边界。**不是强制撤功能；完整辅助图始终可打开，玩家愿意探索才有意义。

<a id="x18"></a>

## X18｜你是别人的隐藏路线

[原始构思](../06-完整游戏方向/再往外走二十步.md#x18)

**玩家实际会做什么。**玩家在墙内维修，引导外面冒险者，同时兼顾自己的工作与家。

**可以这样实现。**内外两张连接图共享机关状态；外来角色用有限目标行动，玩家改变门闩、声源和管线影响其选择。

**先做一小段。**一段外来旅程三个可帮助点，至少一个时刻玩家可以先忙自己的事。

**需要守住的边界。**冒险者不完全依赖玩家；提供明确意图反馈，避免只能猜脚本下一步想做什么。

<a id="x19"></a>

## X19｜旅馆接待互不相容的客人

[原始构思](../06-完整游戏方向/再往外走二十步.md#x19)

**玩家实际会做什么。**玩家接待需求不同的旅客，调整房间、隔音、遮光和作息。

**可以这样实现。**每位客人有少量硬约束与软偏好，房间邻接影响声光传递；安排后模拟一夜，展示具体投诉或满意。

**先做一小段。**四客六房，找到两种都能住好的方案，再加入一次可协商变动。

**需要守住的边界。**别做唯一排布数独；允许调解、换时间与旅客自己适应，满足后不持续制造同一种事故。

<a id="x20"></a>

## X20｜终点是把迷宫交出去

[原始构思](../06-完整游戏方向/再往外走二十步.md#x20)

**玩家实际会做什么。**玩家探索后布置路标与设施，让一个新角色独立完成旅程。

**可以这样实现。**新角色知识从空白开始，只读现场提示，采用有限观察与路线规划；记录卡住原因与自主发现。

**先做一小段。**六房间、三种路标、一次不介入的独立通行，随后看简短旅行记录。

**需要守住的边界。**不能暗中喂完整最短路；陌生人可以走不同路线，失败给改进信息，不要求完美复制玩家。
