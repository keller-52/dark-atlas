# 具体场景：逐条实现思路

这是候选做法，不是已经完成的功能。共用规则见[先搭什么底座](先搭什么底座.md)；先验证条目里的小场景，再决定是否扩展。

<a id="v01"></a>

## V01｜桥头的灯

[原始构思](../07-场景与奇遇/二十四个场景.md#v01)

**玩家实际会做什么。**玩家留灯过桥，回程看见灯被矮个路人调过角度。

**可以这样实现。**灯保存朝向与持有人；路人在离场期间调整灯，桥按实际光照判定，留下一处小脚印说明来源。

**先做一小段。**一座桥一次去回，验证改角后玩家与孩子都能通过。

**需要守住的边界。**不能为了场面让灯失效困住玩家；不额外塞入对白解释每个细节。

<a id="v02"></a>

## V02｜楼下正在量身高

[原始构思](../07-场景与奇遇/二十四个场景.md#v02)

**玩家实际会做什么。**玩家在图上圈出量身高的位置，现实墙上逐年出现刻痕。

**可以这样实现。**位置选在有限有效墙面，过去事件更新当下贴花组；保存所选墙和刻痕阶段。

**先做一小段。**一面墙三个可选位置、一次离开再返回，观察玩家能否认出自己的建议。

**需要守住的边界。**不需要逐年模拟；重要刻痕有照明和镜头可见性，错过后仍能回看。

<a id="v03"></a>

## V03｜怪物给你让路

[原始构思](../07-场景与奇遇/二十四个场景.md#v03)

**玩家实际会做什么。**玩家在窄路观察怪物让行手势，再选择回应或退开。

**可以这样实现。**遭遇锁定双方安全距离，怪物循环两次示范；正确回应打开侧身通道，错误先警告。

**先做一小段。**一个路口三种回应，让玩家无需文字教程也能学习。

**需要守住的边界。**首见不直接秒杀；仪式结束后保留规则，后续相似生物也遵守。

<a id="v04"></a>

## V04｜地图上多了一张桌子

[原始构思](../07-场景与奇遇/二十四个场景.md#v04)

**玩家实际会做什么。**玩家看见对方画早餐桌，可以选食物符号、随手圈点或暂时不答。

**可以这样实现。**地图对话插曲使用空闲条件触发，回应不影响必需谜题；桌子作为持续涂鸦保存。

**先做一小段。**一次无奖励的闲聊，观察玩家是否主动留下回应。

**需要守住的边界。**不要设隐藏亲密度门槛；不回答也不会错失主线，避免温柔变成任务。

<a id="v05"></a>

## V05｜一间不会追你的房间

[原始构思](../07-场景与奇遇/二十四个场景.md#v05)

**玩家实际会做什么。**玩家找到固定厕所，可以看地图、存档、放松。

**可以这样实现。**区域标为绝对安全，追逐者寻路排除此处，时间压力按既定规则暂停；建筑变换不更改它的出口关系。

**先做一小段。**一次追逐后进入，再离开继续，检查恢复节奏。

**需要守住的边界。**这处承诺始终兑现；不塞跳吓或敌人破门，作为世界的稳定参照。

<a id="v06"></a>

## V06｜你的错误路标救了人

[原始构思](../07-场景与奇遇/二十四个场景.md#v06)

**玩家实际会做什么。**玩家回访发现错误路标改变了疏散路线，可以修订并询问结果。

**可以这样实现。**事件记录当时路标版本，疏散者用该版本找路；安全结果来自具体封路时刻而非随机好运。

**先做一小段。**两条路线一个事后回访，展示错标如何绕开事故。

**需要守住的边界。**这是一次限定场面，不奖励到处乱标；后续更正不会抹掉已经发生的历史。

<a id="v07"></a>

## V07｜不要替我开灯

[原始构思](../07-场景与奇遇/二十四个场景.md#v07)

**玩家实际会做什么。**老人请玩家关灯，暗处逐渐传来来客的回应。

**可以这样实现。**对白请求后允许手动关灯；暗处生物按等待与照明条件启动声音和微小物件变化，不渲染本体。

**先做一小段。**一间门廊、一段可以随时结束的停留，检验没有露脸是否仍能理解。

**需要守住的边界。**灯不自动关闭代替玩家选择；若继续照着，老人解释而非突然惩罚。

<a id="v08"></a>

## V08｜出口门框上的抓痕

[原始构思](../07-场景与奇遇/二十四个场景.md#v08)

**玩家实际会做什么。**玩家从门的另一侧检查抓痕，发现它们是阻止门移动留下的。

**可以这样实现。**同一模型两侧展示不同痕迹方向，观察标记联结门的迁徙记录；之后开放询问或追门。

**先做一小段。**一个双面门框两份证据，确保玩家能自己修正猜测。

**需要守住的边界。**先前对白只应是猜测而非确定事实；不要让反转推翻已验证的物理痕迹。

<a id="v09"></a>

## V09｜房子闹别扭

[原始构思](../07-场景与奇遇/二十四个场景.md#v09)

**玩家实际会做什么。**回家时床被挪远，玩家可以调整，也能停留陪房子。

**可以这样实现。**根据少量离家事件触发一次可逆布置变化；门与基本功能保持可达，房子给含蓄短反应。

**先做一小段。**两次出门后一处床位变化，对比玩家是否读作表达而非系统错误。

**需要守住的边界。**不能靠扣资源逼停留；特殊布局先检测物件不重叠、不堵出口。

<a id="v10"></a>

## V10｜熟路上的陌生扶手

[原始构思](../07-场景与奇遇/二十四个场景.md#v10)

**玩家实际会做什么。**受伤回程时玩家发现扶手，附近留言指向此前教过的人。

**可以这样实现。**教学成功后登记改造事件，回访时加扶手与新通行标签；伤情只影响感受，不是触发帮助的必要条件。

**先做一小段。**同一路径改造前后各走一次，健康角色也能看到改进。

**需要守住的边界。**不用巧合证明世界只服务主角；居民同时使用扶手，让因果落在公共需求上。

<a id="v11"></a>

## V11｜排练中的笑场

[原始构思](../07-场景与奇遇/二十四个场景.md#v11)

**玩家实际会做什么。**道具放错引发演员笑场，玩家可以配合即兴继续演。

**可以这样实现。**一次特定道具偏差转入允许恢复的事件分支，演员出现短暂脱稿行为并打开新接续动作。

**先做一小段。**一幕中做对与做错都能完成，后者留下不同短句。

**需要守住的边界。**错误不普遍等于更优；场面只教玩家系统容许偏差，不承诺所有破坏都有效。

<a id="v12"></a>

## V12｜两份不一样的午饭

[原始构思](../07-场景与奇遇/二十四个场景.md#v12)

**玩家实际会做什么。**双方约定吃饭，在地图上留下食物图和油渍。

**可以这样实现。**地图插曲记录所选食物与笔迹贴花，后续章节按相同坐标保留油渍。

**先做一小段。**一段可跳过的午饭与两章后的再见，不影响解谜信息可读性。

**需要守住的边界。**油渍不能遮关键线索；不靠长时间等对方吃完来制造真实。

## V13｜救援员终于找到你

[原始构思](../07-场景与奇遇/二十四个场景.md#v13)

**玩家实际会做什么。**被困时玩家主动吹救援哨，救援员到达后先递水。

**可以这样实现。**玩家已学哨音后可在困境点发出标准求助事件，救援员沿可达路线进入援助状态。

**先做一小段。**一次之前躲避、一次之后求助，验证角色关系转换。

**需要守住的边界。**不能让救援员穿过玩家无法理解的墙；预留救援路径，援助不要求额外道德考核。

## V14｜没寄出的地址

[原始构思](../07-场景与奇遇/二十四个场景.md#v14)

**玩家实际会做什么。**玩家发现信封地址会变，暂停投递去核实寄信人的意愿。

**可以这样实现。**地址由寄信者的撤回状态切换到几个地点，信件观察日志显示变化；确认后再锁定最终指令。

**先做一小段。**三个地址两次改变和一次面谈，允许撤回或重寄。

**需要守住的边界。**移动地址有可查原因；不要自动扣送信失败，尊重撤回应是完整处理结果。

<a id="v15"></a>

## V15｜整座市场把门朝向你

[原始构思](../07-场景与奇遇/二十四个场景.md#v15)

**玩家实际会做什么。**市场回访时摊位朝向改变，玩家能更顺畅地穿过。

**可以这样实现。**保存帮忙避洪事件，市场模块加载对应朝向布局；商贩日程继续，只加几句可选招呼。

**先做一小段。**同一市场前后两版路线，测变化是否明显且方便。

**需要守住的边界。**不能让摊位旋转把任务入口遮住；感谢不强制停镜头，也不把所有人聚拢演讲。

<a id="v16"></a>

## V16｜有一只影子没有重复

[原始构思](../07-场景与奇遇/二十四个场景.md#v16)

**玩家实际会做什么。**玩家看见一个影子偏离记录，之后有机会复现实验找原因。

**可以这样实现。**这个影子带一个事先定义的额外条件，如绑定架子的旧事件；日志保留偏差来源，调查可读。

**先做一小段。**先演异常，再提供一个小测试证实规则，最后让玩家利用一次。

**需要守住的边界。**不能宣布所有影子突然任意行动；异常必须局部、可重现，不损坏既有回放谜题。

<a id="v17"></a>

## V17｜你听见自己明天会说的话

[原始构思](../07-场景与奇遇/二十四个场景.md#v17)

**玩家实际会做什么。**玩家先听见警告，后来站在发声处决定是否说出它。

**可以这样实现。**预告来自可条件取消的预约事件；说或不说都记录为分支，不强制播放玩家台词。

**先做一小段。**一间屋两个时点，两种选择都给一致的结果说明。

**需要守住的边界。**若选择固定时间线版本，就不要声称玩家可改变；本方案采用条件预告，须与 G10 统一。

## V18｜最后一班车上的空位

[原始构思](../07-场景与奇遇/二十四个场景.md#v18)

**玩家实际会做什么。**常坐后排的人没来，玩家路过家门看到普通晚餐。

**可以这样实现。**乘客关系达到某个事件后改变日程，线路保留空位；路过触发可自由看或不看的生活场景。

**先做一小段。**两晚建立习惯，第三晚缺席，给足以排除死亡猜测的生活细节。

**需要守住的边界。**不把不再乘车显示成任务失败；无需追问长对白，让好事可以安静发生。

## V19｜你照不见的幼崽

[原始构思](../07-场景与奇遇/二十四个场景.md#v19)

**玩家实际会做什么。**食物移动时多出一组轻小声音，玩家发现动物有了幼崽。

**可以这样实现。**原生物状态增加幼崽代理，食物消耗和声音节奏同步改变；不额外揭示模型。

**先做一小段。**三次投食建立基线，第四次出现可比较变化。

**需要守住的边界。**关键听觉差异提供字幕与食量记录；增加照料压力要温和，别立刻扣维护资源。

## V20｜一场不用赢的追逐

[原始构思](../07-场景与奇遇/二十四个场景.md#v20)

**玩家实际会做什么。**孩子请玩家扮怪物，玩家故意绕远或夸张失误，让追逐变成游戏。

**可以这样实现。**复用寻路与视野，改为非伤害游戏状态；孩子反馈节奏与险些被抓的次数，随时可结束。

**先做一小段。**一处安全环路三名孩子，验证慢一点也有快乐反馈。

**需要守住的边界。**不按最快抓完给最高分；轻喜剧段落不得突然切回致命战斗。

## V21｜灯不是留给你的

[原始构思](../07-场景与奇遇/二十四个场景.md#v21)

**玩家实际会做什么。**玩家追着远灯到人家门口，发现灯只是留给晚归家人。

**可以这样实现。**灯作为真实住户日程的一部分，玩家来访开放短休息与方向咨询，不启动主线机关。

**先做一小段。**一个可歇脚房间和家人按时回来，保持日常自然继续。

**需要守住的边界。**到达仍给实际帮助，避免长途误导后什么都没有；不把每个普通人强行连到阴谋。

## V22｜终于有一张准确的地图

[原始构思](../07-场景与奇遇/二十四个场景.md#v22)

**玩家实际会做什么。**玩家获得准确地图，用已经学会的能力轻松穿过稳定区域。

**可以这样实现。**区域冻结地形，入口发完整图，连接与碰撞对照校验；可选支线只增加生活细节。

**先做一小段。**一个可明显缩短路程的已知捷径，让玩家感到掌握有效。

**需要守住的边界。**不要随后突然宣布图是假的；这是节奏回报，允许真正顺利。

## V23｜给另一种身体修的路

[原始构思](../07-场景与奇遇/二十四个场景.md#v23)

**玩家实际会做什么。**巨大主角修路后蹲下，从小居民视角检查高差，再加坡道。

**可以这样实现。**提供视角切换与多种身体通行验证，高台、坡道按净高和坡度标签判定。

**先做一小段。**一段先只适合巨人、后让孩子与轮椅角色都能通过的路。

**需要守住的边界。**避免替现实无障碍标准作未经验证承诺；游戏内参数明确，表现上别把居民当检验工具人。

<a id="v24"></a>

## V24｜今晚是你等人敲门

[原始构思](../07-场景与奇遇/二十四个场景.md#v24)

**玩家实际会做什么。**玩家在家休息，听见熟悉敲门节奏，选择开门或隔门说话。

**可以这样实现。**终章读取代送关系生成送餐者与短对白；休息场景无隐藏计时，保留起身与继续躺下的动作。

**先做一小段。**让不同互助对象都能合理成为送餐者，未建立网络时也有诚实的替代收束。

**需要守住的边界。**不能强行假设玩家完成过某个善举；送饭来源必须匹配实际历史。
