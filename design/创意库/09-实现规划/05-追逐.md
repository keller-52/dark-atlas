# 追逐：逐条实现思路

这是候选做法，不是已经完成的功能。共用规则见[先搭什么底座](先搭什么底座.md)；先验证条目里的小场景，再决定是否扩展。

<a id="h01"></a>

## H01｜它只会走你的旧路

[原始构思](../03-追逐与生态/不靠加速的追逐.md#h01)

**玩家实际会做什么。**玩家观察自己的足迹，规划新路逃离或做环路拖延。

**可以这样实现。**足迹生成带时间的有向图；敌人只能沿已知足迹边移动，在岔路按公开规则选新痕。擦除或水流可断边。

**先做一小段。**一环两岔、一个断痕点，验证玩家能否在不提速时甩开追兵。

**需要守住的边界。**确定跳跃、折返和传送如何留痕；无路时敌人调查而非瞬移，不偷读玩家当前位置。

<a id="h02"></a>

## H02｜它追的是你的目的地

[原始构思](../03-追逐与生态/不靠加速的追逐.md#h02)

**玩家实际会做什么。**玩家向假目标布置线索，让追兵去错误地点守候。

**可以这样实现。**敌人对少数候选目的地维护权重，只从现场见到的物品、动作和路线更新；抵达后寻找证据再改判断。

**先做一小段。**两个目标三个可见线索，玩家能有意制造一次错误预测。

**需要守住的边界。**查看地图不自动泄露意图，除非有明确监视规则；提供敌人侦察和犹豫的可见反馈。

<a id="h03"></a>

## H03｜它听得见你命名

[原始构思](../03-追逐与生态/不靠加速的追逐.md#h03)

**玩家实际会做什么。**玩家给公开地点命名、给私人地点留符号，用假名引开追踪。

**可以这样实现。**公开名称注册进可被生物听见的列表，私有标记不进；生物按传播距离与最近命名事件追踪。

**先做一小段。**三间屋一份告示板，测试公开改名与私人标注的区别。

**需要守住的边界。**自由文字只作显示，规则用标签决定；别意外扫描玩家所有笔记，让基本记录无法使用。

<a id="h04"></a>

## H04｜它会学，但也会误学

[原始构思](../03-追逐与生态/不靠加速的追逐.md#h04)

**玩家实际会做什么。**玩家重复一种行为训练敌人，再用不同策略利用它的习惯。

**可以这样实现。**敌人只统计三类策略的近期频次，达到阈值后切换搜寻方案；每次切换有侦察动作与冷却。

**先做一小段。**柜子、钟声、绕圈三种策略，先让敌人学会一种，再诱导它误判。

**需要守住的边界。**保存学习状态，设置遗忘或重训路径；难度不靠全知追踪，防止一旦学习后所有方案都失效。

<a id="h05"></a>

## H05｜它是来救你的

[原始构思](../03-追逐与生态/不靠加速的追逐.md#h05)

**玩家实际会做什么。**玩家躲避救援，也能主动发信号请求破门或撤离。

**可以这样实现。**救援员使用搜寻、劝返、援助、护送状态，抓住后转移到安全点并推进窗口；不采用致命攻击逻辑。

**先做一小段。**一个可选目标、一条危险支路，让玩家经历一次被带回和一次主动求助。

**需要守住的边界。**重要道具不吞掉，错过窗口可有后续路线；避免无休止把玩家送回起点。

<a id="h06"></a>

## H06｜你必须带它走

[原始构思](../03-追逐与生态/不靠加速的追逐.md#h06)

**玩家实际会做什么。**玩家保持合适距离，把大型追逐者带向障碍，再寻找掩护。

**可以这样实现。**敌人有可见追踪半径、攻击距离与撞击前摇；障碍对其冲击有指定响应。丢失目标后去最后可见点。

**先做一小段。**两个可破门和一个避让环路，让玩家主动利用一次撞击。

**需要守住的边界。**碰撞结果使用明确标签，不依赖不稳定物理；每段有可停歇处，避免持续牵引变成操作疲劳。

<a id="h07"></a>

## H07｜它只在你确信安全时行动

[原始构思](../03-追逐与生态/不靠加速的追逐.md#h07)

**玩家实际会做什么。**玩家给藏身处留缝、留声，破坏生物喜欢的封闭条件。

**可以这样实现。**房间计算封闭度、背景声和占用状态；满足栖息条件一段时间才进入危险，分阶段给迹象。

**先做一小段。**三处藏身点各缺一种条件，让玩家观察后改造出安全处。

**需要守住的边界。**不得测量真实心理；显示环境线索，音量设置不影响规则判定，听觉信息有视觉替代。

<a id="h08"></a>

## H08｜你们在追同一个人

[原始构思](../03-追逐与生态/不靠加速的追逐.md#h08)

**玩家实际会做什么。**玩家跟随怪物寻找共同目标，再决定抢先、协助或阻止。

**可以这样实现。**目标角色有自主日程，玩家和怪物各自读取线索；发现新线索更新各自知识，不自动共享坐标。

**先做一小段。**一个会移动的目标、两份不完全线索和一处能观察怪物的高点。

**需要守住的边界。**目标可以拒绝双方；避免怪物总比玩家快一步的脚本作弊，允许成功抢先改变会面。

<a id="h09"></a>

## H09｜追逐发生在地图上

[原始构思](../03-追逐与生态/不靠加速的追逐.md#h09)

**玩家实际会做什么。**玩家在安全桌旁折图、擦线、设置阻断，拖延纸面黑点。

**可以这样实现。**纸面追兵在独立地图图上寻路，现实行动可新增或删除边；修改先预览，提交后按固定步推进。

**先做一小段。**六节点纸图与两处现实机关，验证两层行动互相帮助。

**需要守住的边界。**初版用回合推进或允许桌面暂停；黑点不能无视刚删的边，读档保留纸图和实体进度。

<a id="h10"></a>

## H10｜它怕你停下来听它说话

[原始构思](../03-追逐与生态/不靠加速的追逐.md#h10)

**玩家实际会做什么。**玩家先辨认求助信号，在合适地点停下听完一段话。

**可以这样实现。**每个停听点声明距离、退路、已知线索条件；敌人进入说话状态后固定不攻击，完成后永久缩小一段活动范围。

**先做一小段。**一条可安全停听的短路与一处明显不安全点，检验选择是否基于观察。

**需要守住的边界。**承诺的安全窗口必须可靠；倾听改变一部分行为，不在一次对白后突然治愈全部冲突。
