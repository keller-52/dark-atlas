# 叙事：逐条实现思路

这是候选做法，不是已经完成的功能。共用规则见[先搭什么底座](先搭什么底座.md)；先验证条目里的小场景，再决定是否扩展。

<a id="n01"></a>

## N01｜习惯先于自白

[原始构思](../04-关系与叙事/故事怎样发生在手上.md#n01)

**玩家实际会做什么。**玩家反复做一个生活动作，后来知道它来自某段关系。

**可以这样实现。**习惯动作拥有实际小作用和可跳过表现，累计在不同场合出现；揭示事件只更新理解，不强改已有事实。

**先做一小段。**三次摆杯子，第一次方便取水，第二次被人注意，第三次解释空位。

**需要守住的边界。**不强制每进门都播动作；揭示前后手感相同，让意义变化而非增加任务负担。

<a id="n02"></a>

## N02｜你决定什么进入历史

[原始构思](../04-关系与叙事/故事怎样发生在手上.md#n02)

**玩家实际会做什么。**玩家选择有限证据组成历史记录，并观察读者据此怎样行动。

**可以这样实现。**提交物是证据集合，读者使用明示的可信度与相关性规则形成判断；版本保留，可补充和订正。

**先做一小段。**一处事故六份证据、三个提交槽，至少两份合理但关注点不同的报告。

**需要守住的边界。**不能靠单一隐藏分决定善恶；未提交的证据仍保存在个人档案，方便复查。

<a id="n03"></a>

## N03｜反派会做与你一样的操作

[原始构思](../04-关系与叙事/故事怎样发生在手上.md#n03)

**玩家实际会做什么。**玩家从对手修改地图、熄灯或搬道具的痕迹反推计划。

**可以这样实现。**双方调用同一动作接口与成本检查；对手的有限目标规划器从自己的知识选动作，日志可回放核对。

**先做一小段。**一个灯谜双方轮流操作，验证对手也会因条件不足而失败。

**需要守住的边界。**剧情阶段不能暗中绕开规则；若拥有特殊能力，需提前展示且说明范围。

<a id="n04"></a>

## N04｜缺席的人通过维修被认识

[原始构思](../04-关系与叙事/故事怎样发生在手上.md#n04)

**玩家实际会做什么。**玩家拆修门、椅子或管道，发现前任留下的做法，决定保留或改造。

**可以这样实现。**维修分诊断、拆开、选择方案三步；物件含结构层、修补历史与可读痕迹，完成后改变实际功能。

**先做一小段。**一扇低门闩的门，两种修法，一位需要低门闩的居民。

**需要守住的边界。**不把每件物品都塞成长回忆；错误维修可返工，证据发现后进入笔记而非消失。

<a id="n05"></a>

## N05｜日记承认你没弄懂

[原始构思](../04-关系与叙事/故事怎样发生在手上.md#n05)

**玩家实际会做什么。**玩家把证据连到假设，划掉旧判断，保留不确定处。

**可以这样实现。**笔记维护主张与证据关系，不自动揭答案；新证据只标记冲突，修改留历史。提供可选提示层。

**先做一小段。**四条线索三种假设，先形成可理解误判，再用新证据修订。

**需要守住的边界。**不要要求输入自然语言被机器评分；用可选主张与自由备注并存，备注不控制通关。

<a id="n06"></a>

## N06｜真相不改变事实，改变责任

[原始构思](../04-关系与叙事/故事怎样发生在手上.md#n06)

**玩家实际会做什么。**玩家确认责任后选择具体修复行动，而不是用新真相抹掉旧伤害。

**可以这样实现。**事实表设不可变记录，动机线索增加解释；修复任务改变受影响人物与设施状态，不反向删除事实。

**先做一小段。**一次被玩家确认参与的破坏，提供修路、作证、赔偿三条不同修复行动。

**需要守住的边界。**避免一次善举抵销全部后果；允许当事人不原谅，但不堵住所有继续生活的路径。

<a id="n07"></a>

## N07｜城市误把你当成另一个人

[原始构思](../04-关系与叙事/故事怎样发生在手上.md#n07)

**玩家实际会做什么。**玩家暂借错误身份获得便利，也能在不同阶段说明真相。

**可以这样实现。**识别系统读取钥匙、称谓等凭据；NPC分别保存对身份的相信程度，澄清事件传播到哪些人需明示。

**先做一小段。**一家旅馆与一项未完成工作，比较早澄清、晚澄清、由证据揭示。

**需要守住的边界。**别只给撒谎路线更多好处；解释清楚也应产生内容，防止玩家被迫持续冒名。

<a id="n08"></a>

## N08｜结局是一种持续的做法

[原始构思](../04-关系与叙事/故事怎样发生在手上.md#n08)

**玩家实际会做什么。**玩家在最后亲自走过由长期行为改变的城市，看到生活结果。

**可以这样实现。**结局从已记录事件和地区状态组合选场面，使用少数一致性约束避免人物同时在两处；可显示影响来源。

**先做一小段。**三项长期行为生成两到三个不同结尾片段，确保每个都能追溯到行动。

**需要守住的边界。**不是每个细节都分支；不隐藏总分，容许中途修正。主线结尾需完整，不只一页统计。

<a id="n09"></a>

## N09｜第二次玩时，你是别人的路人

[原始构思](../04-关系与叙事/故事怎样发生在手上.md#n09)

**玩家实际会做什么。**第二遍换成配角，在熟悉事件旁边做先前没看到的事。

**可以这样实现。**主事件时间线复用，配角拥有独立通道和交互；引用首轮结果时读取关键事件摘要而非整个旧场景。

**先做一小段。**同一十分钟用两个人物各玩一次，第二遍至少出现一种新的行动目的。

**需要守住的边界。**第一遍必须自足；旧存档不存在时有默认历史，不强迫玩家补刷长流程。

<a id="n10"></a>

## N10｜有些谜可以不拆穿

[原始构思](../04-关系与叙事/故事怎样发生在手上.md#n10)

**玩家实际会做什么。**玩家可调查某个谜，也可只提供帮助，获得不同但完整的关系收束。

**可以这样实现。**每条小故事分理解事实和参与照顾两条进度，任一可抵达适当结尾；不把未知状态显示成未完成红点。

**先做一小段。**送饭到空屋的故事做三种收束：问清、只修屋檐、约定再来。

**需要守住的边界。**作者仍需写清因果；保留未知不应让任务栏永远悬挂，也不惩罚好奇的玩家。
