# 时间：逐条实现思路

这是候选做法，不是已经完成的功能。共用规则见[先搭什么底座](先搭什么底座.md)；先验证条目里的小场景，再决定是否扩展。

<a id="t01"></a>

## T01｜上一次的你继续走

[原始构思](../02-空间与时间/时间留下什么.md#t01)

**玩家实际会做什么。**玩家录一段自己的行动，回到起点后与影子配合。

**可以这样实现。**保存起点快照与按固定时间步记录的动作；影子对机关做同样交互，条件变化时反馈失败而不是穿墙。

**先做一小段。**两个按钮一道门，一次录制即可完成；再移动一个箱子看回放如何受阻。

**需要守住的边界。**轨迹播放与实际碰撞要一致；原型固定网格和确定性机关，提供快进无关路段与重录。

<a id="t02"></a>

## T02｜房间有自己的年龄

[原始构思](../02-空间与时间/时间留下什么.md#t02)

**玩家实际会做什么。**玩家把一个房间拨到年轻、现在或衰老，利用变化通过。

**可以这样实现。**房间使用三档预制版本，物件有跨版本映射；门口显示变化预览，重要物品存稳定身份，不因版本切换复制。

**先做一小段。**一棵树、一扇木门、一根梁，找到能通行且结构安全的组合。

**需要守住的边界。**不模拟所有材料老化；切换前检查玩家落脚点，收集物品后的其他版本应相应为空。

<a id="t03"></a>

## T03｜你只能给过去留下小事

[原始构思](../02-空间与时间/时间留下什么.md#t03)

**玩家实际会做什么。**玩家只移动有限小物或留短记号，过去的人按约定回应。

**可以这样实现。**允许的通信物使用有限状态编码；双方观察事件触发预写反应与世界变化。误解来自未建立协议的符号。

**先做一小段。**两把椅子和一面墙，先建立左右含义，再完成一次跨时提示。

**需要守住的边界。**协议建立后要稳定；允许重发和询问，别因一次读错导致整条故事无解。

<a id="t04"></a>

## T04｜未来可以借，但会到期

[原始构思](../02-空间与时间/时间留下什么.md#t04)

**玩家实际会做什么。**玩家预支一项未来成果，随后寻找能够让它成立的过程。

**可以这样实现。**每次借用创建因果债，含借用物、到期事件、可选履约链和违约结果；规划图只覆盖手工可验证的链。

**先做一小段。**一座借来的桥，两种修桥方法，一次主动取消借用，检验账是否易懂。

**需要守住的边界。**拒绝循环自我偿还；借用前验证至少有一条可行履约链，失败有恢复点，避免远期软锁。

<a id="t05"></a>

## T05｜时间靠人流动

[原始构思](../02-空间与时间/时间留下什么.md#t05)

**玩家实际会做什么。**玩家邀请人暂住，让房间开始流逝并发生变化。

**可以这样实现。**房间拥有本地时钟，有有效居民在场才推进；人物日程与房间事件使用本地时间，跨房间事件明确转换。

**先做一小段。**两个房间一盆植物一位居民，尝试让植物生长而保留另一屋状态。

**需要守住的边界。**角色不能被当作无条件时间电池；玩家进入是否计时要统一，存档保留各地时钟。

<a id="t06"></a>

## T06｜只有回程会变老

[原始构思](../02-空间与时间/时间留下什么.md#t06)

**玩家实际会做什么。**玩家进入新地时保持清晨，返回旧路时看见世界变老。

**可以这样实现。**以有向连接的首次通过记录定义新路与回程；只有重复通过特定边推进世界阶段，不用模糊距离判断。

**先做一小段。**一条支路一条环线，给玩家清楚预览哪些步会推进时间。

**需要守住的边界。**环路和传送规则先写明；设置阶段上限与替代出口，避免反复掉头瞬间耗完人物寿命。

<a id="t07"></a>

## T07｜你与同伴错开一分钟

[原始构思](../02-空间与时间/时间留下什么.md#t07)

**玩家实际会做什么。**玩家和同伴通过延迟一分钟的物件变化配合，提前约好动作。

**可以这样实现。**维护两份错时状态与带时戳的消息队列，物件事件经固定延迟映射；双方角色各自行动，不把输入延迟处理。

**先做一小段。**一扇门一盏灯，先练传递，再完成错时通过。提供时间线对照。

**需要守住的边界。**暂停应同步冻结；读档保存待投递事件。原型固定时差，不同时加入任意回溯。

<a id="t08"></a>

## T08｜失败被别人继承

[原始构思](../02-空间与时间/时间留下什么.md#t08)

**玩家实际会做什么。**玩家结束一段旅程后换人，新角色利用旧角色留下的东西。

**可以这样实现。**把世界成果与角色个人状态分开存；角色结束触发继承规则，区分死亡、定居和离开。公共设施不重置。

**先做一小段。**两位体型不同的角色，第一位搭桥，第二位从桥抵达自己的目标。

**需要守住的边界。**禁止故意死亡刷永久资源；活着交接也能留下成果，关键物品要有遗失后的恢复规则。

<a id="t09"></a>

## T09｜某些东西会逆着时间生活

[原始构思](../02-空间与时间/时间留下什么.md#t09)

**玩家实际会做什么。**玩家观察逆生长物体的状态，利用它跨时间传递有限信息。

**可以这样实现。**预设一条反向状态序列，物体本地时间与世界时间反向映射；跨时作用用明确因果表，不做任意逆物理。

**先做一小段。**三阶段植物与一个可改变的照料事件，让玩家预测下一阶段。

**需要守住的边界。**先处理矛盾覆盖：同一事件只应用一次，修改过去后撤销哪些后果要明确，避免凭剧情补规则。

<a id="t10"></a>

## T10｜最后一天可以过得很宽

[原始构思](../02-空间与时间/时间留下什么.md#t10)

**玩家实际会做什么。**玩家重复同一段时间，从不同房间陪伴不同的人。

**可以这样实现。**全局时间线固定，观察与关系知识跨轮保留；重要干预有有限分支，已看场面可快速略过。

**先做一小段。**三个角色、同一十分钟、只能完整陪伴其中两条路，观察选择是否来自关心。

**需要守住的边界。**不要以集齐痛苦结局为目标；章节结束给完整收束，没见到的人不自动被判为玩家失职。
