# 地图：逐条实现思路

这是候选做法，不是已经完成的功能。共用规则见[先搭什么底座](先搭什么底座.md)；先验证条目里的小场景，再决定是否扩展。

<a id="m01"></a>

## M01｜旧地图不会撒谎，只会过时

[原始构思](../01-探索与感知/地图也是一种行动.md#m01)

**玩家实际会做什么。**地图保留上次看到的样子，玩家主动复查过旧连接后才更新。

**可以这样实现。**每格存最后观察值、时刻和版本；现实变化只推送给正在观察的角色。地图用褪色和日期区分旧信息。

**先做一小段。**玩家经过桥后离开，水位改变桥，再让他依据地图返回，检查是否理解是过时而非故障。

**需要守住的边界。**至少保留可靠地标；变化须有征兆，别把每段路都设为高频失效。

<a id="m02"></a>

## M02｜擦掉一条路，也擦掉一种追法

[原始构思](../01-探索与感知/地图也是一种行动.md#m02)

**玩家实际会做什么。**擦除自己的路线，或放下一张错图，改变读取地图的追踪者能知道什么。

**可以这样实现。**把敌人知识来源限定为地图副本事件；擦除删的是知识图边，不删除现实。敌人调查实地后可恢复部分信息。

**先做一小段。**一条环路加一个岔口，允许真图和假图各一次，观察玩家是否能预测敌人选择。

**需要守住的边界。**说明敌人是否能自行观察；私人记录与暴露副本分开，避免擦图等于永久毁掉导航。

<a id="m03"></a>

## M03｜地图的纸不够了

[原始构思](../01-探索与感知/地图也是一种行动.md#m03)

**玩家实际会做什么。**玩家把精细区域压缩成文字路线，腾出空间记录新地方。

**可以这样实现。**地图记录有精细、摘要、仅地标三级；自动计算容量，压缩保留关键连接与人物笔记。玩家可在现场恢复精细图。

**先做一小段。**两片小区域限制为只能同时保留一份精图，看压缩决策是否有趣。

**需要守住的边界。**如果试玩者转而截图，就是限制无意义；允许自动摘要，不压缩无障碍提示和已读剧情。

<a id="m04"></a>

## M04｜公开地图会改变城市

[原始构思](../01-探索与感知/地图也是一种行动.md#m04)

**玩家实际会做什么。**玩家选择一份地图的读者与公开范围，再回访看谁使用了道路。

**可以这样实现。**发布生成带版本和受众的地图对象；居民根据获知连接更新日程。访客出现与地区变化从发布事件产生。

**先做一小段。**一个市场、一处诊所、一处藏身地，比较公开全图、局部图和定向交付三种结果。

**需要守住的边界。**不用模拟全城人口；先做三类访客。重要后果先展示传播范围，并允许后续修订。

<a id="m05"></a>

## M05｜地图上的空白是你留给别人的地方

[原始构思](../01-探索与感知/地图也是一种行动.md#m05)

**玩家实际会做什么。**玩家答应不记录某处，用私人暗号记路，或询问能否向特定人分享。

**可以这样实现。**地点有记录许可与受众列表；自动绘图跳过受保护内容，但允许不含坐标的私人提醒。分享前展示泄露范围。

**先做一小段。**一处居民家与两条入口，让玩家用地标成功回访，而不必截图坐标。

**需要守住的边界。**人物记录和隐私坐标分开；不记录不能导致无法完成主线，违约需要可见的关系反馈。

<a id="m06"></a>

## M06｜折一下纸，两间房就靠近了

[原始构思](../01-探索与感知/地图也是一种行动.md#m06)

**玩家实际会做什么。**玩家在地图上选择折线，预览重合房间，确认后获得临时连接。

**可以这样实现。**第一版只支持离散横折、竖折；对映坐标生成传送边，保存原连接。纸层遮挡决定哪些入口暂时不可用。

**先做一小段。**九宫格地图、两次折叠、一个被挡住的出口，检查玩家是否能先预想再行动。

**需要守住的边界。**不做任意折纸物理；撤销前检查有人站在接缝，并给安全退出点，避免实体被折到地图外。

<a id="m07"></a>

## M07｜地图记录的是承诺

[原始构思](../01-探索与感知/地图也是一种行动.md#m07)

**玩家实际会做什么。**玩家承诺从某条路回来，使这条路稳定；可以延期、解释或托人带信。

**可以这样实现。**承诺对象绑定路线、参与者和履约条件；关系事件更新路的稳定阶段，失约先降可靠性再触发后续，不立即删路。

**先做一小段。**一条可选捷径与两位有不同安排的人，检查玩家是否会主动拒绝无法完成的承诺。

**需要守住的边界。**避免多倒计时；每次失约保留补救，主线唯一出口不能依赖一个不可恢复的承诺。

<a id="m08"></a>

## M08｜两个人画同一张纸

[原始构思](../01-探索与感知/地图也是一种行动.md#m08)

**玩家实际会做什么。**玩家圈位置、画箭头、放符号，与另一端的人交换信息。

**可以这样实现。**离线对白状态机读取少量语义工具与坐标区域，播放预写笔迹动画；共用图纸、各自世界状态和双方已知事实分开存。

**先做一小段。**六房间、十种符号、一场小误会与一次成功协作，检验没有自由聊天是否仍有陪伴感。

**需要守住的边界。**不声称能理解任意涂鸦；给不理解的回应和可澄清选项，不用随机沉默卡住流程。

<a id="m09"></a>

## M09｜地图是会被质疑的证词

[原始构思](../01-探索与感知/地图也是一种行动.md#m09)

**玩家实际会做什么。**玩家绘图后把现场证据拖到判断旁边，提交可被询问的报告。

**可以这样实现。**主张、支持证据、反证构成关系图；评审按可解释规则回应，不按隐藏好坏分。接受补充与更正。

**先做一小段。**一份水位争议，用三条证据支持两种方案，检查玩家能否说明取舍。

**需要守住的边界。**不是所有题都唯一答案；把事实正确性、证据充分性和政策选择分开反馈。

<a id="m10"></a>

## M10｜你给地方起名，地方才开始不同

[原始构思](../01-探索与感知/地图也是一种行动.md#m10)

**玩家实际会做什么。**玩家用受限词组给地方命名，观察当地人如何接受、误解或反对。

**可以这样实现。**名称由含标签的词组构成，影响少量明示规则；居民认可度决定名称能否传播，旧名仍保留在记录。

**先做一小段。**三个无名房间、六个词组，让命名改变一条路的可读性或访客行为。

**需要守住的边界。**禁止无限自由文本魔法；改名需可撤销，不能因为起了不理想名字永远失去内容。
