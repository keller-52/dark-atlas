# 组合怎样落地

对应原来的[组合菜单](../08-组合与耐玩/组合菜单.md)。这里补的是两个系统相遇时怎样协作，避免各自都能运行，一放到一起就互相打架。

| 组合 | 共用什么记录 | 最小整合场景 | 必须先定清的边界 |
| --- | --- | --- | --- |
| G02 声音＋H01 足迹 | 同一地点编号、声事件、足迹边 | 玩家在旧环路放声源，再进入新支路 | 采用“足迹决定能去哪，声音影响岔路优先级”；声源不赋予穿越无足迹区的能力 |
| M01 旧地图＋E05 潮汐 | 水位阶段、地点版本、观察时刻 | 低潮绘图，高潮从旧水线找到新船道 | 水位改变现实，只有观察才改地图；地图明确显示记录时的水位 |
| M08 共绘＋T03 小改动 | 共享标记、双方已知协议、因果事件 | 用椅子朝向给过去发信号，现在线索随回应改变 | 未建立协议的标记先询问；同一回复只能应用一次，不因读档重复改历史 |
| G07 固定现实＋S10 剧场 | 光照覆盖、舞台对象候选态、幕次 | 移追光固定一条后台通路，同时影响演员上场 | 先计算光锁定，再执行演出事件；演员不会站到尚未稳定的平台上 |
| R01 房子＋S05 重量 | 房屋组件唯一编号、重量、停靠状态 | 暂存大柜子过低桥，之后回来取 | 寄存不等于销毁；重量变动在安全停靠点结算，房内有人时不危险切换 |
| M04 公开图＋E09 借物 | 地图读者、物品归属、借用记录 | 公布一条路后，居民借走梯子搭公共通道 | 借用者只能去自己知道且可达的地点；关键物品有追踪与协商归还 |
| H04 学习＋G04 热痕 | 可观察热记录、敌人策略计数 | 多次加热空椅子，诱使敌人形成错误经验 | 敌人只学习成功调查到的现象；热痕冷却与策略遗忘使用一致时钟 |
| R03 教路＋T08 接力 | 教学结果、世界成果、角色档案 | 前角色教会向导，后角色获得带路帮助 | 向导记得教会的路，不自动认识新角色；介绍或现场请求建立接触 |
| E02 暗生物＋M05 留白 | 光照、公开程度、私人导航 | 建一条不暴露栖息地的触觉路标 | 私人辅助记录不算曝光；只有向世界发布的坐标触发后果 |
| S02 身份门＋N07 误认 | 身份凭据、NPC所信版本、门票 | 借错身份进入工作区，解释后换成访客许可 | 澄清不应立即让角色困在内部；退出使用入场票，下一次进入再检查新身份 |
| T04 借未来＋R02 自主 | 因果债、协作同意、替代履约链 | 借来的桥需要修桥者，但他临时想离开 | 借用前不能默认别人已承诺；拒绝后有替代修法或撤销借用，不把自主权变死锁 |
| E07 礼仪＋P10 巨人 | 身体尺寸、路权条件、姿态 | 巨人先给小动物让路，再获准通过 | 碰撞与礼仪都承认体型；镜头能看清脚边，不靠不可见小目标惩罚玩家 |
| G05 气味＋E10 市场 | 市场泊位、风向边、气味源 | 根据烘焙气味与风向推断市场改道后位置 | 搬迁先更新源位置，再计算传播；旧气味有明确衰减，不能无限残留 |
| S01 关系空间＋R10 告别 | 关系事件、定居地点、门连接 | 同伴搬家，旧捷径关闭但约定回访路打开 | 告别不是关系归零；迁移在角色不占门槛时提交，保留物品交接 |
| M06 折纸＋H09 纸追逐 | 纸层关系、折叠映射、追兵位置 | 折出临时绕路拖延黑点，再去现实解机关 | 黑点在纸层上有明确位置；折叠先预览，不能一折就无提示把它压到目标上 |
| G09 见证＋N02 记录 | 主张、证据、观察者立场 | 邀请不同见证者核对房间，再提交报告 | 见证改变可确认事实，报告另行决定记录什么；不把多数意见自动算真相 |

## 六类冲突的具体处理

### 任意改图与路线规划

先限定改图只能作用于“可修订”的连接插槽，无法直接改安全屋与目标。让改图改变一个局部环路，足迹仍在实际走过的连接上累计。原型若发现画门总比规划好，就把改图移到独立章节，不靠不断增加成本硬救。

### 回溯与永久后果

为每类记录选清楚作用域：现实位置随快照回退，玩家已知事实可以保留，人物记忆是否保留由故事设定决定。界面在回溯预览中说明哪些改变会撤销。不要让某件普通物品既随快照恢复又作为永久奖励留在背包。

### 追逐与语言阅读

把推断发生在安全观察点。追逐中只应用已学会的短指令，允许一键查看已确认的意思。难度来自何时使用，不在奔跑时识别新语法。原型记录玩家是否频繁因为读界面而被抓，若是，重排节奏。

### 学习敌人与变化地图

先固定地图只做一次有预兆的变化。敌人学习限于躲藏或声源两类，所有学习动作记录在它的观察日志。开发时用覆盖层显示“它现在相信什么”，排除实际位置泄露。之后再逐项加变化。

### 地图容量与剧情记忆

精细地形、路线摘要、人物档案使用不同存储池。容量只限制精细地形，不动对白、约定和无障碍辅助。让摘要由系统提出、玩家确认，避免强迫手抄整张图。

### 陪伴与必然牺牲

内容规划阶段列出每位同伴的完整去向，至少有几条关系能够持续存在。需要离开的角色用提前准备、交接和回访表现变化。不要在实现时把所有离队复用成死亡事件，否则存档、对白和情绪都会被同一种结构绑住。

## 三个混合方案怎样起步

**轻悬疑。**先把 P02 的一栋楼做完整，只添加一次送饭闲聊和一处可维修生活物。共绘与因果能运行后，再补关系段落。暂时不加追兵。

**紧张探索。**先用 P01 的六房间地图验证声事件和足迹。安全屋只做保存、整理、两句回访对白，不同时建设独立养成系统。

**古怪旅行。**先把 P03 的三个停靠点与迁徙市场接起来。用一种生物礼仪制造一次双方都能理解的阻碍，不再加入回溯。重点看房子是否像同行者，而不是慢速仓库。
