# 关系：逐条实现思路

这是候选做法，不是已经完成的功能。共用规则见[先搭什么底座](先搭什么底座.md)；先验证条目里的小场景，再决定是否扩展。

<a id="r01"></a>

## R01｜会走路的安全屋

[原始构思](../04-关系与叙事/把关系写进操作里.md#r01)

**玩家实际会做什么。**玩家与房子约定停靠点，修理、布置、出门与返回都得到小反应。

**可以这样实现。**房子用等待、跟随、担心、寻人、休息几种状态；情绪由具体事件决定，偏好独立于饥饿条，寻路只走预设宽路。

**先做一小段。**两处停靠点、一次主动等待和一次寻找玩家，观察是否产生陪伴感。

**需要守住的边界。**别用惩罚逼人回家；房子擅自行动前留信号，不得弄丢储物或堵住进度。

<a id="r02"></a>

## R02｜同伴有权不跟你走

[原始构思](../04-关系与叙事/把关系写进操作里.md#r02)

**玩家实际会做什么。**同伴表达边界，玩家协商替代路线或暂时分开。

**可以这样实现。**每人有愿望、禁忌与可协商条件，拒绝返回原因和替代动作；路线规划排除不愿通过的边。

**先做一小段。**一位怕水同伴与两条路线，提供架桥、分开、换路三种选择。

**需要守住的边界。**不以好感值直接购买服从；关键剧情要能在分开后继续，等待位置必须可回访。

<a id="r03"></a>

## R03｜你教别人认路

[原始构思](../04-关系与叙事/把关系写进操作里.md#r03)

**玩家实际会做什么。**玩家带同伴认几个地标，再让他试着自己走。

**可以这样实现。**同伴知识图只存亲历连接和被教的标志，复述路线时暴露疑点；成功后把路线加入自主日程。

**先做一小段。**五节点路线，途中一个误认地标，教学后让同伴带路返回。

**需要守住的边界。**教学不要求完整重复走远路；他可发现替代路线，但需有来源，不能突然全知。

<a id="r04"></a>

## R04｜灯要交给谁

[原始构思](../04-关系与叙事/把关系写进操作里.md#r04)

**玩家实际会做什么。**玩家交接灯，分别承担照明与潜行任务，并用信号协调。

**可以这样实现。**灯是唯一可转移实体，持有者决定光锥；同伴根据预设安全点移动，收到信号后转向或等待。

**先做一小段。**一段需要留灯固定的桥和一处可绕后的门，至少交换两次角色。

**需要守住的边界。**递灯需确认接收与距离；同伴不会意外把灯带离唯一通路，提供召回或恢复位置。

<a id="r05"></a>

## R05｜怪物不懂你的礼物

[原始构思](../04-关系与叙事/把关系写进操作里.md#r05)

**玩家实际会做什么。**玩家观察怪物交换方式，再选择如何摆放和交付礼物。

**可以这样实现。**礼物由物品类型、放置姿态、距离和场合组成语义组合，反应表决定误解或认可；记录已验证含义。

**先做一小段。**三类物品两种摆法，让同一个食物产生不同但有线索的回应。

**需要守住的边界。**限制组合数量；误解先改变行为或距离，不直接杀人，怪物也要有学习玩家意图的事件。

<a id="r06"></a>

## R06｜每次回来，饭桌上多一个位置

[原始构思](../04-关系与叙事/把关系写进操作里.md#r06)

**玩家实际会做什么。**回到据点后，玩家能插手饭桌安排，也可以只坐下听一会儿。

**可以这样实现。**居民有日程与成对关系；按当前事件挑一段短互动，座位与物品变化持久化，服务功能可由不同人接手。

**先做一小段。**三人据点，分别处理一次合作、争执和自发帮助。

**需要守住的边界。**不让每次返回都强制排队对白；离开的居民不应带走唯一必需功能，允许安静时段。

<a id="r07"></a>

## R07｜你帮人藏起来

[原始构思](../04-关系与叙事/把关系写进操作里.md#r07)

**玩家实际会做什么。**玩家与被保护者一起安排住所、假线索和可信联络人。

**可以这样实现。**搜索方有独立情报图，公开线索增加暴露概率；保护对象按同意的计划行动，并会提出改变安排。

**先做一小段。**两处住所、一个联系人、一次有预警的搜查，看玩家能否调整方案。

**需要守住的边界。**藏匿不是把人物冻结在箱子里；失败保留转移或谈判机会，追踪者只使用获得的情报。

<a id="r08"></a>

## R08｜同行者记得另一个版本的你

[原始构思](../04-关系与叙事/把关系写进操作里.md#r08)

**玩家实际会做什么。**同伴按他认识的版本对待你，你用现在的行动修订关系。

**可以这样实现。**角色记忆使用带来源的事件集合，信任按具体领域更新，如守约、照顾、保密，不汇成单一善恶值。

**先做一小段。**两位对主角印象相反的人，安排同一行为让双方产生不同而合理的反应。

**需要守住的边界。**不要要求刷重复好事；关键变化来自新证据，拒绝恢复旧身份也能形成新关系。

<a id="r09"></a>

## R09｜你要学会接受照顾

[原始构思](../04-关系与叙事/把关系写进操作里.md#r09)

**玩家实际会做什么。**玩家主动请求带路、帮忙或代送，体验被照顾的位置。

**可以这样实现。**求助动作根据当前困难和关系开放，不依赖低血量；同伴接手具体任务并告诉玩家自己能做到的范围。

**先做一小段。**让熟练玩家主动交出一段路线，也能触发帮助，而无需先受伤。

**需要守住的边界。**援助不等于自动通关；保留玩家选择与参与，拒绝求助不是道德失败。

<a id="r10"></a>

## R10｜告别是一条可以走完的路

[原始构思](../04-关系与叙事/把关系写进操作里.md#r10)

**玩家实际会做什么。**玩家送别、交换物品、约定通信，之后能看到对方的新生活。

**可以这样实现。**离队是可规划事件，保存联系渠道、赠物和目的地；后续来信或回访按世界进度触发，能力缺口由场景替代。

**先做一小段。**一位同伴完成自己的目标后离开，安排一次短回访证明关系继续。

**需要守住的边界。**不没收他替玩家携带的物品；告别允许暂缓，不用突然失踪制造分量。
