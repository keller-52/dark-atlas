# 空间：逐条实现思路

这是候选做法，不是已经完成的功能。共用规则见[先搭什么底座](先搭什么底座.md)；先验证条目里的小场景，再决定是否扩展。

<a id="s01"></a>

## S01｜房间按照关系相邻

[原始构思](../02-空间与时间/空间可以怎样不讲道理.md#s01)

**玩家实际会做什么。**玩家安排见面、送东西或修复关系，房间的相邻方式随之改变。

**可以这样实现。**关系事件驱动房间图边，不连续移动建筑；重要门用过渡走廊接新目的地。只有预设关系标签能改变指定连接。

**先做一小段。**三个角色四间房，安排一次聚餐后出现新捷径，验证玩家能把关系与空间对应起来。

**需要守住的边界。**关系不是单条好感值；门槛有人时延迟切换，不能因争吵把唯一安全出口移走。

<a id="s02"></a>

## S02｜每个人都有自己的门

[原始构思](../02-空间与时间/空间可以怎样不讲道理.md#s02)

**玩家实际会做什么。**玩家独自进门、跟随别人进门，或取得被认可的身份后走不同路线。

**可以这样实现。**门读取进入者身份凭据与临时同行授权，按固定优先级选出口；同一帧进入的小队使用一次门票事件。

**先做一小段。**一扇门对应住户、邮差和访客三个目的地，让玩家尝试借道。

**需要守住的边界。**衣服不自动等于身份；跟随需要许可。退出路线先设计好，防止借身份进去后永久困住。

<a id="s03"></a>

## S03｜出口在迁徙

[原始构思](../02-空间与时间/空间可以怎样不讲道理.md#s03)

**玩家实际会做什么。**玩家查看出口留下的痕迹、查迁徙规律，决定守候还是追赶。

**可以这样实现。**出口使用地点图上的日程与迁移状态机；痕迹显示上次停留和下一类地点。阻塞道路会推迟而非随机改位置。

**先做一小段。**四个停靠点和一条可预测循环，给玩家两种追门策略。

**需要守住的边界。**允许快进等待并显示错过后的下一窗口；出口不能随玩家接近而作弊逃走。

<a id="s04"></a>

## S04｜你带着唯一一间稳定的房间

[原始构思](../02-空间与时间/空间可以怎样不讲道理.md#s04)

**玩家实际会做什么。**玩家带着门框走，把它放到合适位置后进入固定房间。

**可以这样实现。**室内是独立场景，门框记录外部锚点与朝向；离开时恢复相对位置。搬运时检查尺寸，室内有人则禁止收门。

**先做一小段。**一个门框、三个安装点和一件需要中转的长物，验证屋内外连接。

**需要守住的边界。**不能复制门内物件；读档保存锚点，门框失落时有合理回收方式，不删掉整个家。

<a id="s05"></a>

## S05｜重量改变楼层

[原始构思](../02-空间与时间/空间可以怎样不讲道理.md#s05)

**玩家实际会做什么。**玩家安排家具与居民移动，改变建筑浮沉，接近不同楼层入口。

**可以这样实现。**按房间汇总重量，计算几个离散水线状态，状态切换改变连接；不必实时模拟整楼刚体。移动前预览趋势。

**先做一小段。**两层楼、四件大件、一个可迁移住户，尝试让两处入口先后可达。

**需要守住的边界。**避免按人价值计量；居民需同意搬迁。状态变化前给撤离时间，关键出口保持可恢复。

<a id="s06"></a>

## S06｜墙是两边共同维持的误会

[原始构思](../02-空间与时间/空间可以怎样不讲道理.md#s06)

**玩家实际会做什么。**玩家让墙两侧的人通过敲击、递物或说出名字，逐步建立联系。

**可以这样实现。**每堵特殊墙保存双方已确认的信息类别；共享事实达到设定条件后切换薄墙、可递物、可通行三阶段。

**先做一小段。**一堵墙两个人，先用小孔确认对方存在，再决定是否扩大。

**需要守住的边界。**保留拒绝打通的结果；墙是否变化需双方同意，不把强迫交流当唯一解法。

<a id="s07"></a>

## S07｜方向属于你携带的东西

[原始构思](../02-空间与时间/空间可以怎样不讲道理.md#s07)

**玩家实际会做什么。**玩家拿出旧钟、戒指等物件，比较不同方向提示来定位。

**可以这样实现。**每件物品绑定世界中的具体目标或关系节点，罗盘指向图上的下一段路；信号范围和遮挡固定。

**先做一小段。**三件物品各指向不同地标，通过交叉线索找到一处未标位置。

**需要守住的边界。**关系变动时解释指向为何变化；无目标时明确失灵，别用随机抖动假装神秘。

<a id="s08"></a>

## S08｜电梯不经过楼层，经过版本

[原始构思](../02-空间与时间/空间可以怎样不讲道理.md#s08)

**玩家实际会做什么。**玩家在电梯选择建筑年代，观察固定结构的不同用途。

**可以这样实现。**同一房间编号对应若干手工版本，共享空间骨架；电梯切换版本并应用少量跨年代因果映射。

**先做一小段。**一层建筑三个时期，利用旧版用途判断新版被封门的位置。

**需要守住的边界。**先别做任意年份；切换时人和物按规则迁移，不能把版本切换变成无限复制道具。

<a id="s09"></a>

## S09｜路会记住你怎样走过

[原始构思](../02-空间与时间/空间可以怎样不讲道理.md#s09)

**玩家实际会做什么。**玩家慢行、奔跑、扶人等行为被道路记住，回访时看到空间变化。

**可以这样实现。**每条路累积少数行为计数，达到阈值后在离开区域时替换预制变体；设置恢复和重塑事件。

**先做一小段。**同一段路分别试跑、慢走和护送，检查变化是否能从行为读懂。

**需要守住的边界。**反馈不要过度频繁；别处罚手抖跑过一次。影响最好是路线气质与功能，不是暗中扣分。

<a id="s10"></a>

## S10｜迷宫是一场排练

[原始构思](../02-空间与时间/空间可以怎样不讲道理.md#s10)

**玩家实际会做什么。**玩家做场务，移动道具、安排灯位和改变上场顺序，从后台改舞台。

**可以这样实现。**演出用带前置条件的事件图，场景门按角色与幕次开放；后台状态跨轮保留，舞台状态在排练重置。

**先做一小段。**一幕三演员、两个道具、一场可避免的小事故，允许两种处理方式。

**需要守住的边界。**事件失败后有临场补救，不能一句台词没触发就整幕死锁；复杂剧情暂不与自由物理叠加。
