# 感知：逐条实现思路

这是候选做法，不是已经完成的功能。共用规则见[先搭什么底座](先搭什么底座.md)；先验证条目里的小场景，再决定是否扩展。

<a id="g01"></a>

## G01｜借来的眼睛

[原始构思](../01-探索与感知/感知不只是视野.md#g01)

**玩家实际会做什么。**玩家选择观察某只动物，看到它能理解的通路，再用食物或手势请求它移动。

**可以这样实现。**同一场景维护人、鼠、蛾三种通行图；动物自主寻路，观察模式只切换感知层。用饥饿、避光、归巢三个目标决定是否接受引导。

**先做一小段。**做一间有通风管和灯的房间，要求玩家从两种感知拼出出口。看他能否解释为什么动物拒绝进入。

**需要守住的边界。**先只做两种动物；不可切换后直接替玩家解完整路径，退出观察时保留人的位置与危险提示。

<a id="g02"></a>

## G02｜声音先于形状

[原始构思](../01-探索与感知/感知不只是视野.md#g02)

**玩家实际会做什么。**敲击、投石、轻声呼喊分别得到局部、定向和大范围线索。

**可以这样实现。**声事件沿房间连接传播，记录距离、材质和衰减；回声用延迟声响加轮廓片段表达。敌人接收同一事件，但只获得估计声源。

**先做一小段。**用三条长短不同的走廊，让玩家只靠一次投石挑出可能通路，再检查推断是否可理解。

**需要守住的边界。**原型不用完整声学模拟；门的开闭必须影响传播，字幕和视觉脉冲提供等价信息。

<a id="g03"></a>

## G03｜阴影告诉你缺了什么

[原始构思](../01-探索与感知/感知不只是视野.md#g03)

**玩家实际会做什么。**玩家搬灯或换观察角度，从影子猜物体形状。

**可以这样实现。**隐藏物保留碰撞与投影代理，只不渲染本体；少数历史影子使用独立图层并有统一标识。二维先用预制剪影与投影变换。

**先做一小段。**做三个物体与两个可放灯的位置，观察玩家是否会主动换角度，而非靠撞墙试形状。

**需要守住的边界。**实际碰撞不能与推断无关；历史影子首次出现时给可验证差异，避免所有误判都被归为超自然。

<a id="g04"></a>

## G04｜热是一封迟到的信

[原始构思](../01-探索与感知/感知不只是视野.md#g04)

**玩家实际会做什么。**玩家切到热感层，比较椅子、门把手和杯子的余温，也能放热源制造痕迹。

**可以这样实现。**物件保存最后受热时间、热量与冷却类型，按简单曲线衰减；接触产生热转移事件。敌人读取热痕位置与年龄，不直接锁定本人。

**先做一小段。**一间屋放两把刚被碰过的椅子、一只持续加热的炉子，让玩家判断谁离开得更晚。

**需要守住的边界。**不必流体模拟；持续热源与人体余温需有可辨差异，颜色之外用纹理、读数区间辅助。

<a id="g05"></a>

## G05｜先闻到家

[原始构思](../01-探索与感知/感知不只是视野.md#g05)

**玩家实际会做什么。**玩家沿气味提示找源头，开窗、堵缝或移动带气味的布料改变路线。

**可以这样实现。**房间图的边记录风向和通气率，气味分类型在离散步中扩散；界面显示方向扇区与浓淡描述。

**先做一小段。**四间房、两个通风开关和两种气味，验证玩家能否通过改变气流排除一个错误来源。

**需要守住的边界。**低频更新足够；混合气味不能只剩视觉噪声，所有关键类型都要可单独关注。

<a id="g06"></a>

## G06｜只有闭眼才认得路

[原始构思](../01-探索与感知/感知不只是视野.md#g06)

**玩家实际会做什么。**按住闭眼后，眼前画面淡去，熟悉路线以步距和触碰提示出现。

**可以这样实现。**保存最后经过路径及地标；闭眼时显示这份记忆，碰撞仍由当前现实决定。接近已改变障碍时给触觉文字与短促声。

**先做一小段。**让玩家先明眼走过一条路，再改变一处门，让他在睁闭眼交替中找到差异。

**需要守住的边界。**不取消基本碰撞反馈；设置自动停在未知落差边缘的辅助选项，不把闭眼操作变成盲走摔死。

<a id="g07"></a>

## G07｜照亮也是作证

[原始构思](../01-探索与感知/感知不只是视野.md#g07)

**玩家实际会做什么。**玩家移动灯，观察对象从不稳定变成确定，某些重要对象需要额外确认。

**可以这样实现。**对象有候选状态、观察者与锁定状态；光照射线达到阈值后固定候选。一次性剧情确认与可逆空间锁定分开处理。

**先做一小段。**一个转桥和两个落脚处，验证移灯、留灯、借灯是否各有可解释的用途。

**需要守住的边界。**先只允许桥和门参与，不让所有摆件都变状态；不可逆结果不能被随意扫过的手电误触。

<a id="g08"></a>

## G08｜你的身体是测量工具

[原始构思](../01-探索与感知/感知不只是视野.md#g08)

**玩家实际会做什么。**背人、携带长物或换鞋后，身体可通过的路线改变，玩家能事先试探。

**可以这样实现。**角色记录宽度、高度、负重与地面适配标签；连接声明通行条件，近门显示身体轮廓预览。动作耗时与属性挂钩。

**先做一小段。**同一房间放窄缝、低门和湿坡，比较空手与背人两次路线选择。

**需要守住的边界。**尺寸变化不应把角色卡进墙里；放下人和物件需要安全点，提供返回已知路线的办法。

<a id="g09"></a>

## G09｜看见的人越多，真相越少

[原始构思](../01-探索与感知/感知不只是视野.md#g09)

**玩家实际会做什么。**玩家邀请不同同伴来到现场，一起观察并讨论有分歧的部分。

**可以这样实现。**每位角色对候选事实持支持、反对或未知状态；现场证据能改变立场，只有满足该对象的见证规则才固定。

**先做一小段。**三人两种记忆一份现场证据，验证玩家能否通过证据改变结论，而非只凑人数。

**需要守住的边界。**不要通用多数决；无法调和时保留分歧并提供其他路线，避免剧情角色被当成开门筹码。

<a id="g10"></a>

## G10｜你听见的是将要发生的事

[原始构思](../01-探索与感知/感知不只是视野.md#g10)

**玩家实际会做什么。**玩家听见近期可能出现的声音，再安排自己的动作去利用或阻止它。

**可以这样实现。**只预测已排定的确定事件：维护短时事件队列，提前播放对应声。玩家改条件后取消旧预告，并显示变化痕迹。

**先做一小段。**先做自动落物和定时门，再做玩家预约发声，检验他能否区分预告与当下。

**需要守住的边界。**不预测任意玩家输入；无法取消的命定事件必须另作规则说明，不能与条件预测混用。
