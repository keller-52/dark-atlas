# 生态：逐条实现思路

这是候选做法，不是已经完成的功能。共用规则见[先搭什么底座](先搭什么底座.md)；先验证条目里的小场景，再决定是否扩展。

<a id="e01"></a>

## E01｜灯光也会过度捕捞

[原始构思](../03-追逐与生态/黑暗里的生活.md#e01)

**玩家实际会做什么。**玩家调灯朝向和时段，观察虫群、捕食者与植物变化。

**可以这样实现。**按区域汇总照明强度，三类生物用阈值与延迟响应；生物数量先用群体代理，近处才显示个体。

**先做一小段。**一条街三盏灯，做出人能走且植物能开的布置。

**需要守住的边界。**不要求全生态模拟；用延迟和趋势反馈防止频繁开关刷资源，允许稳定方案省心运行。

<a id="e02"></a>

## E02｜黑暗是需要保护的栖息地

[原始构思](../03-追逐与生态/黑暗里的生活.md#e02)

**玩家实际会做什么。**玩家留食物、听回应、查看次日痕迹，与看不见的生物建立习惯。

**可以这样实现。**生物有隐藏位置和可观察副作用，只有在无人直视、光照合规时移动；食物与回应由状态机处理。

**先做一小段。**一间屋三晚，形成可预测的取食习惯，再出现一只幼崽的迹象。

**需要守住的边界。**看不见不等于随机；每次缺席有可查原因，误照后能修复关系，避免永久失去内容。

<a id="e03"></a>

## E03｜道路需要休息

[原始构思](../03-追逐与生态/黑暗里的生活.md#e03)

**玩家实际会做什么。**玩家轮换路线、安排居民分流，让道路恢复。

**可以这样实现。**边记录近期通行负荷与恢复速率，到阈值切换损耗阶段；居民路线可批量调整，地图显示趋势。

**先做一小段。**两条并行路线和一批访客，验证分流是否产生不同而清楚的结果。

**需要守住的边界。**无人的时间应能自然恢复；设自动分流选项，别让维护条变成每天同一份家务。

<a id="e04"></a>

## E04｜你种的不是资源，是路标

[原始构思](../03-追逐与生态/黑暗里的生活.md#e04)

**玩家实际会做什么。**玩家种植物路标，等生长方向揭示水、风或人声。

**可以这样实现。**植物记录环境采样目标与几档生长状态，使用预制形态朝有效方向变化；成长到一定程度即可读取。

**先做一小段。**三种种子两处未知来源，让玩家用种植位置提出假设并验证。

**需要守住的边界。**允许等待快进与移植；关键线索不能因种错一次永久消失，不扩展成复杂农场配方。

<a id="e05"></a>

## E05｜洪水不是灾难倒计时

[原始构思](../03-追逐与生态/黑暗里的生活.md#e05)

**玩家实际会做什么。**玩家查看潮汐预测，在不同水位走陆路、船路或浮屋连接。

**可以这样实现。**水位用周期函数或离散阶段控制通行边、浮体锚点和危险区；只在阶段边界更新寻路。

**先做一小段。**同一区域在低、中、高水位各有一条优势路线，测试等待是否也是有效选择。

**需要守住的边界。**不能淹死暂停菜单里的玩家；等待前预览安全性，退潮搁浅提供恢复办法。

<a id="e06"></a>

## E06｜一座城在睡觉

[原始构思](../03-追逐与生态/黑暗里的生活.md#e06)

**玩家实际会做什么。**玩家观察城市呼吸，疏通阻塞，降低某区的不适。

**可以这样实现。**全城共用呼吸相位，各区域把相位映射为门开合、温度和音效；病灶用独立状态影响节律。

**先做一小段。**一段随呼吸开合的通道与一处可疏通管道，让玩家靠规律通过。

**需要守住的边界。**节奏有视觉提示并可放慢；不要每条路都要求等一个周期，修复后提供稳定通行。

<a id="e07"></a>

## E07｜怪物之间有礼貌

[原始构思](../03-追逐与生态/黑暗里的生活.md#e07)

**玩家实际会做什么。**玩家观察生物让路、鸣叫与优先级，使用手势参与。

**可以这样实现。**遭遇读取双方体型、携幼与信号标签，按有限礼仪表决定等待、让行或警告；第一次犯错先警告。

**先做一小段。**一个路口三类生物，玩家用两种合适方式通过。

**需要守住的边界。**礼仪必须从观察中学到；禁止任意隐藏规则，提供笔记与重复演示，不靠瞬杀教学。

<a id="e08"></a>

## E08｜天气会搬动秘密

[原始构思](../03-追逐与生态/黑暗里的生活.md#e08)

**玩家实际会做什么。**玩家看天气预报，选择何时调查同一处痕迹。

**可以这样实现。**线索定义可见天气条件与稳定性，天气按可预测日程切换；局部雾机或遮雨物提供有限干预。

**先做一小段。**一扇门在霜、雨、晴三种状态呈现不同证据，合成一个判断。

**需要守住的边界。**可等待且保留已见记录；关键证据的窗口要可再现，避免错过一次只能重开。

<a id="e09"></a>

## E09｜你留下的东西成为别人的工具

[原始构思](../03-追逐与生态/黑暗里的生活.md#e09)

**玩家实际会做什么。**玩家把物品留在公共区域，回访看居民如何借用或改造。

**可以这样实现。**物件保持唯一身份、持有人与位置历史；居民在日程点执行借用事件，留言说明去处，关键物品有追回流程。

**先做一小段。**梯子、旧灯和绳子各安排一位借用者，检验变化是否让人觉得有生活而非被偷。

**需要守住的边界。**核心谜题物不能消失到不可访问区域；借用与永久赠送分开，避免复制或误删资产。

<a id="e10"></a>

## E10｜地图上有迁徙的街区

[原始构思](../03-追逐与生态/黑暗里的生活.md#e10)

**玩家实际会做什么。**玩家根据约定和迁徙日程寻找街区，安排相遇而非追坐标。

**可以这样实现。**街区使用预制模块与少数泊位，搬迁在玩家离场时完成；地图记录下一站、离站时间和留守线索。

**先做一小段。**一个市场三个泊位，加入一次可以提前得知的改道。

**需要守住的边界。**熟悉后解锁预约或直达；不要每次购物都重复寻找，同一建筑内部保持稳定。
