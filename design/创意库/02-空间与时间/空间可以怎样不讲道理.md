# 空间可以怎样不讲道理

<a id="s01"></a>

## S01｜房间按照关系相邻

[查看实现思路](../09-实现规划/03-空间.md#s01)

厨房不在卧室旁边，而在“最近一起吃过饭的人”旁边。你改变人与人的关系，就改变建筑连接。吵架会拉长走廊，和解可能打开一扇原本不存在的门。

好玩的部分是通过生活行为改路：安排一次晚餐，比找钥匙更有意义。关系规则需要能观察，不能让玩家猜作者眼里的正确人情。

<a id="s02"></a>

## S02｜每个人都有自己的门

[查看实现思路](../09-实现规划/03-空间.md#s02)

同一扇门，你进去是仓库，邮差进去是街道，小孩进去是屋顶。玩家可以跟在别人身后借路，也可以通过工作、衣着或被承认的身份改变目的地。

最初像便利的伪装，后来会问：换一个身份之后，谁还认得你？身份不要只有一次开锁用途，让待遇、路线和对话一起改变。

<a id="s03"></a>

## S03｜出口在迁徙

[查看实现思路](../09-实现规划/03-空间.md#s03)

出口会像候鸟一样季节性移动。你调查门框留下的灰、等待的人群和风向，寻找它下一次落脚的位置。熟悉习性比跑得快更重要。

后面可以护送它穿过一个被堵住的区域。出口也会受伤，逃离变成照顾通道本身。别把追门做成随机刷新点的跑腿。

<a id="s04"></a>

## S04｜你带着唯一一间稳定的房间

[查看实现思路](../09-实现规划/03-空间.md#s04)

门框可以搬动，门内是一个始终不变的小房间。你从哪个方向放下门，出来时就以那个方向重新接入外界。屋里的摆设则保存你的旅行。

玩家会逐渐把临时据点当作家。困难可以来自如何把门送过狭窄地带，而不是随时没收它。稳定性是这套玩法给玩家的承诺。

<a id="s05"></a>

## S05｜重量改变楼层

[查看实现思路](../09-实现规划/03-空间.md#s05)

建筑像漂在水里的船。你搬走家具，某层会上浮；聚集居民，另一层可能下沉到新的入口。空间变动来自看得懂的整体平衡。

这让搬运与安置有了意义，也可以让玩家选择把人集中起来还是分散住。避免逐件搬箱子的重复劳动，允许安排搬迁、用滑轨或借助居民。

<a id="s06"></a>

## S06｜墙是两边共同维持的误会

[查看实现思路](../09-实现规划/03-空间.md#s06)

双方都以为对面没有人，墙就坚固。只要交换声音、物品或名字，墙会逐渐变薄。某些区域因此不是要击碎障碍，而是让两边开始交流。

也有居民确实需要边界，不希望墙消失。这里有一个很好的转折：玩家学会开路之后，还要学会什么时候不该开。

<a id="s07"></a>

## S07｜方向属于你携带的东西

[查看实现思路](../09-实现规划/03-空间.md#s07)

指南针指向家的方向，旧钟指向最早发生的事，戒指指向承诺的另一端。玩家可以同时携带几种方向，推断一个位置在不同关系中的坐标。

它适合做寻人和追忆，不需要假装复杂物理。给物件明确、稳定的指向逻辑，感人的例外最好只出现一次，而且能事后解释。

<a id="s08"></a>

## S08｜电梯不经过楼层，经过版本

[查看实现思路](../09-实现规划/03-空间.md#s08)

你按下同一层的不同年份，看见建筑在不同用途下的样子：医院、学校、避难所、旅馆。楼梯位置没变，使用方法却变了。

新的理解来自同一结构被不同人生活过。别每层都重复找电池修电梯；让某一版的日常秩序成为另一版的解题信息。

<a id="s09"></a>

## S09｜路会记住你怎样走过

[查看实现思路](../09-实现规划/03-空间.md#s09)

第一次你跑着通过，路就变得急促、狭窄；你停下来照顾过某人，路会形成能休息的凹处。移动方式会缓慢塑造空间气质。

这适合长期反馈，不适合毫无提示的即时惩罚。给玩家重走、修复和改变习惯的机会，不要让第一次操作永久决定所有后果。

<a id="s10"></a>

## S10｜迷宫是一场排练

[查看实现思路](../09-实现规划/03-空间.md#s10)

门只为“该上场的人”打开，幕后通道连接所有场景。你可以遵守剧本穿行，也可以改掉道具、挪动聚光灯、让演员提前离场。

黑暗是未被观众看见的后台。后期目标可以是让一场注定的事故不发生，同时让戏继续演下去。别只做对台词的谜语；保留空间操作和即兴补救。
