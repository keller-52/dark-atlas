# 时间留下什么

<a id="t01"></a>

## T01｜上一次的你继续走

[查看实现思路](../09-实现规划/04-时间.md#t01)

回溯之后，先前的行动由影子继续执行。你可以让它踩按钮、带灯、开门，自己走另一条路。影子不能临场反应，它只忠实重复。

变化来自两次行动的相遇，而不是不断堆更多影子。允许预览和快速重录，别让每次试错都重演一分钟无关的路。

<a id="t02"></a>

## T02｜房间有自己的年龄

[查看实现思路](../09-实现规划/04-时间.md#t02)

你能让一间房年轻或衰老，旁边的房间不受影响。树长大可以做桥，木门腐烂可以通过，但梁柱也会塌。老化不是万能破坏按钮。

最有意思的是在门槛两侧制造年龄差：水先结冰，管子仍然完好。剧情可落在“让某处保持原样”上，不必一直追求快进。

<a id="t03"></a>

## T03｜你只能给过去留下小事

[查看实现思路](../09-实现规划/04-时间.md#t03)

无法发送长信，只能挪一把椅子、在墙上刻一划、把杯子放在左边。过去的人会按自己的理解回应。你需要建立双方都懂的习惯。

限制让交流有质感。后面一把椅子的方向就足以传达危险。不要靠误解强行拖剧情；玩家应能逐渐形成可靠协议。

<a id="t04"></a>

## T04｜未来可以借，但会到期

[查看实现思路](../09-实现规划/04-时间.md#t04)

借用未来五分钟后的桥、伤口愈合后的身体或已经打开的门。到期后，世界会要求相应过程发生：桥必须有人修，钥匙必须真的被找到。

玩家是在安排因果上的欠账。适合少量重要选择，别堆成财务表；到期前要有补救路径，不能因为早期未知规则突然判死。

<a id="t05"></a>

## T05｜时间靠人流动

[查看实现思路](../09-实现规划/04-时间.md#t05)

有人的地方时间才前进。废弃房间一直停在离开那刻；你把居民带回去，植物开始生长，钟重新走，危险也重新发生。

探索变成安排谁在何处停留。一个人愿意留下陪伴某个房间，可能比一把钥匙更重要。不要让人完全退化成可搬运的机关。

<a id="t06"></a>

## T06｜只有回程会变老

[查看实现思路](../09-实现规划/04-时间.md#t06)

向未知前进时，世界保持清晨；原路返回时，时间才开始流逝。越执着回到起点，你越清楚看见那些地方的变化。

它把“我要不要回去看看”变成有分量的决定。适合短篇，规则太长时间高频使用会难以理解，也容易逼玩家永不回头。

<a id="t07"></a>

## T07｜你与同伴错开一分钟

[查看实现思路](../09-实现规划/04-时间.md#t07)

你们在同一片空间，时间相差固定的一分钟。对方关门时你可能还没走到，对方点的灯会在你需要之前熄灭。配合靠提前安排。

有时你能看见对方刚坐过的椅子，有时对方只听见你未来的脚步。给通信留下可靠渠道，别用输入延迟冒充时间机制。

<a id="t08"></a>

## T08｜失败被别人继承

[查看实现思路](../09-实现规划/04-时间.md#t08)

你死后切换到另一位进入者。前一位留下的绳、修好的桥和未完成的承诺都保留。新角色有不同的身体和动机，不是同一角色换名字。

死亡因此能产生社会历史，但不应鼓励刷死解锁。熟练玩家活着也能留下同样的帮助，失败只是另一种延续。

<a id="t09"></a>

## T09｜某些东西会逆着时间生活

[查看实现思路](../09-实现规划/04-时间.md#t09)

一种植物从枯萎走向发芽；你今天修好的钟，昨天的人会听见。你能利用这些东西传递信息，却不能直接控制它们的过去。

先展示一个能反复验证的小规律，再扩展用途。谜题的乐趣应在因果推理，不在事后解释任何矛盾都叫逆时间。

<a id="t10"></a>

## T10｜最后一天可以过得很宽

[查看实现思路](../09-实现规划/04-时间.md#t10)

大事件不可改变，但你能让同一段时间在不同房间里分别经历。你救不了整座城市，却能陪几个人走完各自的一小段路。

这里的重玩动力来自选择关注谁，不是收集所有死亡动画。给某些日常真正的完成感，也允许平静结局，不把徒劳当成唯一深刻。
