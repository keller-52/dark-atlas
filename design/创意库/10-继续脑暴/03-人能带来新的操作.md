# 人能带来新的操作

关系玩法最容易停在选对白。下面尽量让相处变成可以观察、安排、试错的行动，同时给对方保留自己的意愿。

<a id="b21"></a>

## B21｜你只能替别人问一次路

**点子。**陌生人不一定愿意告诉你住址，但可能愿意告诉他信任的某个人。你要找合适的中间人，把问题交给他，再接受对方愿意透露的程度。

**实现。**消息包含提问者、代问者、目的和接收范围；NPC按关系与信息权限给完整地址、约见地点或拒绝。中间人可以改变措辞，但不能凭空编答案。

**先试。**四个人、两条信任关系、一个寻人目标，让直接问和转问都有合理结果。

**别做过头。**不让社交图变成找颜色钥匙。中间人可能帮你得到一次见面，却不交出私人地址，这也应推进任务。

<a id="b22"></a>

## B22｜你与同伴各自只能携带半个答案

**点子。**某种线索离开一个人就会褪色。你和同伴分别记住不同部分，必须在行动时靠简短信号配合，而不是把信息全倒进玩家笔记。

**实现。**把任务分成不同观察权限和有限通信信号；同伴执行预先协商的条件动作，界面保留他明确告诉过你的内容。玩家可停下来复核约定。

**先试。**一人看水位、一人看门号，用两个信号合作通过三处门。

**别做过头。**单机同伴不能故意装笨；玩家可以请求重说，记忆负担不是核心难点。和 G09 的共同见证不同，这里强调分工行动。

<a id="b23"></a>

## B23｜一张餐桌是临时交通枢纽

**点子。**彼此愿意坐下来吃饭的人，其住处会在这一晚临时相邻。你决定邀请谁、留几个空位，既安排关系，也安排夜间路线。

**实现。**晚餐记录实际到场者与愿意接纳的连接，散席后生成有期限的门；邀请先征询双方，私人房间不自动完全开放。

**先试。**四人三座位、一段需借道的夜路，做出两种成立的饭局。

**别做过头。**这是 S01 的可操作仪式版本。别把吃饭全变成交通算题，保留无任务目的的座位和闲谈。

<a id="b24"></a>

## B24｜合作不是同步，是愿意等一等

**点子。**同行者走路、开门、观察的节奏不同。你可以先去探查再回来，也可以放慢、安排接应。游戏奖励的是理解彼此节奏，不是逼 AI 追上玩家。

**实现。**同伴有清楚的任务时长和主动停留原因，玩家可设置会合点与先后顺序；已走过的无事路段用短过渡省去等待。

**先试。**一快一慢两人、一处限时开门和两种配合方法，观察是否形成分工而非护送烦躁。

**别做过头。**慢不能只是惩罚。给同伴独特观察或工作贡献，允许玩家在安全段快进，别要求持续贴身跟随。

<a id="b25"></a>

## B25｜谁来宣布一条路安全

**点子。**你可以先走过去，但公共交通不会只凭你的成功就开放。要请不同身体、不同经验的人试走，并处理他们找到的问题。

**实现。**验路角色各自检查净宽、照明、坡度和地标。报告给具体位置与改进办法，达到公开标准后开启居民日程。

**先试。**一条玩家能轻松过的小路，经三人试走后暴露两个完全不同的问题。

**别做过头。**不要把角色简化成参数袋。试走可伴随个人目标，也允许认可多种修法，不必追求唯一完美工程。

<a id="b26"></a>

## B26｜一个人愿意暂时替你保管恐惧

**点子。**主角害怕某种环境，可以在出发前向朋友说清最担心的事，约定一个具体回应。进去以后，那段约定会成为可以使用的行动，而不是抽象勇气加成。

**实现。**恐惧表现为有限交互限制，如无法独自进入完全封闭房间；可信约定提供一次呼叫、门外守候或可返回的信号。状态来自虚构角色设定，不诊断玩家。

**先试。**一处封闭档案室，允许陪同、保持联系和另找入口三条路。

**别做过头。**不把聊天描写成即时治愈，也不强迫直面恐惧才算成长。实际帮助应可见、可依赖。

<a id="b27"></a>

## B27｜你要帮两个人在不见面的情况下合作

**点子。**两位专业人士暂时不愿同处，却各自掌握修复所需的一半知识。玩家安排留言、交接和可检查的中间成果，让合作先于和解发生。

**实现。**工作订单拆成有输入输出的步骤，双方按自己认可的证据接手；不共享私人对白，只转交被同意的工作信息。

**先试。**修一部电梯，电工与木匠各做两步，玩家能安排不同交接次序。

**别做过头。**修好之后不自动让他们拥抱。区别于普通传话任务，每次交接都要检查或改变实际设施。

<a id="b28"></a>

## B28｜传闻会比你先抵达

**点子。**你的经历会沿交通网络传播。你可以赶在传闻前解释，也可以让可信的人带一封更准确的说明。到达顺序改变初次见面的态度。

**实现。**消息作为带来源与版本的对象沿居民日程移动，接收者存最先听到和后来修订的内容；传播在关键节点批量推进。

**先试。**三个聚落两条传播路线、一个被夸大的事件，让玩家选择快路解释或慢路收集证据。

**别做过头。**不做全城无限谣言模拟；给版本来历和修订机会，不能一次误传永远锁死所有人。

<a id="b29"></a>

## B29｜有人想学你的坏习惯

**点子。**一个崇拜主角的孩子模仿你翻窗、乱画路标和硬闯危险区。玩家需要重新思考示范，或承认某些做法只适合自己。

**实现。**孩子只学习少量被当场看见的动作，拥有不同身体与风险判断；教学对话和演示能建立例外，不监视全部玩家输入。

**先试。**两种可模仿动作，一种对孩子不合适，提供解释、替代示范与修环境三种处理。

**别做过头。**不要突然让孩子因玩家普通操作死亡。先给清楚预警和补救，重点是责任如何改变动作意义。

<a id="b30"></a>

## B30｜真正的帮助是让自己以后不用再来

**点子。**玩家起初替街区做所有事，后来需要让居民自己维护设施、传递知识和处理例外。最终验收是一段你不在场的普通日子。

**实现。**每项工作有知识、工具、可用时间三个条件；居民通过培训和交接获得条件，离场模拟只运行有限事件并生成日志。

**先试。**供水、照明、送饭三项工作，安排两位居民和一份可读说明，模拟一天。

**别做过头。**不同于纯升级自动化，这里要验证别人是否理解，以及计划失败后能否自行补救。居民可以主动提出比你更好的做法。
