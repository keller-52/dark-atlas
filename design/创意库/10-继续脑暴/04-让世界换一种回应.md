# 让世界换一种回应

这一组更适合改变中后段的目标：玩家已经会探索了，世界怎样回应这份熟练，才能不只是再加一层雾？

<a id="b31"></a>

## B31｜一关的目标是制造一场可信的误会

**点子。**你要保护一个不愿被发现的人，就得让调查者沿证据得出另一种合理解释。重点不是放一张假纸，而是安排痕迹之间能互相支持。

**实现。**调查者使用少量证据关系进行推理，玩家可改变脚印、物品归属与时间记录；系统显示已知哪些线索会被检查，但不直接给最终答案。

**先试。**一间空屋四条可改痕迹，至少两种一致解释能通过调查。

**别做过头。**给调查者一套玩家能逐渐学会的判断方式。解法应能通过试探验证，不能到最后临时增加一条从未出现过的证据来否定计划。

<a id="b32"></a>

## B32｜城市需要一处永远找不到的地方

**点子。**某个秘密花园只有在没有公开路径时才存在。你不去寻找它，而是管理信息，让需要的人能偶尔抵达，任何人都不能把它据为私有。

**实现。**花园入口在满足匿名引导条件的几个节点间出现；公开坐标使当前入口关闭，但保留恢复匿名的方式。游戏明确哪些发布行为算公开。

**先试。**三种引导方式：精确图、模糊地标、可信陪同，观察谁能抵达以及后续变化。

**别做过头。**与 M05 留白相邻，但这里把不可垄断的公共空间作为目标。私人笔记或无障碍记录不应被当作违规曝光。

<a id="b33"></a>

## B33｜敌人会把你的陷阱当成家

**点子。**你原想引怪物进死胡同，后来发现那里恰好满足它的生活需求。它定居后不再追你，却会保护那一带。一次战术动作成为生态安排。

**实现。**敌人有觅食、追踪、休息与定居条件，陷阱区域满足需求后切换长期状态；玩家能从取食和筑巢迹象读懂变化。

**先试。**两个诱导区域，一个只困住它，一个适合生活，比较后续路线和行为。

**别做过头。**不能所有怪物都喂一下就驯服；定居是一个特定物种的规则，也需要考虑原住民。

<a id="b34"></a>

## B34｜世界开始按照你的攻略生活

**点子。**你写的路线建议被居民广泛采用。最短路变拥堵，冷门商店突然有人光顾，原本安静的角落需要重新协商。攻略越成功，原答案越不再合适。

**实现。**路线发布后按有限访客群更新通行负载与服务需求；版本修订能分流，世界变化以日为单位结算。

**先试。**两条路三类使用者，发布、观察、修订一次，形成反馈循环。

**别做过头。**区别于 M04 的初次公开后果，这里关注持续维护建议。不要每次传播都必然变坏，允许成熟的稳定方案。

<a id="b35"></a>

## B35｜结局后，清理一场成功的冒险

**点子。**主线结束，你再走一遍路，收回临时灯、补上砸破的门、把借来的工具还掉。你看见自己的“精彩通关”对别人留下了什么。

**实现。**重要破坏和借用事件生成可选收尾点，地点重新加载和平版本；每次清理更新住户生活，不设百分百清洁奖杯门槛。

**先试。**三处收尾：归还、修复、决定保留一件已经被大家使用的东西。

**别做过头。**它应是一段有节制的尾声，不是通关后强制大扫除。正常冒险造成的损坏也不必全部道德化。

<a id="b36"></a>

## B36｜救出去的人又回来了

**点子。**玩家以为撤离就是好结局，但有人自愿回城工作、探亲或照顾生物。你开始修建往返路，而不是只追求一次性逃离。

**实现。**获救人物在后段有自己的返程目标，玩家可协助制定风险计划；路线从撤离单向图转成可持续双向交通。

**先试。**一位返城者、两种合理理由、一条需要改造的往返路。

**别做过头。**别用“原来营救白做了”否定前段。营救给了他选择，回去是新的主动决定，必须有知情与准备。

<a id="b37"></a>

## B37｜你要允许某条路自然消失

**点子。**一条旧路需要不断维修，却已经很少有人使用。它的消失能让河流恢复，老住户又确实舍不得。玩家处理的是如何结束一项维护，而非永远增加设施。

**实现。**路有维护事件、实际使用需求和替代方案，停修后分阶段退化；先安排必要通行，再让环境恢复。

**先试。**一座旧便桥、两位使用者、一种替代渡法，允许保留、改建、退役三种结果。

**别做过头。**不把自然永远写成正确答案。费用与需求只作具体依据，不用抽象总分决定居民是否值得被照顾。

<a id="b38"></a>

## B38｜坏结局里仍有一件值得完成的小事

**点子。**主计划失败后，游戏没有立刻读档。你仍能把一封信送到、让两个人见面，或者把灯放在后来者看得见的地方。这段行动不是偷偷逆转失败，而是让失败之后仍有生活。

**实现。**主目标进入失败收束状态，开放少量与实际历史匹配的后续目标；玩家可选择继续或回到明确的早期存档，不自动覆盖。

**先试。**一段失败后五分钟以内的可玩尾声，至少两件小事可选，不依赖新收集品。

**别做过头。**先清楚告知主计划已失败，不假装还能完成来拖人。重试与接受结果都得到尊重。

<a id="b39"></a>

## B39｜下一章从你没走的那条路开始

**点子。**前一章的选择会决定下一章的起点：你没有亲自探索的支路，可能是另一个角色生活的地方。玩家从自己的盲区进入新视角。

**实现。**每章只有两三条手工支路，记录探索程度与关键选择；后章从未见或少见区域对应的完整片段开始，随后汇入公共结构。

**先试。**两章、两条分支、两种开场，比较是否真正获得新信息和新行动。

**别做过头。**不靠程序即时生成整章。若玩家全都走过，就让另一个人物视角提供新意，不惩罚喜欢探索的人。

<a id="b40"></a>

## B40｜最后一次探索由别人描述给你听

**点子。**终章里你留在据点，另一人带着你整理的地图出发。你只能收到有限描述，靠之前的知识提出建议，同时相信对方能自己判断。

**实现。**远行者按独立知识图走路，在重要节点发出结构化观察；玩家选建议、请求核实或承认不知道。画面可呈现想象草图与实际回报的差异。

**先试。**六节点三次通信，一次你的地图过时、一处对方发现的新路，提供多种成功过程。

**别做过头。**这是 X20 的远程协作版本。不能让对方只会照指令，通信也不应靠猜作者描述；重要信息允许澄清和重读。
