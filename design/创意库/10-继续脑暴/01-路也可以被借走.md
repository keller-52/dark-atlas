# 路也可以被借走

这一组把空间当成可以安排、交换和使用的东西。新意不只在门通向哪里，也在谁能用、什么时候用，以及开出一条路会占去什么。

<a id="b01"></a>

## B01｜背包摊开就是一块地形

**点子。**背包里的摆放不只是收纳。把它铺在地上，里面的格局会长成一小段现实：长棍是桥，布是遮雨棚，杯子是蓄水井。你要在好携带和好使用之间取舍。

**实现。**用小网格背包保存物件占格与朝向，展开时将组合映射到预制地形模块。只允许在标记空地展开，预览人物与关键出口是否被挡。收起前检查有没有居民或非随身物停留。

**先试。**六格背包、四件物品、两处不同缺口。看玩家能否为了下一段路主动改装，而不是每次塞进唯一标准答案。

**别做过头。**不需要任意物体自动生成地形，也不要每走几步就重排。和 X13 的箱中世界不同，这里关注临时使用的空间与携带安排。

<a id="b02"></a>

## B02｜你可以把捷径借给别人

**点子。**一条短路只能同时服务一个目的地。你可以暂时把它借给赶着送药的人，自己走远路；对方用完后会把路还回来，也可能请你再延一会儿。

**实现。**捷径是可移动的连接资源，借用记录使用者、两端和归还条件。归还按完成事件触发，地图显示现在服务谁；主动召回前先等通道内的人走完。

**先试。**三个地点、一条可借捷径、两个时间需求不同的人。让玩家能从效果中看见自己的绕行帮了什么忙。

**别做过头。**借出不是定时点收菜。把归还与具体事件绑在一起，允许事先约定，不因玩家离线或暂停而算违约。

<a id="b03"></a>

## B03｜全世界只有六扇门

**点子。**你能在墙上装门，但总数固定。开新路，就要决定拆掉哪扇旧门。原本属于个人的捷径，后来可能已经成了别人的日常通道。

**实现。**门是唯一编号的实体，安装点是预设插槽。拆门前展示受影响路线与正在使用的人，关键地区保留不依赖这批门的基础出口。

**先试。**五间房、三扇门和一名会使用通道的居民。让玩家先为自己布置，再面对一个合理的新需求。

**别做过头。**门数只是原型参数，不是定死六扇。区别于 M06 的折图，这里真正的压力来自有限设施被多人使用。

<a id="b04"></a>

## B04｜地图比例尺会占用现实

**点子。**你把某个房间在图上放大，现实里它就变得宽敞；代价是相邻空间被挤窄。可以给病人留出轮椅通路，也可能压缩自己的回程。

**实现。**不用连续缩放整张关卡。每房间预做窄、常规、宽三种尺寸版本，用一个区域面积预算约束组合，切换通过可移动隔墙表现。

**先试。**三个相邻房间、两种身体宽度、一条固定安全边界。玩家需要安排空间而不只是最大化当前房间。

**别做过头。**变化不能压死站在边上的人；提交前预览并暂缓有人占用的切换。也不要让全部家具自动缩成不可信的小模型。

<a id="b05"></a>

## B05｜门要等你离开才会开

**点子。**一种门不接受“我想进去”，只接受“这里的人需要出去”。你得从另一侧安排一次真实离开，或者把求助传进去，让通路从里面开始。

**实现。**门使用出口需求事件而非靠近触发。居民目标、送入的物件或里面启动的工作能产生需求；门打开后维持清楚的通行窗口。

**先试。**一个门内住户、一条传话管和两个可提出的理由。允许对方拒绝，玩家仍能走另一条路。

**别做过头。**不能把人骗到危险处才算聪明。这里考验从别人一侧理解空间，门的条件必须能观察。

<a id="b06"></a>

## B06｜用绳结保存一段路

**点子。**每经过一个岔口，绳上就多一个结。把绳交给别人，他可以依靠结的顺序认路；把两段绳接起来，能提出一条你从未完整走过的路线。

**实现。**绳结编码相对转向与地标，而非直接保存全图坐标。接绳时校验两段交接地标，错接给出不一致提示，不能凭空生成道路。

**先试。**两位角色分别探索两段路，在一个共同地标交接，合成送药路线。

**别做过头。**结不必真的考手工打结，支持图形编辑与语音说明。它比一般地图更强调路线如何被交给不同的人。

<a id="b07"></a>

## B07｜你能购买一次“经过”，不能拥有那条路

**点子。**有些通道需要用实际帮助换来一次通行。你可以先囤经过的权利，也可以托一个更合适的人代用；如何使用，比攒钱更重要。

**实现。**通行凭证绑定路线、次数与可转交对象，条件可从修理、照看、运送等任务事件取得。交易界面明确说明一次是单程还是往返。

**先试。**两条收费性质不同的路、三件互相可替代的帮忙事项、一名可代办的朋友。

**别做过头。**主线至少有低成本慢路，不能让人花错票后软锁。不要把所有社交都货币化，普通善意也应存在。

<a id="b08"></a>

## B08｜路权需要接力

**点子。**某种不稳定走廊只在两端都有人守望时存在。你不能一个人把整条路永久点亮，但可以沿线安排交班，慢慢建出一条大家都能走的路。

**实现。**连接检查两端有效守望者，居民日程带班次；交班完成后才撤旧班。系统提前显示空档，提供临时支撑装置作为补救。

**先试。**三段走廊、两名同伴和一个临时支架。让玩家排一次班，随后亲自通过。

**别做过头。**与 R03 教认路相比，这里关注共同维持通行。班次不按现实时间运行，稳定之后能自动轮换，避免成为值班管理软件。

<a id="b09"></a>

## B09｜小路会把使用者变成路标

**点子。**走过某种路，衣服上会留下只有当地人认得的纹样。你因此能问到新消息，也可能被误认成某个社群的人。路线选择改变你呈现给世界的经历。

**实现。**特定连接添加可见经历标签，NPC只响应少数有内容的组合；玩家能解释、遮住或清洗，保留实际经历记录。

**先试。**两条路两种纹样、三位立场不同的人，验证改变的不只是门禁，还有相遇内容。

**别做过头。**不要把误认变成永久惩罚。与 S02 的身份门相邻，但这里让旅途主动写在身上，而非先选身份再开门。

<a id="b10"></a>

## B10｜你要修一条自己永远用不到的路

**点子。**你能在墙内钻行，要为一名无法钻墙的人修通地面路线。你探索时的便利，反而容易让你忽略别人真正的障碍。

**实现。**两种身体使用不同通行图，玩家能在关键点模拟对方视角，安装坡道、扶手和提示；最后由对方根据现场信息独立走一遍。

**先试。**四间房三种障碍，不给自动最优答案，只在试走后提供具体困难。

**别做过头。**这是 X20 的明确身体差异版本，重点验证理解能否被设计成可用的帮助。对方可以提出方案，不能只负责验收。
