# 工具不只是钥匙

这里想让物品改变操作方式，而不只是遇到某种颜色的门就用某种颜色的道具。

<a id="b11"></a>

## B11｜可以装进瓶子的安静

**点子。**你在安静房间打开瓶子，收走一小片寂静。之后把它释放在嘈杂区域，能听清细小线索，也能让靠声音相认的生物暂时失去联系。

**实现。**瓶子存一份有时限和半径的静音区域能力；释放后按声事件标签衰减，不降低玩家设备的全局音量。原取样处恢复普通环境声，无需抽象地被永远剥夺安静。

**先试。**一处安静源、一台噪声机器、一段细小回声，让玩家比较探听与潜行两种用途。

**别做过头。**别让它成为无限隐身。脚印、光和视觉仍有效；安静也可能切断自己的通信，要能提前知道。

<a id="b12"></a>

## B12｜摩擦可以涂在地上

**点子。**你能把几块地面变滑或变涩。让重物顺坡滑下，也能铺一段刹车带保护它；追逐时改地面，敌人不会凭空变笨，只是需要重新选路。

**实现。**第一版按格设置摩擦类型，移动物使用可预测的离散滑行规则，角色动作有清楚的起步与停步距离。画线前显示预计停点。

**先试。**一个重箱、一段坡、两处需要精准停止的位置，再加入一个会绕路的追兵。

**别做过头。**不要一开始依赖复杂刚体摩擦。玩家自己也受同规则影响，坡底需有恢复箱子的办法。

<a id="b13"></a>

## B13｜工具记得上一份工作

**点子。**一把剪刀刚剪过纸，接下来会倾向于把碰到的东西当纸处理；修门用过的锤子会去找接缝。工具习惯需要通过动作重新训练。

**实现。**每件工具只保留一个明确模式，由在训练物上完成动作切换；可作用目标列入手工规则表，外观和握持动作显示模式。

**先试。**一件工具三种工作记忆、两个可交叉解决的障碍。看切换是否产生计划，而非每门前换档。

**别做过头。**不承诺任意材质转换；历史模式要随存档保留，切换可逆，别在普通使用时暗改属性。

<a id="b14"></a>

## B14｜钥匙不是打开，是暂时锁住

**点子。**世界里的门平时都会自行变换。你手里的钥匙只能把某一扇固定下来。安全来自选择什么保持不变，而不是不停解锁新东西。

**实现。**门有周期候选出口，插钥匙冻结当前映射；拔出后继续周期。钥匙数量有限，但每区有不变的基础回路。

**先试。**三扇变换门两把钥匙，让玩家固定往返路线，再去探索未知出口。

**别做过头。**和 G07 固定现实相邻，这里把长期稳定与可携带工具绑在一起。冻结时门内有人怎么处理，必须先写清。

<a id="b15"></a>

## B15｜背着伤口去修桥

**点子。**你的身体是一张可修补的布地图。剪下一角能补一座断桥，但你暂时失去那部分感知；回来缝好，地图上的补丁会保留这段经历。

**实现。**身体分成有限功能块，各块对应一种明确能力；放置补丁在指定裂口生成通路。修复材料与取回方式可预览，不需要血腥表现。

**先试。**两种功能布片、一个缺口和一条回收路径，比较牺牲哪种能力更适合当前计划。

**别做过头。**不要让玩家不可逆失去基本导航或无障碍信息。它是虚构身体的取舍，不把真实伤残当作奇观。

<a id="b16"></a>

## B16｜你带的风来自另一个地方

**点子。**风袋能收集某处风的方向、温度与气味，在别处释放。吹动机关只是最简单用途，还能把故乡的一点空气带给困在地下的人。

**实现。**风袋保存有限属性标签与剩余量，释放生成定向场，影响布、气味边和特定温度装置。温度用离散档，不做气体动力学。

**先试。**两种风源、一个风车、一位能辨认家乡气味的人，让同一工具同时有实用和关系用途。

**别做过头。**每种属性都要能辨认；如果全部用途都靠标签开门，就删掉多余属性，保留真正可组合的两项。

<a id="b17"></a>

## B17｜相机拍下物体的用途

**点子。**拍下一张椅子不是复制椅子，而是取下“可以坐”的用途。你能把用途贴给树桩或大箱子，创造临时休息点。原椅子在用途归还前不再能坐。

**实现。**只支持少量可转移功能，如坐、照明、响铃。照片是唯一功能凭据，接收物必须满足兼容条件；转移和归还由事务事件完成。

**先试。**三件物体两种功能，让玩家为了居民日程临时重排生活设施。

**别做过头。**不声称能理解任意物体用途。物理承重与显示要一致，不能给一片纸贴“桥”就无条件承载所有人。

<a id="b18"></a>

## B18｜把一个动作交给物件保管

**点子。**你可以让门把手记住“轻敲三下”，让鞋记住“停一步”。后来别人触碰时，物件会替你做出这个小动作，用来传话或教路。

**实现。**录制受限动作片段而非任意角色动画，物件保存触发条件、次数与目标类型；执行前检查安全和场景有效性。

**先试。**一扇门、一双鞋、一位学路者，通过两个动作建立一段能独立使用的提示。

**别做过头。**与 T01 的整段回放相比，这里是可传递的小动作。限制动作集合，不能录下伤害后无提示地让 NPC 承担。

<a id="b19"></a>

## B19｜伞能替别人挡住视线

**点子。**在“被看见就固定”的世界里，一把伞可以保护某件事暂时不被确认。你得选择替谁遮住、遮多久，以及谁需要知道伞下发生什么。

**实现。**伞作为遮挡体参与视线检测，展开角度决定被保护对象；角色可请求跟随伞影。对象状态仍遵守 G07，不另造例外。

**先试。**一个会被观察锁定的移动物、一位同伴和一段公开走廊，比较单独遮挡与同行。

**别做过头。**不要让它等于所有敌人都看不见玩家。遮的是具体视线，脚步、边缘和伞本身都还存在。

<a id="b20"></a>

## B20｜罗盘指向你最近忽略的东西

**点子。**它不指目标，而指向你曾接近却没有调查的可选线索。走得越急，积累越多；你可以回头，也可以接受有些东西暂时不知道。

**实现。**当玩家进入可观察范围但未交互时，登记候选线索；罗盘按距离与最近经过排序，不读取眼球，也不推断真实注意力。已放弃的目标可隐藏。

**先试。**一个小街区五处可选细节，比较玩家是否愿意使用，还是觉得被任务清单纠缠。

**别做过头。**这是主动开启的回访工具，不能不停提醒或显示收集百分比。线索范围与“忽略”含义要在界面说清。
