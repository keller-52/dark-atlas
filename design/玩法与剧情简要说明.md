# 残光图志：玩法与剧情简要说明

更新：2026-10-28

本文供玩法 Demo 与剧情研究并行参考。基于世界版 v4 及后续讨论整理，是当前方向，不是最终定稿。仓库中的 200 条创意是备选素材，不是全部需要实现的需求。以下玩法尚未经过试玩验证。

## 一、希望玩家获得的体验

玩家扮演少年“墨”，陪活体移动木屋“老铁皮”穿越正在褪色的荒原，前往东海。

主要体验是观察地形、规划连接、利用猎犬规则开路，并带老铁皮一起通过。玩家逐渐熟悉它的习惯，在日常同行中喜欢上它。结尾希望留下怅然若失：旅途确实改变了人，但共同生活无法原样继续。不是大团圆，也不靠让所有人受难来制造重量。

## 二、玩法方向

### 核心循环

探索并发现锚点 → 在图册中规划连接 → 画桥、擦桥、引导猎犬 → 自己与老铁皮通过 → 发现新区域及人物。

- **固有陆地**：无需耗费活性墨线维持，普通地形记录免费。
- **雾化断层**：需要有限的活性墨线连接锚点，形成浮桥；擦除后收回连接额度。
- **图册推演**：打开图册时暂停世界，显示猎犬下一步的预计行动，以可理解的判断为主，不以反应速度为核心门槛。
- **老铁皮同行**：体型、路线与读图移动需求使它不能照搬玩家的捷径。“自己能过去”与“带它一起过去”应有区别，但避免冗长等待与机械护送。

### 巡图猎犬：主要解谜对手

猎犬只能沿有效墨线连接移动。玩家既要防止它接近老铁皮，也能利用它吞噬封路墨障。

当前候选行为是追向连通网络中吸引力最高的节点：普通节点 < 老铁皮驻点 < 新画连接 < 墨障 < 浓墨印章。具体数值、衰减和行动顺序留给 Demo 验证。

逐步探索三类玩法：
1. 擦断连接，隔离猎犬。
2. 用新连接或印章诱导它改变路线。
3. 引它拆除障碍，再重新安排自己、老铁皮与猎犬的通路。

巨犬与幼犬避让、宿敌凛交替改图属于后续扩展，不要求首个 Demo 全部实现。

### 回声、余温与绳结

- 回声以视觉波纹辅助判断空间、锚点与暗门，不要求纯听力辨向。
- 余温用于理解近期行动与环境线索，其具体用途待验证。
- 绳结记录路线、帮助自己和同伴认路，不等于能替代活性墨线架设重型浮桥。
- 寂静瓶可罩住远处噪音源，让圈外的人听见微弱线索；不会影响只读墨线的猎犬。

这些能力需要在前期自然使用，为终章无图归途提供基础，但不固定每幕交替结构或玩法占比，也不反复演练完整终局。

## 三、剧情概要

### 世界与人物

“褪色潮”使荒原通路逐渐变成断层。图册能暂时连接孤岛，也为猎犬提供路径。

墨与老铁皮在西境灯塔共同生活。老铁皮提出去东海，两人约好回来装上寄存的彩色旧木窗。它体内的原初炉芯正在损坏，旅途另有隐情。

旅途中遇到：
- **帕克**：依靠门轴声音认路的邮差，希望有地方可以敲门停留。
- **老石与阿禾**：面临迁居与治疗问题的修鞋匠和孙女。
- **凛**：经历猎犬灾难后，试图通过擦除道路阻止危险的对手。
- **赫伯**：参与过灯塔工程、保护欲过强的老救援员。
- **灰**：模仿墨、害怕被遗忘的小墨灵。

### 五幕走向

1. **西境灯塔与浅滩**：建立共同生活及回家装窗的约定，学习探路、架桥和带老铁皮通行。
2. **风鸣石谷**：帮助邮差与爷孙，在点亮航标获得交通医疗条件、保留暗处生态之间取舍。更好结果需要理解环境并付出实际努力；获得方式尚未确定，不将二周目设为既定要求。
3. **千桥废墟**：利用猎犬拆障，与凛争夺路线；老铁皮的编号与过去逐渐暴露。
4. **风雪驿站**：与赫伯、灰相遇，得知炉芯危机及东海冷泉是终止灾难的必要去处。墨追赶独自离开的老铁皮，赫伯参与救援。危险仍须遵守已教给玩家的规则。
5. **东海告别与归途**：老铁皮在冷泉永久熄火，变成海边不再移动的木屋。墨带着旧物与修窗材料返回，借助已掌握的回声、绳结和沿途留下的帮助走完无图归途。回到灯塔装窗、寄信；朋友在远方继续生活，何时重逢保持开放。

结尾主要依靠玩家完成行动、认出熟悉地点和感受到伙伴缺席，不集中逐项解释全部伏笔。

## 四、人物与叙事的取舍

- **不设专门的温馨间章**。性格通过正常探索、停靠、整理工具与同行回应自然体现，不强制玩家停留看风景或等待感动。
- 老铁皮有真实的偏好、疲惫和不足。不要把所有别扭与停机都解释成对墨的训练；具体“假装坏掉”桥段仍需取舍。
- **必要信息进入主线**：危险为何成立、告别为何必要、墨为何返回，不能依赖收集隐藏文本才能理解。
- **额外细节增加余味**：旧画、修补痕迹、收据等可以让玩家更喜欢人物，但漏掉它们不应改变主线的基本理解与情感走向。
- 不保证每位玩家在同一时刻顿悟，也不通过多份材料反复解释同一个心意。
- 温情、救援与高潮都遵守世界规则，不能为了演出临时让猎犬脱离墨线行动，或让老铁皮绕过既定移动限制。

## 五、供玩法 Demo 研究的边界

### 先验证什么

用少量平台、可改连接、一只猎犬和一个老铁皮占位角色，先验证：
- 玩家能否理解自己的操作为什么改变猎犬路线。
- 隔离猎犬、利用猎犬开路、带老铁皮通过是否形成不同判断。
- 是否存在“远端盖章—引犬—擦桥”的万能解。
- 失败后是否愿意尝试新方案，而不是重复劳动。

这是研究建议，不是锁死的关卡脚本。首个 Demo 无需制作完整剧情、美术、群像、终章或全部感官工具。

### 可独立调整，暂不影响剧情推进

行动与回合顺序、墨线额度、印章限制、吸引力数值、预览与撤销、关卡规模、双犬规则、凛的操作策略，均以原型结果为准。剧情只保留“利用猎犬突破封锁”等行为目标，不规定唯一按键序列。

### 必须与剧情协同的内容

- 带老铁皮通行需要产生真实的照顾与协作，而非单纯等待。
- 终章所需的无图辨向能力应提前自然建立；保留视觉回声等必要辅助，不突然改成记忆或听力考试。
- 终章与普通探索的差异主要来自伙伴缺席、路线意义变化和熟悉能力的重新使用，不能为了教学把前期写成反复训练终章。

## 六、仍未定案

更好分支的获得方式及是否涉及二周目；具体行动制与资源规则；无图探索的频率；老铁皮是否及何时故意制造独立尝试机会；结尾保留哪些旧物与伏笔。

当前不指定引擎、工期或最终流程时长，也不宣称规则已经完备或玩法已经验证。
