# 《暗区图志：请勿登记》（Dark Atlas: Unlisted）单机游戏完整设计大纲

> **核心命题：当整座城市都在要求100%的透明与测绘时，你手里的地图究竟是救人的路标，还是递给猎手的名单？**
> 本设计案从 `keller-52/dark-atlas` 的200个创意条目中精选并重组了 **24个核心机制与场景条目**，通过 **“50%冰冷掠食规则 + 30%零和利益冲突 + 20%笨拙善意”** 的黄金张力配比，构建出一款兼具硬核策略潜行、空间规则解谜与深沉人文余韵的单机游戏。

## 一、 游戏概览与核心立意（High Concept）

| 维度 | 核心设计说明 |
| :--- | :--- |
| **游戏名称** | **《暗区图志：请勿登记》（Dark Atlas: Unlisted）** |
| **类型与视角** | 2D/2.5D 俯视角 · 制图博弈 + 信息潜行 + 空间规则解谜 |
| **单局流程时长** | 主线约 10–12 小时（共五幕 + 终章尾声），支持多周目侧面视角重访 |
| **核心创意来源** | 主框架融合 **P04《请勿登记》** + **P01《不要相信回来的路》** + **P02《另一端的笔迹》**，故事基底取自 **W01《无人认领的街道》** 与 **W03《迟到的地图》** |
| **核心体验痛点突破** | 摒弃“全员恶人/跳脸惊吓”的廉价恐怖，同时拒绝“全员误会/无害化温情”的平庸套路；用真实致命的底层规则压迫感，衬托出黑暗中极其稀缺的善意与默契 |

### 1.1 世界观背景：被行政系统遗忘就会“黑化”的垂直都市
在巨型地下垂直都市 **“第三井区（Well-3）”**，空间的物理稳定性与市政厅的《全域普查图册》直接绑定。凡是被市政网络持续照明、登记门牌并定期巡检的街区，空间结构就保持稳固；而一旦某条街道因拆迁停滞、欠费断供或历史事故从市政名单上被抹除，灯光便会熄灭，走廊开始随潮汐、重量与声波发生错位，沦为 **“暗区（Unlisted Zone）”**。

然而，暗区并非死地。这里不仅滋生了顺着地图线条与人类习惯捕食的 **“规则掠食者”**，更庇护着一群无法在阳光下生存的 **边缘居民**（逃避清退的修鞋匠、无证匠人、身份冒用者）以及只能在绝对黑暗中繁衍的 **夜行共生生物**。

### 1.2 玩家身份：手握“双层图册”的外勤勘测员
你扮演一名刚接手亡母遗留辖区的年轻勘测员 **林（Lin）**。一封寄往“不存在地址”的欠费水单，将你引向了母亲生前负责的最后一片暗区。你的每次出发都带着两套截然不同的工具体系：
- **对公工具**：必须向市政厅定期提交的 **【公开蓝图】** 与能够强行锁定叠加态空间的 **【定影提灯】**。
- **对私工具**：母亲留下的 **【旧羊皮底图】**（上面不仅有旧时代的地形，还会浮现二十年前某人的实时笔迹）以及一把能替他人遮蔽观测的 **【黑伞】**。

## 二、 冲突与张力架构：拒绝“无害化”的三层阻碍设计

为了让探索的每一步都充满真实的紧张感与决策重量，游戏中的阻碍严格按照 **5 : 3 : 2** 的比例构建：

| 阻碍层级 | 占比 | 关联创意编号 | 核心对抗逻辑与玩家体验 |
| :--- | :--- | :--- | :--- |
| **第一层：冰冷无情的规则掠食者** | **50%** | **M02 / H02 / H03 / H04 / H07 / H09** | **不可谈判、没有苦衷的生存威胁**。怪物不靠移速碾压，而是靠读取你的地图、预判你的目的地或利用你的躲藏习惯猎杀你，逼迫玩家进行高智商的信息反制。 |
| **第二层：零和博弈的制度与同行** | **30%** | **M04 / N03 / C15 / S02** | **清醒的利益冲突，无法靠“道歉”解决**。同行竞争者会使用和你一模一样的机制拆毁你的路；市政猎手与征税员会顺着你公开的地图去抓捕暗区居民。 |
| **第三层：笨拙而珍贵的微光善意** | **20%** | **H05 / R01 / E02 / E07 / C07 / C08** | **高压之下的喘息与情感锚点**。正因为外面有真怪物与真掠夺，会闹别扭的移动安全屋、强行把你拽回安全区的老救援员、主动让路的盲眼巨兽才真正令人动容。 |

### 2.1 三大核心规则怪物（不靠加速的智斗追逐）
1. **【巡图猎犬（Carto-Hound）】—— 融合 `M02 擦掉一条路` + `H09 追逐发生在地图上`**
   - **猎杀规则**：它没有视觉，只能在玩家已经绘制成型的地图线条上移动。你的地图画得越完整、越精确，它包抄你的路线就越快。
   - **反制操作**：当猎犬的黑点在地图纸面上逼近时，玩家必须在现实中摸黑行动，同时打开图册 **用橡皮擦掉关键走廊**（切断它的寻路图，但自己也失去导航），或者 **手绘一张通往死胡同的假地图副本** 钉在岔路口引诱它扑空。
2. **【静室寄居者（Closet-Stalker）】—— 融合 `H07 它只在你确信安全时行动` + `H04 它会学，但也会误学`**
   - **猎杀规则**：颠覆传统恐怖游戏“躲进柜子/锁死房门就安全”的惯性。这种生物专门在 **“四面封闭、无光、绝对安静”** 的狭小空间里孵化生成。你如果锁死门躲进储物柜屏住呼吸，3秒后它就会在柜内把你吞噬。
   - **反制操作**：藏身时必须刻意 **留一道门缝**、保持微弱的滴水声或敲击声；若连续使用同一种声源诱饵，它会学会绕开声源，玩家反而可以利用它的“误学”规律，把真正的补给线伪装成诱饵区。
3. **【截道影（Destination-Walker）】—— 融合 `H02 它追的是你的目的地` + `H03 它听得见你命名`**
   - **猎杀规则**：它从不跟在你屁股后面跑，而是根据你 **反复翻看的地图区域、背包里携带的专用工具、以及你在地图上写下的显眼地名**，推断出你要去哪里，提前在终点门后守株待兔。
   - **反制操作**：信息欺骗。想去东侧水泵房修阀门前，先在地图西侧标上大号的“核心仓库”，并在西侧走廊用热源伪造停留痕迹（`G04`），骗它去西侧蹲守后再走暗道奇袭东侧。

### 2.2 人类对手与制度压力（同规则对抗）
- **同行对手：04号首席勘测员“白鸦”（`N03 反派会做与你一样的操作`）**
  他是市政厅派来加速暗区清退的王牌。他没有任何洗白空间，纯粹信奉“秩序高于一切”。在第三、四幕中，他会与你在同一张大地图上实时博弈：**你会用提灯固定危桥，他就会远程击碎灯芯让桥在你脚下虚化；你给居民留下绳结路标，他就会移动路标把居民引向治安队的收容车。**
- **公开地图的连锁代价（`M04 公开地图会改变城市` + `M05 留白`）**
  每章结束向市政厅交图时，凡是被你画进【公开蓝图】的街道，第二天就会通电、来商贩，但同时也会迎来征税官与生态捕猎队。如何用少量的公开主干道满足市政指标，同时在支线上“合法留白”保护避难所，是贯穿全流程的战略难题。

## 三、 四大核心玩法系统与规则道具（Core Mechanics）

### 3.1 感知系统：视野之外的四重信息网
游戏默认视野极窄，但玩家拥有四套比肉眼更可靠的探路手段：
1. **回声测绘（`G02 声音先于形状`）**：敲击墙面或投石，声波以不同频率的视觉线条反弹——实心承重墙是短促红波，空旷大厅是绵长蓝波，墙后藏着活物则会传来不规则的杂音回波。
2. **余温追踪（`G04 热是一封迟到的信`）**：切换热感镜片，看不见人，但能看见“3分钟前有人握过的门把手”、“刚熄灭的炉火”以及“正在变凉的一杯茶”。你还可以用火柴加热空椅子，给追踪者制造假时间线。
3. **定影提灯与黑伞（`G07 照亮也是作证` + `B19 伞能替别人挡住视线`）**：暗区中的许多桥梁、门洞和信件处于“未观测叠加态”。提灯照射即可将其固定为当前物理形态；而撑开黑伞则能阻断市政探头或04号勘测员的视线，保护伞下的人或地形不被强制锁定。
4. **跨时空共绘底图（`M08 两个人画同一张纸` + `T03 你只能给过去留下小事`）**：你的底图连着二十年前母亲的图册。你们无法写长信，只能用约定的简笔画沟通（例如画三把椅子代表前方塌方），并请求二十年前的她在特定位置种一棵树或挪开一块砖，从而在二十年后的今天为你搭起树根桥。

### 3.2 空间与规则道具：不止是开锁钥匙
游戏中没有“红钥匙开红门”的枯燥设计，所有工具都遵循统一的物理与状态转移规则：

| 工具名称 | 关联编号 | 核心操作机制 | 典型高光用法 |
| :--- | :--- | :--- | :--- |
| **【折叠图板】** | **M06 / B04** | 在图册上沿折痕对折，折痕两侧的现实房间门洞会临时无缝拼接；放大某房间比例尺则会挤压隔壁房间宽度 | 将远处的安全屋直接“折”到濒死同伴门外；或把走廊缩窄卡住大型猎杀者，为轮椅居民放大无障碍通道 |
| **【寂静收集瓶】** | **B11** | 在绝对安静的房间打开瓶盖装走“一片寂静”，在别处摔碎后生成半径5米的静音力场（持续20秒） | 扔进噪音震耳的蒸汽机房听清墙后的求救敲击声；或在【巡图猎犬】身边制造静音带掩护撤离 |
| **【用途拓印机】** | **B17** | 拍下物体的“功能属性”生成相纸，贴在另一物体上使其获得该功能（原物体在撕下相纸前失去该功能） | 拍下餐椅的【可坐】属性贴在碎石堆上供老人歇脚；拍下蜂鸣器的【发声】属性贴在石块上做成远程声诱雷 |
| **【锁门秘钥】** | **B14** | 暗区的门每隔1分钟会随机切换连接的房间；把钥匙插进锁孔不是为了开门，而是将这扇门“冻结”在当前连接上 | 全游戏只有3把秘钥，玩家必须决定哪条退路值得永久固定，何时拔出钥匙去冒险刷新未知出口 |
| **【记路绳结】** | **B06 / R03** | 记录你走过的转向与地标操作，编成一条绳结交给NPC，NPC即可按绳结独立往返该路线 | 教会认路极差的邮差（`C01`）绕开危险区，建立据点间的自动物资与书信传递网 |

### 3.3 同行据点：“老铁皮”与关系操作化
你的基地不是地图上的固定点，而是一台会跟在你身后慢吞吞移动的四足老式勘测屋 **“老铁皮”（`R01 会走路的安全屋` + `C08`）**：
- **尺度互补（`G08`）**：你能钻过狭窄的通风管，老铁皮过不去；老铁皮能直接趟过带腐蚀性的浅水河道，你必须站在它的屋顶过河。
- **性格与互动（`V09 房子闹别扭`）**：没有饥饿条或耐久度惩罚。但如果你连续三次只从它肚子里拿物资就跑，回来时会发现它把床挪到了离门最远的角落背对着你；如果你带它去迁徙集市看风景（`E10`）、给它换上轻便的木门，它会在暴雨天主动把屋檐伸向你所在的走廊。

## 四、 五幕式完整剧情与关卡流程大纲（Campaign Outline）

### 第一幕：寄往不存在街道的水费单（新手引导与规则立威）
- **舞台区域**：第七沉淀池街道（潮汐水渠区）
- **融合条目**：`W01 无人认领的街道` + `M01 旧地图与过时` + `E05 洪水不是灾难倒计时` + `G02 声音探路` + `H01 足迹追逐`
- **剧情演进**：
  主角林收到一封寄给亡母的催缴单，地址是被市政注销十年的“沉淀池北街”。进入暗区后，玩家学会用敲击回声测绘地形，并发现母亲留下的旧地图虽然精确，但水位早已改变（`M01`）。
- **核心关卡体验**：
  利用高低水位周期（`E05`）交替探索地面与船道。下半程首次遭遇沿脚印追杀的暗区猎手（`H01`），玩家必须利用水位上涨冲刷掉自己的旧脚印，或故意踩出一条通往断桥的假回路甩掉怪物。在街尾的旧邮局里，你发现了母亲的旧羊皮底图，纸上突然浮现一行湿润的墨迹：“*谁在动我的备忘录？*”

### 第二幕：谁的灯光，谁的猎场（公开与留白的第一次零和抉择）
- **舞台区域**：无灯纺织巷 & 季节性迁徙夜市
- **融合条目**：`W02 请替我把灯关掉` + `M04 公开地图` + `M05 留白` + `E02 暗处栖息地` + `E07 怪物礼仪` + `C02 修鞋匠` + `V03 怪物让路` + `V07 不要替我开灯`
- **剧情演进**：
  市政厅下达指标，要求你测绘纺织巷并恢复强光电网。但进入巷子后，你遇到了为了把修好的鞋交给邻居孩子而拒绝撤离的老修鞋匠（`C02`）、请求你关掉门前路灯以免吓跑夜间伴生萤虫的独居老人（`V07`），以及在窄巷里只要你熄灯侧身敲地就会温顺收起骨刺给你让路的盲眼巨兽（`V03`）。此时，同行对手“04号白鸦”登场，警告你隐瞒不报将面临失职调查。
- **核心关卡体验**：
  玩家第一次面对 **【公开蓝图】与【私密底图】的提交抉择**：
  - 若将整条纺织巷如实画入公开图，次日回访时强光灯亮起，商贩进驻，但盲眼巨兽已被捕杀，修鞋匠也被强制清退；
  - 若使用 **【用途拓印机】（`B17`）** 与伪造的水位证据（`M09/B31`），向市政厅提交一份“该区已严重塌方无法通行”的假证词，并在私密底图上用触觉路标与绳结（`B06`）为居民搭建只有当地人懂的暗道，就能同时保住供电支线与暗区生态。

### 第三幕：纸上的追杀与墙上的刻痕（双时空交错与高压智斗）
- **舞台区域**：折叠档案塔 & 沉没旧校舍
- **融合条目**：`P02 另一端的笔迹` + `W03 迟到的地图` + `M06 折纸相连` + `M02 擦路防追` + `H09 纸面追逐` + `V02 楼下正在量身高` + `V05 不会追你的房间` + `V12 两份不一样的午饭`
- **剧情演进**：
  通过旧底图上的笔迹交流，你确认另一端是二十年前被困在校舍里的一名少年“阿彻”，以及当年正在调查水源污染的母亲。为了查明当年事故的档案，你们必须在两个时代同时潜入档案塔。
- **核心关卡体验（全作机制巅峰）**：
  1. **纸面与现实双重追逐**：档案塔内游荡着【巡图猎犬】。你必须一边在地图上擦掉走过的走廊（`M02`）、通过折纸（`M06`）将安全走廊拼接到面前，一边让二十年前的阿彻在过去挪动铁门替你挡住去路。
  2. **高压中的绝对温柔**：在整座建筑都在移动、猎犬步步紧逼的窒息感中，你推开一扇写着“*总得有个地方让人安心*”的普通洗手间门（`V05`）——这里没有任何机关和反转，真的绝对安全。
  3. **跨时空名场面**：休息时，你和二十年前的阿彻约好同时吃午饭，你吃着冷罐头，他在地图角落画了一盘歪歪扭扭的饺子（`V12`）；临别前他问你墙边哪里适合刻身高，你圈出柱子后，回到二十年后的废墟现场，手指抚过墙面——那排刻痕已经一格格长过了你的肩膀（`V02`）。

### 第四幕：不可洗白的断桥与救援哨音（真相揭晓与规则决战）
- **舞台区域**：第三井区主干断桥 & 深层剧场防空洞
- **融合条目**：`N06 真相不改变事实，改变责任` + `N03 反派同规则操作` + `G07 光固定现实` + `B19 黑伞` + `H05/C07/V13 过分认真的救援员` + `V08 出口门框上的抓痕`
- **剧情演进**：
  你抵达当年事故的核心现场，发现了一个残酷的真相：二十年前的大断桥**确实是母亲亲手炸毁的**（`N06`）。当年上层工业区发生剧毒泄漏，市政厅企图封锁消息任由毒水下排，母亲为了保住下层数万居民炸断了混流桥，但也导致第七街区彻底跌入暗区，数十名工人因此致残。没有“母亲其实是被冤枉的”洗白反转，只有沉甸甸的代价与尚未走完的善后路。
- **核心关卡体验**：
  04号勘测员“白鸦”带着强光锁定仪发起总攻，企图用强光永久抹除暗区通道。这是一场**完全对等的同规则Boss战（`N03`）**：他用强光固定死墙，你就用【寂静瓶】熄灭声控灯、撑起【黑伞】掩护迁徙的出口门（`S03/V08`）与居民撤离。
  在终局崩塌的绝境中，你的提灯破碎、退路断绝。此时你吹响了前几章一直觉得烦人、总想把你抓回安全区的 **老救援员铜哨（`H05/V13`）**。沉重的脚步声穿透黑雾，满脸伤疤的老救援员破墙而入，向你伸出手——而你认出他手臂上的旧伤，他正是二十年前在墙边量身高的少年阿彻。

### 第五幕（终章）：把迷宫交出去（非对称终极验收与尾声）
- **舞台区域**：第三井区共生路网
- **融合条目**：`B30 真正的帮助是让自己以后不用再来` + `X20 终点是把迷宫交出去` + `B40 最后一次探索由别人描述给你听` + `V10 熟路上的陌生扶手` + `B35 清理一场成功的冒险` + `V24 今晚是你等人敲门`
- **终极关卡设计（不用主角操作的终局大考）**：
  在第四幕的突围中，主角腿部受伤，回程时惊讶地发现陡坡上多了一排木制扶手——那是你之前教会认路的居民自发安装的（`V10`）。
  到了终章，市政厅的最终听证会只剩最后两小时，需要有人将完整的水质铁证与共生地图送过整片暗区，但你已无法亲自奔跑。**终章的玩法是“放手”（`X20/B40`）**：你坐在移动小屋“老铁皮”里，看着认路很差的邮差（`C01`）、修鞋匠的学徒和年轻的冒名者（`C15`）接力出发。你只能通过传声管听他们描述眼前的状况，依靠你对整座城市规则的理解给出建议，并见证他们用自己发明的土办法走完你修好的路。
- **可玩尾声（Epilogue）**：
  没有“红蓝绿三选一”的虚假结局门（`N08 结局是一种持续的做法`）。听证会结束后，暗区获得了自治缓冲权。你可以拄着拐杖慢悠悠地重走一遍安静下来的街道，收回当初为了逃命乱放的强光灯、补好被猎犬撞坏的木门、把借来的工具一一归还（`B35`）。最后回到“老铁皮”屋里躺下休息，听见门外传来熟悉的敲门声——有人给你送来了一盒还冒着热气的饺子（`V24`）。

## 五、 原型验证与防疲劳设计（Prototyping & Pacing）

为了确保这套设计在实际游玩中紧凑耐玩、不沦为繁琐的跑腿模拟器，开发上遵循以下三条铁律：

1. **三层状态严格解耦（防作弊底座）**：
   底层代码严格分离 **【客观物理现实】**、**【角色/怪物观测知识】** 与 **【玩家纸面地图显示】**。所有怪物（如巡图猎犬、截道影）严禁直接读取玩家的全局坐标，必须且只能根据其感知到的声波事件、余温残留或地图线条寻路，保证玩家每一次“演戏欺骗”都100%可预测、有回报。
2. **同一机制的四次情感变奏（防疲劳节奏）**：
   以 **“绘制与标记”** 为例：第一幕用来防迷路（求生）；第二幕用来决定谁被市政看见（责任）；第三幕用来擦除线条欺骗猎犬并与过去的人画画聊天（博弈与陪伴）；第五幕用来写成别人也能看懂的路标交出去（托付）。操作按键始终只有两个，但心境与目的每一幕都在进化。
3. **最小灰盒验证切片（Vertical Slice）**：
   先不制作复杂美术，用 **6个网格房间 + 1只只读地图线条的【巡图猎犬】 + 1把可擦除/折叠的地图板 + 1扇无条件安全的厕所门** 搭建15分钟的可玩原型。只要玩家在测试中能自己悟出“故意擦掉身后的路把怪物困在死胡同”并为此会心一笑，核心循环即告成立。
