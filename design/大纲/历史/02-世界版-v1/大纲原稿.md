# 《残光图志：未名之途》（Dark Atlas: The Uncharted Way）单机游戏完整设计大纲

> **核心体验命题：在一个正在被黑暗抹去地形的世界里，你画下的每一笔道路都能让孤岛相连，但也都在为顺着墨迹觅食的怪物指路。当没有体制替你兜底时，你敢把谁的名字写进地图？**

## 一、 重构设计说明：针对原版五大痛点的系统性革新

本设计案基于 `dark-atlas` 创意库重新筛选并深度打磨了 **16个高咬合度创意条目**，彻底摒弃原版“行政都市+机制堆砌+虚假双赢”的框架，向《OneShot》《Rain World》《Outer Wilds》等经典独立单机看齐，完成五大维度的核心重构：

| 原版痛点 | 本版重构方案 | 关联核心条目 | 
| ----- | ----- | ----- | 
| **1. 城市背景有“兜底感”** | **升格为无兜底的“残光世界”背景**：取消市政厅、水费单、听证会等现代行政架构。整个世界正在向虚无的“暗海”坍缩，唯有被测绘并有人行走的道路才能维持物理存在，没有任何上级机构替玩家兜底。 | `P01` `P03` `E10` `S03` | 
| **2. 机制过多且绕过路线规划** | **机制做减法，回归“路线规划”绝对核心**：彻底砍掉“跨时空共绘改写过去”、“折纸拼接房间”、“比例尺缩放”、“相机转移功能”等破坏地形约束的机制。全作仅聚焦 **【图册绘擦（固路vs引怪）】** 与 **【声/热双频感知】** 两大相互咬合的底层系统。 | `M01` `M02` `G02` `G04` `B06` `B11` | 
| **3. 解法违反已写出的规则** | **100%严密的物理与规则自洽**：①【巡图猎犬】只读地图墨迹，静音瓶对它完全无效，只能靠擦图或假拓片反制；②【寂静瓶】是“罩住远处高分贝噪音源”的吸音场，玩家站在力场外才能听清墙内微弱求救；③ 取消跨时空设定，彻底消除“少年20年后变老头”的年龄漏洞。 | `M02` `H09` `B11` `C07` | 
| **4. 宣称零和实则“造假双赢”** | **构建无后门的真实两难取舍**：取消“交假证词白嫖供电与安全”的设计。\*\*【落笔连入主网】**能稳固空间、引来医疗渡船，但必然招来顺图猎杀的猎犬并驱散暗处共生体；**【留白保持隐匿】\*\*能隔绝猎犬与保护夜行生态，但会导致道路慢性坍缩、物资断绝、重症者无法获救。隐瞒绝非万能解。 | `M04` `M05` `E01` `E02` `B37` | 
| **5. 群体矛盾宏大空洞、主角有家庭包袱** | **《OneShot》式无父母个体叙事**：主角“墨”是一名无父无母、在荒原边缘醒来的小描图员，唯一的目标是护送胆小固执的活体移动小屋“老铁皮”跨越荒原寻找归宿。全作不讲“民众vs体制”，只讲孤独个体之间的相遇、信念交锋与托付。 | `R01` `W04` `C13` `N03` `X20` | 

## 二、 世界观与个体叙事基底（World & Individual Focus）

### 2.1 世界背景：正在褪回“白纸”的残光荒原

这个世界没有名字，也没有统治它的帝国或市政厅。很久以前，一场被称为 **“褪色潮（The Uninking）”** 的灾变席卷了大陆——大地开始失去固定形状，像被水浸湿的炭笔画一样慢慢晕开、消散。

* **物理法则**：凡是没有被观测、没有被画进《残光图册》、也没有活人定期走过的荒野，地形就会在黑雾中不断漂移、错位，最终沉入不可逆的虚无。

* **生存困境**：残存的生灵蜷缩在零星的“锚定孤岛”（废弃驿站、沉没钟楼、迁徙集市、巨兽背脊）上。想要让两个孤岛保持连接、让渡船与药品能够流通，就必须由 **“缀路人”** 亲手走过黑雾，将路线画在特制的《残光图册》上，并点燃界碑。

* **残酷伴生**：然而，黑暗中也诞生了顺着“人类的认知与地图”捕食的规则怪物。地图画得越清晰，道路越稳固，顺着图线爬过来的掠食者就越精准。

### 2.2 核心角色：无父无母的描图员与想回家的活房子

本作采用轻量级单机的“纯个体视角”，全流程围绕主角与身边一个个具体生命的羁绊展开：

1. **主角：墨（Mo）—— 无父无母的见习缀路人**

   * 他没有显赫身世，也没有“替父母赎罪/查案”的血缘包袱。游戏开场时，他在世界最西端一座即将坍塌的孤岛灯塔里醒来，身边只有一本空白的《残光图册》、一支炭笔、一块黑橡皮，以及门外正被黑水泡得瑟瑟发抖的移动小屋。

   * 他身材瘦小、动作轻巧，独自处于绝对黑暗中过久会因为耳鸣而手抖（画图线条变歪），需要依靠微光、同伴的声音或小屋的炉火来恢复安定（`B26`）。

2. **核心旅伴：“老铁皮（Rusty）”—— 想回家的四足旧木屋（`P03` + `R01` + `W04` + `C08`）**

   * 它不是冷冰冰的基地车，而是一间长着四条生锈机械木腿、烟囱会像耳朵一样耷拉下来的活体老房子。它的门框内侧刻着一个早已从世界地图上消失的地名——**“东海造船厂·零号船台”**。它唯一的执念，就是在自己彻底散架前回到最初被造出来的地方看一眼大海。

   * **操作化关系**：它讨厌你只把它当储物箱。如果你连续几次进屋放下杂物头也不回地跑掉，再回来时会发现它把床搬到了离门最远的角落背对着你（`V09`）；但如果你帮它清理腿关节里的碎石、把窗户朝向有发光花田的方向、或者在雨夜陪它烧一壶热茶，它会在黑雾暴涨时主动迈开木腿冲到悬崖边，把屋檐伸过来接住你。

3. **同规则宿敌：“擦路人”凛（Lin）—— 决绝的孤岛守墓人（`C13` + `N03`）**

   * 她不是任何体制的走狗，而是一名曾经和你一样热衷于连接世界的老缀路人。三年前，她亲手画通了前往自己所住村落的精确地图，结果引来了成群的【巡图猎犬】，整个村落一夜覆灭。

   * 从此她彻底走向反面，手持能抹除现实路基的 **【空白石】** 游走于荒原。她的信条冰冷而自洽：**“只要所有孤岛都切断联系、烂在各自的黑暗里，怪物就会饿死。”** 她会使用和你一模一样的机制拆毁你的路、熄灭你的界碑、擦掉你的路标，是全作最具压迫感的智斗对手。

## 三、 阻碍与张力架构：拒绝“全员善意”的 5 : 3 : 2 配比

如果所有阻碍都是笨拙的善意，探索就会沦为毫无危机感的散步。本作将荒原上的阻碍严格划分为三个层级，用 **80% 的真实致命威胁与残酷冲突**，淬炼出 **20% 笨拙善意** 的催泪重量：

| 阻碍层级 | 占比 | 核心定位 | 玩家面对的真实处境 | 
| ----- | ----- | ----- | ----- | 
| **第一层：冰冷无情的规则掠食者** | **50%** | **纯粹的生态猎食，不可感化、不可谈判** | 它们不靠移动速度碾压，而是顺着你的地图墨迹、目的地意图和躲藏习惯猎杀你。一旦失误就会被撕碎，逼迫玩家吃透规则进行高智商反制。 | 
| **第二层：信念相悖的宿敌与荒原恶徒** | **30%** | **零和的生存争夺与同规则对抗** | “擦路人”凛会实时切断你的退路；荒原上的【盲眼拾荒团】会顺着你公开的航标灯抢掠聚落物资。他们各有残酷的生存逻辑，绝不会因为你的嘴炮而罢手。 | 
| **第三层：黑暗中笨拙而珍贵的善意** | **20%** | **高压绝境下的喘息与情感锚点** | 会闹别扭却替你挡雨的“老铁皮”、强行把你扛回驿站训话的老救援员赫伯、遵守礼仪给你让路的盲眼巨兽。正因为外面真的会死人，这一盏热茶才让人鼻酸。 | 

### 3.1 三大核心规则掠食者（100%规则自洽，严禁逻辑作弊）

#### 1. 【巡图猎犬（Ink-Hound）】—— 融合 `M02 擦掉一条路` + `H09 追逐发生在地图上`

* **底层感知规则（唯一信息源）**： 它没有眼睛，也没有耳朵，**现实中的声音、光线、气味对它完全无效**。它只存在于“地图拓扑层”与“现实空间”的交界处，**唯一能感知并移动的路径，就是玩家已经在《残光图册》上画出的墨水线条**。你的地图画得越完整、连通性越好，它在纸面上包抄你的速度就越快。

* **严密自洽的反制解法**：

  * ❌ **错误解法（规则证伪）**：朝它扔【寂静瓶】或蹲在阴影里屏住呼吸——毫无作用，只要你脚下的走廊还在地图墨线上，它会精准无误地咬断你的喉咙。

  * ✅ **唯一合法反制**：

    1. **断路摸黑（`M02`）**：当看见纸面上的黑点顺着墨线逼近时，立刻掏出黑橡皮**擦掉连接你所在房间的地图走廊**。猎犬在纸面上的寻路瞬间中断，只能在断开的墨线尽头徘徊；代价是你自己也失去了这片区域的地图导航，必须依靠刚才留下的余温痕迹（`G04`）或墙面回声（`G02`）摸黑找路。

    2. **假图诱捕**：在空白羊皮纸片上画一条通往死胡同或断崖的假分支，钉在岔路口的界碑上，将猎犬骗入死胡同后立刻撕掉假图，将其永久困死在孤立图块中。

#### 2. 【截道影（Destination-Stalker）】—— 融合 `H02 它追的是你的目的地` + `H03 它听得见你命名`

* **底层感知规则**： 它从不跟在你身后追脚印，而是读取你暴露的 **“目的地意图”**——包括你在地图上写下的显眼地名标签（如“核心水闸”、“避难所”）、你反复打开图册查看的固定区域、以及你提前在某个方向点亮的引路灯。它会直接走捷径去你的终点门后守株待兔。

* **严密自洽的反制解法**：

  * **声东击西（信息欺骗）**：想去北侧药库取药前，故意在地图南侧废墟标上大号的【重要仓库】字样（`H03`），并往南侧走两步用火柴加热沿途的门把手伪造行动轨迹（`G04`）。当你通过回声听见截道影沉重的脚步声被骗往南侧守候时，立刻不翻地图、靠记忆直奔北侧药库。

  * **私人暗语（`M05`）**：不在地图上给重要据点写文字名称，而是用只有自己懂的无意义涂鸦（如画一双倒放的鞋）代替文字标签，避免触发它的命名感知。

#### 3. 【静室寄居者（Hollow-Nester）】—— 融合 `H07 它只在你确信安全时行动` + `H04 它会学，但也会误学`

* **底层感知规则**： 彻底颠覆传统恐怖游戏“躲进柜子/锁死房门就绝对安全”的肌肉记忆。这种寄生生物的孵化条件是严格可观测的三个物理指标：**【四面封闭 + 完全无光 + 持续3秒绝对安静】**。当你锁死房门、熄灭提灯、躲进狭小柜子里屏住呼吸时，恰好满足了它的生成条件，3秒后柜壁就会裂开将你吞噬。

* **严密自洽的反制解法**：

  * **留缝与微响**：躲避其他怪物而不得不藏身狭小空间时，必须**故意给柜门留一道缝隙**，或者有节奏地轻敲木板保持微弱声响，破坏它的孵化条件。

  * **利用“误学”反杀（`H04`）**：它会记录你最近三次使用过的诱饵声源并学会绕开。你可以故意连续三次用发条八音盒制造噪音，等它学会“无视八音盒声音”后，把发条八音盒挂在自己身上大摇大摆从它领地走过。

## 四、 核心机制系统：极致聚焦的“制图”与“声热感知”

为了避免机制泛滥喧宾夺主，全作砍掉了所有空间瞬移与时间改写工具，所有关卡解谜与潜行博弈均由以下 **两套核心系统 + 三件规则工具** 驱动：

### 4.1 核心系统一：《残光图册》—— 落笔固路 vs 留白隐匿

玩家手中的图册不是UI界面，而是直接决定世界物理状态的唯一核心机制：

1. **落笔固路（锚定现实）**： 当你用回声与脚步探明一条走廊并将其画在图册上时，这条路就会从“漂移黑雾态”变为“稳固实体态”。只要墨迹还在，你和NPC、以及“老铁皮”就能安全快速地通过它，不会迷路。

2. **擦除断联（抹去存在）**： 用黑橡皮擦掉某段路，不仅能斩断【巡图猎犬】与宿敌“凛”的追踪，还能让原本被墙堵死的漂移空间重新洗牌；但代价是该路段再次被黑雾吞没，已建立的通行线立即中断。

3. **主网点亮 vs 私密留白（真正的零和博弈，`M04` + `M05` + `E01` + `E02`）**： 每个区域的界碑都可以选择是否将当前绘制的地图 **【拓印至航标主网】**。本作彻底取消“造假双赢”，两个选择各有沉重且不可逆的后果：

| 抉择方向 | 获得的真实收益（救赎） | 必须承受的真实代价（失去） | 
| ----- | ----- | ----- | 
| **【拓印主网 · 点亮航标】** | 1\. 区域空间永久稳固，“老铁皮”与重型渡船可直接驶入；  2\. 远方的医疗船与物资商队顺航标抵达，重病老人与受伤同伴得以获救；  3\. 视野开阔，主角不再因黑暗耳鸣而手抖。 | 1\. 航标强光永久杀死或驱离该区域的【夜光共生菌与盲眼温顺兽】（`E01/E02`）；  2\. 【巡图猎犬】与【荒原拾荒团】顺着主网墨迹大举入侵；  3\. 躲避追捕的无名逃亡者被迫流亡。 | 
| **【图册留白 · 熄灯隐匿】** | 1\. 绝对隔绝【巡图猎犬】与拾荒团的顺图入侵；  2\. 保护畏光的暗处共生生物继续繁衍，盲眼巨兽会继续为你修补地板、让出暗道（`V03/V07`）；  3\. 想要安静度日的隐居者保住家园。 | 1\. 道路无法稳固，每次往返都必须靠记忆与微弱余温在黑雾中重新摸索；  2\. 医疗船与“老铁皮”无法直接驶入，急需外界药物的伤者将因断供而病情恶化甚至离世；  3\. 长期留白的支线会在数日后自然风化消失（`B37`）。 | 

### 4.2 核心系统二：声与热的双频感知（`G02` + `G04`）

在视野极窄的黑雾荒原中，玩家依靠“听觉回声”与“视觉余温”理解世界：

* **回声测绘（`G02 声音先于形状`）**： 用炭笔尾端轻敲墙面或投掷石子，声波会以可视化的波纹反射回来——实心岩壁是短促的白波，空旷大厅是绵长的蓝波，木门与通风管是清脆的绿波，而潜伏着活物的角落则会反射出杂乱颤抖的红波。

* **余温读取与伪造（`G04 热是一封迟到的信`）**： 无需切换复杂滤镜，世界中的温度会以细腻的暖色残影呈现：3分钟前有人扶过的门把手泛着微红、刚走过的脚印留着淡黄余温、桌上一杯正在变凉的热茶能帮你精准推断屋主离开了几分钟。更重要的是，你可以**用火柴或热茶故意加热空椅子与假路线**，给追踪你的怪物或宿敌“凛”制造虚假的行动时间线。

## 五、 五幕式完整流程与关卡设计（Campaign Outline）

### 第一幕：泡在黑水里的铁皮屋（世界观立威与核心循环建立）

* **舞台区域**：西境沉没灯塔 & 潮汐浅滩（世界边缘的孤岛群）

* **核心条目**：`P01 不要相信回来的路` + `M01 旧地图过时` + `E05 洪水不是灾难倒计时` + `G02 声音探路` + `H01 足迹追逐` + `R01 会走路的安全屋`

* **个体叙事与关卡推进**： 无名少年“墨”在坍塌的灯塔顶层醒来，听见楼下传来沉闷的铁皮敲击声。你顺着声音摸索下去（学会 `G02 回声探路`），发现一间四足机械木屋“老铁皮”正被上涨的腐蚀黑水困在礁石上，一条木腿卡进了裂缝。 你捡起屋里的《残光图册》与【定影风灯】，利用退潮与涨潮的水位差（`E05`）探索周边浅滩：退潮时走陆路收集维修齿轮，涨潮时站在老铁皮屋顶渡过深槽。

* **高光机制时刻**： 下半程首次遭遇顺着脚印余温追猎的【浅滩盲猎者】（`H01`）。你学会不走原路返回，而是赶在涨潮前故意踩出一条通往礁石死角的假脚印链，利用潮水冲刷掉自己的真实退路。修好木腿后，老铁皮笨拙地抖了抖烟囱，门框上浮现出它指向东方的归家执念。你们正式结伴踏上荒原。

### 第二幕：认路很差的邮差与不肯亮灯的谷地（第一次真实零和取舍）

* **舞台区域**：风鸣石谷 & 幽光菌林

* **核心条目**：`C01 认路很差的邮差` + `C02 不肯逃走的修鞋匠` + `E02 黑暗是栖息地` + `E07 怪物礼仪` + `V03 怪物让路` + `V07 不要替我开灯` + `B06 绳结` + `B11 寂静瓶`

* **个体叙事与关卡推进**： 进入石谷后，老铁皮因为峡谷太窄无法通行，只能停在谷口等你（`G08`）。你在谷中遇到了迷路三天、靠听各家门轴吱呀声认路的邮差 **帕克（`C01`）**，他正急着把退烧药送给谷底修鞋匠 **老石（`C02`）** 病重的孙女；而老石之所以不肯撤离这片正在塌陷的石谷，只是因为答应给隔壁孤儿修的冬靴还没纳完最后一双底。

* **严密自洽的解谜设计**：

  1. **寂静瓶正确教学**：谷底有一座失控轰鸣的废弃风车，巨大的噪音不仅震碎了回声波纹，还让邮差帕克完全听不见门轴声。你必须先去安静的旧祠堂收集【寂静瓶】（注意不能在祠堂死角待满3秒以免引出【静室寄居者】），然后**将寂静瓶扔在轰鸣的风车轴承上罩住噪音源**。世界安静下来的20秒里，你和帕克站在十米外的石壁旁，终于清晰听见了被困在塌方墙后的老石敲击鞋楦的求救声！

  2. **盲眼巨兽的礼仪（`E07/V03`）**：通往老石屋子的窄巷里卧着一头庞大的【盲眼苔背兽】。硬闯或用风灯照射会激怒它引发塌方；通过观察洞口独居老人的提示（`V07`），你学会熄灭风灯、贴紧左侧墙根并轻敲两下地面示意“借道”，巨兽便会温顺地收起骨刺，替你让出半边走廊。

* **无后门的零和抉择（拒绝造假双赢）**： 老石的孙女高烧不退，单靠帕克背来的药只能撑两天，必须决定是否点燃石谷的【航标界碑】将此地绘入主网：

  * **若点亮航标**：老铁皮与荒原医疗船得以开进石谷，小女孩彻底获救，老石也能带着修好的鞋跟医疗船撤离；**但代价是**，航标强光瞬间灼伤了整片幽光菌林，那头曾温柔给你让路的【盲眼苔背兽】在痛苦的哀鸣中逃入深渊再也不见，谷口的独居老人也失去了陪伴他入眠的夜行发光虫，只能沉默地收拾行囊离开。

  * **若保持留白熄灯**：菌林与盲眼巨兽安然无恙，你可以用【记路绳结】（`B06`）教会邮差帕克一条摸黑进出的小路维持最低限度的送药；**但代价是**，老铁皮无法穿过石谷，你必须拆下老铁皮身上珍贵的备用暖炉芯留给小女孩续命（导致下一幕老铁皮在风雪中移动变慢、无法为你烘烤恢复体力的热茶），且石谷西侧的道路在三天后彻底坍塌断绝。

  * **设计意图**：无论怎么选，玩家都会失去珍贵的事物，没有任何“撒个谎两边全占”的作弊选项。

### 第三幕：纸上的猎犬与擦路人的交锋（机制巅峰与同规则对抗）

* **舞台区域**：千桥废墟 & 迁徙集市

* **核心条目**：`M02 擦路防追` + `H09 纸面追逐` + `C13 负责涂掉道路的人` + `N03 反派同规则操作` + `V05 不会追你的房间` + `V09 房子闹别扭` + `E10 迁徙街区`

* **个体叙事与关卡推进**： 穿过石谷后，你们追上了随风向移动的【迁徙集市】（`E10`）。如果你在前一幕经常丢下老铁皮独自跑图，老铁皮会在集市外闹别扭停下，把床挪到角落不理你（`V09`），直到你去集市换来一桶防锈油帮它擦洗烟囱、陪它看一场集市的影子戏，它才重新把门朝向你打开。 然而，在横跨裂谷的“千桥废墟”上，你们撞见了宿敌 **“擦路人”凛（`C13`）**。她刚刚用【空白石】抹掉了集市通往东方的唯一石桥，并冷冷地警告你：“你画在图册上的每一笔，都是在给猎犬画餐盘。”

* **核心关卡体验（同规则双层智斗）**：

  1. **纸面猎犬初战（`M02` + `H09`）**：凛为了逼你放弃制图，将你的图册气息暴露给了游荡在裂谷中的【巡图猎犬】。霎时间，你的地图纸面上出现三个高速移动的墨色黑点，顺着你刚画好的廊桥网格朝你和老铁皮包抄而来！你必须一边在现实中奔跑，一边打开图册**精准擦掉关键连接桥的墨线**，把猎犬截断在北侧孤岛，同时靠记忆摸黑扳动南侧水闸。

  2. **与“凛”的同规则对决（`N03`）**：在废墟中枢，凛与你展开实时博弈——你用【定影风灯】照住摇晃的残桥（`V01`）让老铁皮通过，凛就会投掷寒霜石遮蔽灯光、或者用空白石擦除你刚画好的路标；你则利用【余温伪造】（`G04`）在东侧走廊点燃一排火柴假装主力突围，把凛引向东侧去擦路，自己带着老铁皮顺着提前编好的【记路绳结】从西侧无图暗道破局而出！

  3. **高压中的绝对温柔（`V05`）**：在整座千桥都在崩塌、猎犬与凛双重夹击的窒息中段，你在断桥下推开一扇歪斜的旧报亭木门，门框上用粉笔写着：“*喘口气吧，这里不在任何地图上。*”——这间屋子没有任何陷阱或反转，猎犬读不到它，凛也找不到它，你真的可以在里面安安静静地喝一口水。

### 第四幕：哨声响起的地方（老救援员赫伯与不可洗白的往事）

* **舞台区域**：第七沉降驿站 & 巨兽墓园

* **核心条目**：`C07 过分认真的救援员` + `H05 它是来救你的` + `V13 救援员终于找到你` + `C15 没有恶意的冒名者` + `H02 截道影` + `N06 真相不改变事实`

* **个体叙事与关卡推进**： 离东海只剩最后一段路时，暴风雪裹挟着黑雾降临。在这片连方向都会迷失的盲区里，游荡着一个让你极其头疼的阻碍——守在废弃7号驿站的 **老救援员赫伯（`C07/H05`）**。 赫伯是一名六十多岁、右腿装着铁支架的独眼老人。他守着早已没有上级联络的驿站四十年，吹着刺耳的铜哨在风雪里巡逻。**他抓你不是为了害你，而是因为外面有致命的【截道影】（`H02`），他认死理地觉得“这么小的孩子和一间破木屋去东海就是送死”**。一旦被他抓到，你不会死，但会被他强行扛回驿站火炉边锁上门，白白错失风雪停歇的通行窗口！

* **关卡博弈与情感反转**：

  * **前半程（躲避笨拙的保护 + 智斗真怪物）**：你既要利用假地名标签和假余温欺骗真正的致命掠食者【截道影】（`H02`），又要提防赫伯大叔的巡逻哨音，还要处理一个偷穿了你的备用斗篷、模仿你的笔迹在驿站骗吃骗喝的 **小冒名者“灰”（`C15`）**。

  * **真相揭晓（`N06`）**：在驿站深处的旧日志里，你发现了老铁皮真正的来历——原来老铁皮根本不是什么“想去东海看海的普通木屋”，它是当年擦路人“凛”和老赫伯共同建造的 **“零号移动灯塔”**！当年正是因为老铁皮身上的主航标灯过载暴走，才引来了吞没凛家乡的猎犬潮。老铁皮之所以拼命往东海走，是因为它记得造船厂里有销毁自己核心炉、彻底平息猎犬潮的熔炉——**它一路带你去东海，是想在把你送到安全地带后，自己走进熔炉自毁谢罪！**

  * **绝境哨音名场面（`V13`）**：得知真相后你冲出驿站去追独自冲进黑雾的老铁皮，却在巨兽墓园被三只【截道影】彻底包死在绝壁下，风灯摔碎，图册被撕裂。在屏幕逐渐变黑、耳鸣达到顶峰的绝望时刻，按键提示只剩下一个动作——**吹响赫伯塞给你的那枚救援铜哨**。 下一秒，那个你躲了一整章、嫌他烦了一整章的暴躁老头赫伯，举着火把撞碎冰墙冲了进来，用身体替你架住怪物的扑击，一句话也没骂你，只是从怀里摸出一壶温水递到你嘴边：“*先喝口水，臭小子。那间破房子在前面等你呢，我陪你去把它拽回来。*”

### 第五幕（终章）：把迷宫交出去（《OneShot》式情感终局与接力破局）

* **舞台区域**：终焉海岸 · 零号船台

* **核心条目**：`X20 终点是把迷宫交出去` + `B40 最后一次探索由别人描述给你听` + `V10 熟路上的陌生扶手` + `B35 清理一场成功的冒险` + `V24 今晚是你等人敲门`

* **终局困境（拒绝俗套二选一，用机制与关系破局）**： 你和赫伯终于在海岸船台追上了老铁皮，而“擦路人”凛也守在这里，身后是顺着你一路画下的主干图册蜂拥而至的【巡图猎犬母体】。 摆在面前的看似是一个死局：

  * 如果保住《残光图册》的主干墨线，猎犬母体将顺着墨线吞噬船台与沿途所有聚落；

  * 如果让凛用【空白石】彻底抹去图册，猎犬母体会因失去路径而溃散，但老铁皮也会因为失去图册的认知锚定而彻底熄火休眠，且你们两人一屋将被永远困死在没有地图的终焉海岸，再也回不去。

* **终极关卡设计——【不用墨水的活体路网】（`X20` + `B40`）**： 你做出了第三个选择：**你亲手用黑橡皮擦光了整本《残光图册》上的所有纸面墨迹！** 猎犬母体在瞬间失去了所有纸面拓扑路径，在海岸黑雾中彻底迷失消散。但正如凛所说，没有了地图，你背着受伤的赫伯、带着失去远行导航的老铁皮，面对来时那片漆黑错乱的荒原，根本不可能走回去——**如果只有你一个人的话。** 此时，终章真正的玩法展开：

  1. 在擦掉纸面地图后，你拿出了传声海螺与仅存的几段【记路绳结】。令你震撼的是，黑暗的荒原深处亮起了一道道不属于地图墨迹的微弱回声——那是邮差帕克（`C01`）、修鞋匠老石（`C02`）、小冒名者“灰”（`C15`）、甚至是终于被触动的擦路人凛（`C13`）！

  2. **非对称远程接力（`B40`）**：你坐在老铁皮的屋檐下，通过传声管听着远方的伙伴们一段接一段地向你描述他们眼前的黑雾地形（“*墨，我听到前面有三声短回音，地面是温的，该往哪边栓绳结？*”）。你凭借整场旅途对世界规则的透彻理解，在没有地图的情况下为他们指引方向；而他们则在外面用【记路绳结】、门轴声标与温水火盆，替你和老铁皮反向搭建起一条“不写在纸上、猎犬永远读不到、只存在于人与人记忆与接力中”的归家之路！

  3. 回程途中，当你一瘸一拐地扶着老铁皮走过第三幕那段最难走的陡坡时，发现崖壁上不知何时钉上了一排结实的木制扶手——那是小冒名者“灰”和邮差帕克提前替你们装好的（`V10`）。

* **可玩尾声（Epilogue）：今晚是你等人敲门（`B35` + `V24`）** 老铁皮最终没有自毁。它在终焉海岸换上了一块普通的新木板，跟著你们顺着绳结路网回到了阳光微露的石谷边缘停泊下来。 在安静的可玩尾声里，你可以慢悠悠地走过熟悉的道路，收回当初为了逃命乱扔的诱饵、修补好被撞坏的木门、把借来的工具还给邻居（`B35`）。最后，疲惫的你回到老铁皮温暖的屋里躺下，窗外下起小雨，老铁皮习惯性地把屋檐往你窗边歪了歪（`W04`）。门外响起了熟悉的“两长一短”敲门声——邮差帕克和老赫伯正端着一锅刚煮好的热汤，站在门外等你开门（`V24`）。

## 六、 原型验证与防疲劳节奏设计（Prototyping & Pacing）

1. **三层数据状态严格解耦（杜绝规则漏洞的技术底座）**： 游戏底层严格分离 **【物理世界层（Physical World）】**、**【纸面墨迹层（Ink Map Graph）】** 与 **【感官事件层（Sound/Heat Events）】**。

   * 【巡图猎犬】的寻路AI**只允许传入 `Ink Map Graph`**，哪怕玩家在现实中贴着它脸放鞭炮，只要该格不在墨迹图上，猎犬在代码层面就是完全盲聋的；

   * 【寂静瓶】的作用逻辑是**在 `Sound Events` 层生成一个圆形遮罩过滤网**，凡是圆心处于遮罩内的声源（如轰鸣风车），其向外辐射的噪声值直接归零，从而让遮罩外的微弱声源（墙后敲击）信噪比突破阈值被玩家听见。所有解法100%由底层物理规则自然涌现，绝不写死剧情脚本豁免。

2. **同一核心机制的四幕情感变奏（防疲劳设计）**：

   * **第一幕（求生）**：画图是为了在潮汐中认清退路，擦图是为了修正水位变化；

   * **第二幕（取舍）**：画图与留白成了决定一个聚落“得救但失去生态”还是“隐匿但独自承受枯竭”的沉重落笔；

   * **第三幕（博弈）**：画图与擦图变成与【巡图猎犬】及宿敌“凛”在纸面与现实双线交锋的战术武器；

   * **第五幕（托付）**：主动擦去全部纸面墨线，用绳结与口耳相传的记忆替代纸面地图，完成从“依赖地图”到“相信彼此”的终极升华。

3. **15分钟最小灰盒原型（Vertical Slice）**： 用 **8个网格房间 + 1间可移动但过不去窄桥的活房子“老铁皮” + 1只只读地图墨线的【巡图猎犬】 + 1台轰鸣风车与1个【寂静瓶】** 搭建最小可玩切片。测试标准只有两条：① 玩家能否在没有文字提示的情况下，自己试出“把寂静瓶扔向风车才能听见墙后敲门声”；② 玩家能否在猎犬逼近时果断擦掉身后的走廊墨线，靠地面残留的余温脚印摸黑逃回老铁皮屋里。只要这两步成立，整部作品的核心骨架即告稳固。
