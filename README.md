# 残光图志 · 墨线实验

这是一个可试玩的 Godot 二维玩法研究 Demo。它用六个小关验证：有限墨线回收、隔离猎犬、借猎犬拆障、重复调度猎犬，以及老铁皮的停靠位置能否参与解谜。规则是本次原型的实验选择，尚未冻结为正式游戏需求。

## 开始试玩

本仓库保存 Demo 源码与启动器，Godot 引擎、缓存、运行日志和私人试玩记录不提交到 GitHub。

Windows 首次下载仓库后：

1. 从 [Godot 官方发布页](https://github.com/godotengine/godot-builds/releases/tag/4.7.2-stable) 下载 `Godot_v4.7.2-stable_win64.exe.zip`。
2. 把压缩包中的两个可执行文件解压到仓库根目录的 `.tools/godot/`。
3. 双击根目录的 **开始试玩.cmd**。首次启动会先导入资源，再打开游戏。

如果本机已经有 `.tools/godot/` 中的引擎，可以直接双击启动。Godot 是便携版，无需系统安装。

双击 **打开编辑器.cmd** 可查看和修改项目；项目入口为 `demo/project.godot`。也可以用自己的 Godot 4 稳定版导入该文件。中文使用系统字体 Microsoft YaHei / Noto Sans CJK SC 等，不另行分发系统字体。

## 怎么玩

目标是让 **墨和老铁皮都到达金色终点**。六关全部可以直接选择，无需解锁。

| 操作 | 方法 |
| --- | --- |
| 画桥或擦桥 | 按 3，依次点两个锚点；也可点击路线中段 |
| 移动墨 / 老铁皮 | 按 1 / 2，再点相邻目的地 |
| 放浓墨印章 | 按 4，再点锚点 |
| 确认操作 | 空格 / 执行一步 |
| 等待 | 点“等一步”，再确认 |
| 撤销 / 重来 | Z / R |
| 提示 / 规则 | H / F1 |
| 取消选择或关闭说明 | 右键 / Esc |
| 下一关 | N / 下一关 |

选择操作时世界暂停，橙色箭头显示猎犬本步将走的位置。确认后你的操作先执行，猎犬再走一段。预测与执行调用同一套确定规则。危险操作会提前提示，仍允许尝试；随时可以完整撤销。

## 本次原型明确采用的实验规则

- 每次架桥、擦桥、角色移动、盖章、等待均推进一步。玩家不受倒计时催促。
- 青色墨桥可画、可擦；擦除完整返还额度。淡色虚线表示可画的位置。带短刻痕的旧墨线固定存在、不占额度、不可擦。
- 灰色陆地栈道不占墨线；细点线栈道仅允许墨通过。猎犬只沿有效墨线行走，不能走陆地栈道。
- 猎犬在连通网络中选择最高吸引源：普通节点 1、老铁皮 2、新桥落笔端 3、墨障 3.5、印章 4。相同吸引力先选最近节点，再按字母排序。当前节点已是最高且最近时停留。
- 手动画桥的第二个锚点为落笔端，只在本次猎犬行动时提供吸引力。直接点击路线使用关卡文件预设的落笔端，执行前会显示。
- 印章持续本步及后两步，有次数限制；同时最多一枚，新章替换旧章。印章可以放在任意已显示锚点，仍须有墨线连通才能吸引猎犬。
- 猎犬进入墨障节点后永久清除障碍，随后休眠一步。墨可以与猎犬同岛；猎犬与老铁皮同岛则失败。
- 角色都停留在岛屿节点，移动动画期间不能操作，因此不存在擦掉角色脚下半座桥的歧义。
- 回声、绳结、完整剧情、双犬和凛的改图暂未加入。本 Demo 专注于验证改路与同行的核心循环。

## 六关测试什么

1. 第一座桥：额度能否通过回收继续利用，双角色操作是否清楚。
2. 剪断追来的路：玩家能否理解切断连接如何隔离猎犬。
3. 请它开门：能否把猎犬作为开路工具，再安全隔离。
4. 还要再借一次：是否会过早关住猎犬，如何腾出额度完成下一步。
5. 老铁皮也是路标：没有印章时，能否主动利用老铁皮的位置诱导猎犬。
6. 一起走过最后一桥：能否组合拆障、回收、狭窄捷径与同行通路。

## 试玩记录与观察

记录只保存在本机 `demo/playtest/`，不上传、不联网。`attempts.jsonl` 保存关卡、步数、用时、撤销、失败、提示、重来和选填感受；`progress.json` 保存完成印记。界面集成测试使用独立的 `artifacts/qa-playtest/`，不覆盖玩家进度。

观察时重点看：玩家能否说清猎犬为何移动；后几关是否仍需改变思路；是否反复套用同一套路；老铁皮是否参与计划；解开后是否愿意继续。自动通关只证明规则可执行及关卡可解，玩法是否有趣仍需要真实试玩。

## 验证与代码

双击 **验证规则.cmd**，或在终端运行以下命令：

```powershell
& '.\.tools\godot\Godot_v4.7.2-stable_win64_console.exe' --headless --path '.\demo' --script 'res://tests/rules_test.gd'
& '.\.tools\godot\Godot_v4.7.2-stable_win64_console.exe' --headless --path '.\demo' --script 'res://tests/ui_test.gd'
```

- `demo/scripts/simulation.gd`：纯规则、合法性、寻路、行动预测与执行。
- `demo/scripts/levels.gd`：六关的数据、说明和逐步提示。
- `demo/scripts/main.gd`：原生矢量画面、鼠标键盘、动画、撤销和本地记录。
- `demo/tests/`：六关通关回放、边界规则、确定性与界面集成检查。包含答案，试玩前可以先不读。
- `artifacts/`：运行日志与测试报告。
- `design/`：原有玩法说明、当前与历史剧情大纲、创意库；Demo 的具体实验规则见本文。
